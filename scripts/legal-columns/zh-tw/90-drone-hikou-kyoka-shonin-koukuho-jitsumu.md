**先講重點：**在日本以工作為目的飛行無人機（空拍機），要掌握兩套制度。一是機體登錄（含電池重量100公克以上，自2022年6月20日起義務化）；二是在指定空域或以指定方式飛行時所需的飛行許可與核准（航空法第132條之85、第132條之86）。登錄與許可、核准是不同的手續，完成登錄並不代表就不需要許可。飛行許可與核准申請、機體登錄的書類製作與代理，由行政書士負責；無線電相關事項（技術基準適合、無線電台執照）是總務省依電波法辦理的另一套手續；事故後的賠償責任與紛爭由律師負責；業務委託契約的稅務由稅理士負責——各自以獨立的事業體、分別簽約為前提分工。辦公室或起降場所的租賃、購買，由另一事業體四葉不動產股份有限公司負責。本文屬一般性資訊提供，不保證特定飛行計畫是否屬於許可、核准的對象、能否通過審查、何時可以飛行。最終的適格判斷與法令解釋由有資格者與行政機關進行。本事務所不收取介紹費。

## 用無人機從事業務時，登錄與許可、核准有何不同？

「登錄」與「飛行許可、核准」是目的不同的兩套制度。混淆兩者，容易只辦其中一項就起飛。

機體登錄是替無人機分配登錄記號、掌握所有人的制度，自2022年6月20日起義務化。同時，規範對象由200公克以上擴大為100公克以上（含電池）。已登錄的機體須在機體上標示登錄記號，原則上並須具備以無線電發送識別資訊的功能（Remote ID）。

另一方面，飛行許可與核准，是當飛行落入指定空域（航空法第132條之85）或使用指定飛行方式（同法第132條之86）時，取得國土交通大臣許可、核准的制度。登錄是「把機體登記到登錄簿上」的入口手續，許可、核准則是「可否那樣飛」的手續，角色不同。

| 制度 | 依據 | 用途 |
| --- | --- | --- |
| 機體登錄 | 航空法（2020年修法新設、2022年6月20日施行） | 替100公克以上機體分配登錄記號、掌握所有人；原則搭載Remote ID |
| 飛行許可 | 航空法第132條之85 | 在禁止空域飛行的許可 |
| 飛行核准 | 航空法第132條之86 | 不依指定方式飛行的核准 |

## 哪些飛行（空域、方式）需要許可或核准？

航空法第132條之85規定了不得飛行的空域。大致是：可能影響航空器航行安全的空域（機場周邊的進入表面等區域、地表或水面150公尺以上高度的空域），以及人口或家屋密集地區（人口集中地區）上空。災害時設定的緊急用務空域也包含在內。在這些空域飛行需要許可。

航空法第132條之86規定了飛行方式。基本規則必須始終遵守：不在酒精等影響下飛行、飛行前確認、與其他航空器或物件的防撞、不以造成他人困擾的方式飛行。在此之上，下列方式飛行需要核准。

| 需要核准的飛行方式 | 內容 |
| --- | --- |
| 夜間飛行 | 日間（日出至日落）以外的飛行 |
| 目視外飛行 | 未以目視持續監視的飛行 |
| 無法確保距離的飛行 | 與人或物件之間無法保持省令所定距離（30公尺）的飛行 |
| 活動場所上空飛行 | 祭典、廟會等眾人聚集的活動場所上空 |
| 危險物運送 | 運送危險物的飛行 |
| 投下物件 | 投下物件的飛行 |

此外，持有技能證明者，在一定條件下飛行取得機體認證的機體時，可省略部分許可、核准（第四級〔Level 4〕飛行制度於2022年12月5日施行）。可否省略，依飛行類別而不同，須個別確認。

## 包括申請與個別申請如何區分使用？

申請分為以特定日期、地點的飛行為對象的個別申請，以及以一定期間、一定範圍的飛行整批為對象的包括申請。反覆、持續進行空拍或巡檢的業者，一般使用整合期間或飛行路線的包括申請。以期間為準的包括申請，最長可涵蓋一年。

| 種類 | 適合的用法 |
| --- | --- |
| 個別申請 | 特定日、特定地點的單次飛行 |
| 包括申請（期間） | 反覆、持續進行的類似飛行（最長一年） |
| 包括申請（路線） | 不特定飛行路線，在一定範圍內反覆進行 |

即使是包括申請，活動場所上空、危險物運送、投下物件等高風險飛行，也可能無法整批納入。可用何種形式，取決於飛行內容，並非一律。

## 申請書類與審查會看哪些重點（飛行手冊、技能）？

申請時要提出機體資訊、操縱者的飛行經歷、知識與技能，以及確保安全的體制（飛行手冊）。審查會看機體是否符合安全基準、操縱者是否具備必要的飛行經歷與能力、是否訂有防止事故的程序。

申請原則上透過線上的無人機資訊基礎系統（DIPS2.0）進行，須於預定飛行開始日的至少10個開廳日前提出。書類製作，以及為滿足要件而整理需補強之處，是行政書士可代理、代辦的部分。但飛行本身的安全判斷，以及機體、操縱者是否滿足要件的實質確認，由業者本人與國土交通省、登錄檢查機關進行。行政書士無法保證飛行本身的可行性。

## 無線電、保險、事故應對該找誰諮詢？

無人機飛行也涉及航空法以外的手續。各自以獨立的事業體、分別簽約為前提分工。

- 影像傳輸等所用無線設備的技術基準適合（技適）、無線電台執照 → 依電波法由總務省辦理的手續。與本事務所依航空法的許可、核准是不同手續
- 事故發生時的損害賠償責任、當事人間的紛爭、圍繞保險金的爭議 → 律師
- 無人機事業的業務委託契約所涉所得稅、法人稅等稅務 → 稅理士
- 辦公室、倉庫、起降場所的租賃或購買 → 不動產經紀業者（另一事業體四葉不動產股份有限公司）

此外，若飛行中造成人員受傷、第三人物件毀損、與航空器碰撞或接近等，須向國土交通大臣報告事故等情形。行政書士負責的是飛行許可、核准申請與機體登錄的書類製作、代理，飛行手冊的整理，以及交付各專家的資料整理。受任流程請見[受任的流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)，承辦業務的全貌請見[承辦業務](https://luck428.com/legal/services)。亦提供中文（繁體、簡體）與英文諮詢。本事務所不收取介紹費。

## 常見問題

**Q. 100公克以下的小型無人機，登錄與許可都不需要嗎？**
A. 100公克以下的機體不屬於航空法上的無人航空機，因此不在登錄以及第132條之85、第132條之86許可、核准的對象範圍內。但小型無人機等飛行禁止法或地方條例等其他規範，可能在某些地點適用。請依飛行地點逐一確認。

**Q. 只要辦過一次包括申請，就能到處自由飛行嗎？**
A. 不行。包括申請僅在其涵蓋的空域、方式、期間範圍內有效。活動場所上空、危險物運送等高風險飛行可能無法整批納入，範圍外的飛行需另行取得許可、核准。

**Q. 取得資格（技能證明）後，許可、核准就不需要了嗎？**
A. 無法一概而論。雖然有「持技能證明者在一定條件下飛行取得機體認證的機體時，可省略部分許可、核准」的機制，但取決於飛行類別與條件。可否省略須個別確認。

**Q. 行政書士能做與不能做的是什麼？**
A. 行政書士負責飛行許可、核准申請與機體登錄的書類製作、代理，以及飛行手冊的整理。無線電技適與無線電台執照是總務省的另一套手續，事故後的賠償責任與紛爭屬律師領域，稅務屬稅理士領域。飛行本身的安全判斷與要件充足的實質確認，由業者與行政機關進行。
