**先講重點：**歸化是外國籍者提出申請、取得日本國籍的制度，需要法務大臣的許可（國籍法第4條）。普通歸化的要件有六項：在日本連續有住所五年以上；年滿18歲且依本國法有行為能力；素行善良；能夠維持生計；原則上因歸化而喪失原有國籍（防止雙重國籍）；遵守憲法（國籍法第5條）。日本國民的配偶、子女等有放寬要件的簡易歸化（國籍法第6條、第7條、第8條）。歸化許可申請書類的製作與諮詢由行政書士負責，但申請原則上須由本人親自到法務局、地方法務局出頭辦理，行政書士不能代替本人申請歸化。國籍喪失、本國戶籍或公證書的取得由本國的公證機關、領事館辦理；在留資格手續是入管的手續；涉及繼承、登記時由司法書士或稅理士負責——各自以獨立的事業體、分別簽約為前提分工。繼承所得不動產的出售、管理，由另一事業體四葉不動產股份有限公司負責。本文屬一般性資訊提供，不保證個別歸化的可否或要件的充足。最終准駁由法務大臣判斷。本事務所不收取介紹費。

## 歸化與永住有何不同，該如何選擇？

歸化與永住常被混淆，但是根本不同的制度。歸化是取得日本國籍、成為日本人的制度（依據國籍法，窗口為法務局）；永住則是保有外國籍、取得在留資格之一「永住者」的制度（依據入管法，窗口為出入國在留管理廳）。

| 項目 | 歸化 | 永住 |
| --- | --- | --- |
| 取得的地位 | 日本國籍（成為日本人） | 保有外國籍、在留資格「永住者」 |
| 依據法 | 國籍法 | 出入國管理及難民認定法 |
| 窗口 | 法務局、地方法務局 | 出入國在留管理廳 |
| 原國籍 | 原則喪失（防止雙重國籍） | 保留 |
| 選舉權等 | 可取得 | 不可取得 |

何者較適合，取決於是否想保留原國籍、如何看待在日本的參政權與身分等個別情況。這是制度差異的說明，最終如何選擇由本人決定。關於自在留資格轉換的全貌，亦可參見處理外國人經營者在留資格的[外國人經營者的在留資格（經營・管理簽證）與公司設立](https://luck428.com/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)。

## 歸化的要件（住所、生計、素行、防止雙重國籍等）是什麼？

普通歸化的要件規定於國籍法第5條第1項，共六項。

| 要件 | 內容 |
| --- | --- |
| 住所要件 | 在日本連續有住所五年以上 |
| 能力要件 | 年滿18歲，且依本國法有行為能力 |
| 素行要件 | 素行善良（就納稅、守法等綜合判斷） |
| 生計要件 | 能以本人或與其共同維持生計的配偶、其他親屬的資產、技能維持生計 |
| 防止雙重國籍要件 | 為無國籍，或原則上因歸化而喪失原有國籍 |
| 遵守憲法要件 | 未曾企圖以暴力破壞憲法或依憲法成立的政府等 |

能力要件的年齡自2022年4月1日起由「20歲以上」改為「18歲以上」。防止雙重國籍要件另有例外，適用於本人非出於己意而無法喪失國籍的情形（國籍法第5條第2項）。此外，對日本國民的子女、配偶、在日本出生者等，另有放寬住所要件等的簡易歸化（國籍法第6條、第7條、第8條）。例如日本國民的配偶，可能就婚姻與一定期間居住的組合獲得放寬。自己適用哪一條規定，須備齊資料後個別確認。

## 中國大陸、台灣的朋友在本國需要準備哪些書類？

在本國準備的身分關係書類，因各國制度而異。中國大陸沒有像日本的戶籍制度，因此以公證書證明身分關係；台灣設有戶籍制度，因此使用戶籍相關書類。

| 出身 | 主要準備的本國側書類例 |
| --- | --- |
| 中國大陸 | 出生公證書、親屬關係公證書（載明父母、兄弟姊妹、子女等關係者）、證明國籍的書類等。如在日本出生等情形有些不需要 |
| 台灣 | 戶籍謄本、除籍謄本、載明婚姻、出生等身分關係的書類等 |

中國不承認雙重國籍，定居外國的中國公民自願取得外國國籍時，自動喪失中國國籍（中華人民共和國國籍法第9條）。台灣（中華民國）則在歸化許可之後於本國側辦理國籍喪失等手續。這些書類多半需要日文譯本，視提出對象而定，可能要求公證、領事認證或海牙認證（Apostille）。要否因書類與提出對象而異，亦請一併參見處理本國關係書面認證區分的[外國關係書面的認證（Apostille、公證、領事認證）的區分使用](https://luck428.com/legal/column/gaikoku-kankei-shomen-ninsho-apostille-koushou-tsukaiwake)。

## 歸化申請的流程與審查中容易卡關之處在哪？

歸化許可申請，原則上由本人親自到管轄住所地的法務局、地方法務局出頭辦理（未滿15歲者由法定代理人代為申請）。先於事前諮詢確認必要書類，備齊後受理，其後有面談與調查，法務大臣許可後於官報告示，自告示日取得日本國籍（國籍法第10條）。

容易卡關之處在於：住所要件「連續」的持續性（長期出國可能被評價為中斷）、與素行要件有關的納稅與交通違規、生計要件的說明，以及本國書類的取得與翻譯準備。行政書士可協助這些書類的製作、整理，並就何處需補強提供諮詢。但要件是否具備的最終判斷由法務大臣進行，須本人出頭的手續，行政書士不能代替本人辦理。歸化亦非入管申請取次制度的對象。

## 涉及在留資格、繼承、登記時該找誰諮詢？

歸化前後可能涉及其他制度。各自以獨立的事業體、分別簽約為前提分工。

- 歸化前在留資格的更新、變更 → 出入國在留管理廳的手續（在留手續）。與歸化本身的窗口、依據法均不同
- 在本國辦理國籍喪失、取得本國戶籍或公證書 → 本國的公證機關、領事館。並非由日本的行政書士代辦
- 歸化前後發生繼承時的繼承糾紛或外國法解釋 → 律師
- 繼承登記等不動產、公司登記 → 司法書士
- 遺產稅、所得稅等稅務 → 稅理士
- 繼承所得不動產的出售、管理 → 不動產經紀業者（另一事業體四葉不動產股份有限公司）

行政書士負責的是歸化許可申請書類的製作、整理，本國書類、翻譯文件的整理，交付各專家的資料整理，以及陪同諮詢。涉及外國籍的繼承準據法，於[繼承人在海外居住、外國籍時的手續](https://luck428.com/legal/column/souzoku-kaigai-gaikokuseki)整理。受任流程請見[受任的流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)，承辦業務的全貌請見[承辦業務](https://luck428.com/legal/services)。亦提供中文（繁體、簡體）與英文諮詢。本事務所不收取介紹費。

## 常見問題

**Q. 歸化後原有國籍會如何？**
A. 因日本原則上不承認雙重國籍，歸化時原則上喪失原有國籍（防止雙重國籍要件）。中國大陸的朋友一般於取得日本國籍時自動喪失中國國籍；台灣的朋友則於歸化後在本國側辦理喪失等手續。個別處理依本國制度而定。

**Q. 歸化申請能全部交給行政書士嗎？**
A. 書類的製作、整理與諮詢支援可由行政書士負責，但申請原則上須由本人到法務局、地方法務局出頭辦理。歸化並非入管申請取次制度的對象，行政書士不能代替本人申請。

**Q. 住所要件的五年，中途出國會歸零嗎？**
A. 由於會審視「連續」的持續性，長期出國等可能被評價為居住中斷。中斷與否依個別情況判斷，故應整理出入境紀錄事先確認。最終判斷由法務大臣進行。

**Q. 行政書士會保證我符合歸化要件嗎？**
A. 不會。行政書士負責資料整理與諮詢支援，但要件是否具備、歸化是否准許，由法務大臣判斷。本文亦屬一般性資訊提供，不保證個別許可。
