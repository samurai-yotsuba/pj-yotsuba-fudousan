**結論（先講重點）**：作為營業常設經營、向公眾展示或使其聆聽音樂或演劇之設施——如Live House、小劇場、迷你劇院——可能該當興行場法（昭和23年法律第137號）之「興行場」。此時，擬作為營業經營者，須取得都道府縣知事（市或特別區則為市長或區長，以下同）之興行場營業許可（同法第2條第1項）。入場者衛生所必要之措施（換氣・照明・防濕・清潔）之基準，以及設置場所・構造設備之公眾衛生上必要基準，非由法律本體、而由都道府縣（含設置保健所之市或特別區）之條例訂定（同法第2條第2項・第3條）。本文為一般資訊提供，不判斷・保證個別設施是否該當興行場、許可之可否或對基準之適合。建築基準法上之用途・特殊建築物・檢查完成證與用途變更之可否屬建築士與特定行政廳、消防設備屬消防署、深夜提供酒類之申報與伴隨接待時之許可屬行政書士、物件之選定・租賃屬別事業體之不動產業者領域。四葉集團之行政書士，以獨立的事業體承辦許可・申報之申請支援。

## Live House・小劇場需要興行場營業許可嗎？

首先，是否該當「興行場」為出發點。興行場法第1條將興行場定義為「向公眾展示或使其聆聽電影、演劇、音樂、運動、曲藝或觀賞物之設施」。常設之Live House、小劇場、迷你劇院，係向公眾展示或使其聆聽音樂・演劇・電影之常設設施，故作為營業經營時原則上該當興行場，須取得第2條第1項之許可。

另一方面，以餐飲店營業為主、演奏僅屬附隨服務之「Live Bar」等，有被整理為不該當興行場之情形。是否該當，由許可權者之自治體斟酌設施之規模・常設性・營業實態判斷，故於企畫早期階段向所在地保健所確認不可或缺。

| 確認觀點 | 內容 |
| --- | --- |
| 公眾性 | 是否向不特定之客展示・使其聆聽 |
| 常設性 | 常設設施，抑或逐一活動之臨時利用 |
| 作為營業 | 是否反覆繼續經營 |
| 主從關係 | 興行為主，抑或餐飲等附隨 |

同一建物中，另須餐飲店營業許可或深夜酒類提供餐飲店營業之申報之情形亦有，此等與興行場營業許可為不同手續。伴隨餐飲提供時，亦請一併確認[餐飲店營業許可與保健所之設備基準](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)。

## 興行場之構造設備基準由何決定（法與都道府縣條例之關係）？

興行場法本體，就客席寬廣或通路寬度等細部數值基準幾無記載。具體基準由各都道府縣（含設置保健所之市・特別區）之條例訂定。第2條第2項規定，設置場所或構造設備經認定不適合條例所定公眾衛生上必要之基準時得不予許可；第3條就入場者衛生所必要之措施（換氣・照明・防濕・清潔）課營業者義務，並定其基準由都道府縣以條例訂定。

| 項目 | 由何處訂定 | 常生問題之點 |
| --- | --- | --- |
| 營業許可之要否・許可權者 | 興行場法（第1條・第2條） | 是否該當興行場、許可權者為知事或市長・區長 |
| 換氣・照明・防濕・清潔之衛生措施 | 都道府縣等之條例（第3條） | 具體基準值因自治體而異 |
| 設置場所・構造設備之公眾衛生上基準 | 都道府縣等之條例（第2條第2項） | 便所・洗面・通路等之基準 |

故「他縣曾如此」並不直接通用。確認計畫地所在自治體之興行場法施行條例・規則，並事前向保健所相談，為實務之出發點。又，興行場之營業者地位，於讓渡・繼承・合併・分割時承繼並須申報（同法第2條之2）。

## 建築基準法・消防法之用途，與興行場許可如何契合？

與興行場營業許可（衛生之許可）另外，建物本身須符合建築基準法・消防法之基準。劇場、電影院、曲藝場、觀覽場、公會堂、集會場及類此者，該當建築基準法別表第一（い）欄（一）項之特殊建築物，受用途地域之建築限制（同法第48條・別表第二）及特殊建築物之構造・防火・避難規定。

| 法律 | 主要觀點 | 負責 |
| --- | --- | --- |
| 建築基準法 | 用途地域之可否、特殊建築物之構造・雙向避難、檢查完成證、用途變更之要否 | 建築士・特定行政廳 |
| 消防法 | 作為防火對象物之消防用設備・防火管理者 | 消防署 |
| 興行場法 | 衛生所必要之措施・公眾衛生上基準 | 保健所（許可權者） |

劇場・電影院・曲藝場・觀覽場，依客席部分之樓地板面積，可興建之用途地域不同（例如客席是否未滿200㎡），於住居系用途地域多受限制。將既有店舖或事務所改為Live House時，亦可能須用途變更之確認申請。此等可否・數值由建築士與特定行政廳、消防用設備由消防署判斷，非行政書士所能判斷・保證。既有建物之遵法性（有無檢查完成證等）為租賃前應確認之重要點。

## 深夜提供酒類時，是否另需申報？

Live House於深夜（午前0時以後）經營提供酒類之營業時，於興行場營業許可與餐飲店營業許可之外，另須依風俗營業等之規制及業務適正化等相關法律為深夜酒類提供餐飲店營業之申報。此申報須於開始營業之日的10日前，向營業所所在地管轄之公安委員會（經由警察署）為之。

應留意者為「接待」之有無。伴隨坐於客旁持續歡談等接待時，非深夜酒類提供之申報，而成為風俗營業（接待餐飲等營業・1號營業）之許可問題，深夜0時以後之營業本身受限制。現場演奏原則上不該當接待，惟依營業形態判斷有別，故亦請一併確認[深夜酒類提供餐飲店營業之申報與要件](https://luck428.com/legal/column/shinya-shurui-teikyo-todokede-yoken)。

| 營業形態 | 所需手續 |
| --- | --- |
| 無酒類提供・無深夜營業 | 興行場營業許可（有餐飲則加餐飲店營業許可） |
| 深夜0時以後提供酒類・無接待 | 上述加深夜酒類提供餐飲店營業之申報 |
| 伴隨接待 | 風俗營業之許可（深夜營業受限制） |

## 自物件尋找至取得許可・開業之手順為何？

手續橫跨衛生・建築・消防・警察數者，順序一錯，即可能發生押下物件後方知無法使用之事態。概略流程如下，惟名稱・順序因自治體而異。

| 階段 | 主要內容 |
| --- | --- |
| 物件一次調查 | 與建築士確認用途地域・特殊建築物・有無檢查完成證 |
| 向保健所事前相談 | 確認是否該當興行場、條例之構造設備・衛生基準 |
| 向消防相談 | 確認消防用設備・防火管理之要否 |
| 內裝・設備之設計施工 | 符合條例基準・避難・防火之設計 |
| 興行場營業許可之申請・檢查 | 附圖面，經現地檢查而許可 |
| 深夜酒類提供之申報等 | 有酒類提供・深夜營業則於開業10日前申報 |

於締結物件租賃契約前，先確認用途地域・遵法性・原狀回復範圍，對防止落空甚為重要。物件之選定・租賃之媒介，由別事業體之四葉不動產株式會社負責。

## 許可・建築・消防・物件應委託何人（角色分工）？

| 委託對象 | 主要角色 |

## 常見問題

**Q. 即使是小型Live Bar也需要興行場營業許可嗎？**
A. 以餐飲為主、演奏屬附隨之Live Bar，有被整理為不該當興行場之情形。另一方面，若作為向公眾使其聆聽音樂之常設設施經營，則該當興行場，須取得興行場法第2條第1項之許可。是否該當由自治體斟酌規模・常設性・營業實態判斷，請事前向所在地保健所相談。

**Q. 興行場之構造設備基準看哪部法律可知？**
A. 興行場法本體幾無細部數值，換氣・照明・防濕・清潔及其他衛生之措施，以及設置場所・構造設備之公眾衛生上基準，由各都道府縣（含設置保健所之市・特別區）之條例訂定（同法第2條第2項・第3條）。確認當地施行條例並向保健所相談為出發點。

**Q. 有了興行場營業許可，是否即無須建築與消防手續？**
A. 否。興行場營業許可為衛生之許可，建築基準法（用途地域・特殊建築物・用途變更・檢查完成證）與消防法（消防用設備・防火管理）為另外之手續。劇場・電影院・曲藝場・觀覽場・集會場該當特殊建築物，須建築士・特定行政廳、消防署之判斷。

**Q. 深夜提供酒類需要什麼？**
A. 於午前0時以後經營提供酒類之營業，須依風俗營業等之規制及業務適正化等相關法律為深夜酒類提供餐飲店營業之申報，於開業10日前向公安委員會（經由警察署）為之。伴隨接待時，則成為風俗營業之許可問題，其深夜營業受限制。
