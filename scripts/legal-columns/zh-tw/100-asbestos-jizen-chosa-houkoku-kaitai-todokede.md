**結論（先說要點）**：拆除或改修建物時，調查石綿（石棉）含有建材有無之事前調查，原則上不問工程規模皆為義務。其依據為二法並列：大氣汚染防止法第18條之15（元請業者等之調查・記錄・報告）與依勞働安全衛生法之石綿障害予防規則第3條。建築物之事前調查，自2023年（令和5年）10月1日起，須由建築物石綿含有建材調查者等有資格者進行，非行政書士得代行之領域。一定規模以上（建築物拆除之拆除部分樓地板面積合計80㎡以上，或建築物改修、工作物之請負代金合計額100萬日圓以上〔含稅〕）之工程，自2022年（令和4年）4月1日起，須將事前調查結果透過石綿事前調查結果報告系統，向都道府縣等與勞働基準監督署報告。本文為一般資訊提供，自發注者（屋主）宜先掌握之順序，整理事前調查、報告、其他届出、罰則與專家之分工，不就個別工程是否為調查・報告對象作最終判斷。

## 拆除・改修前，石綿之事前調查為何為義務？

石綿（石棉）過去廣泛用於建材，吸入會引起間皮腫及肺癌。拆除或改修既有建物時，若不知情而破碎石綿含有建材，粉塵即飛散。故於工程著手前，調查建材石綿有無之「事前調查」，原則上對所有建築物・工作物之拆除・改修工程皆為義務。

事前調查之依據橫跨二部法律。

| 法令 | 主要內容 |
| --- | --- |
| 大氣汚染防止法第18條之15 | 拆除等工程之元請業者或自主施工者，調查特定建築材料（石綿含有建材）之有無，製作・保存記錄，一定規模以上並向都道府縣知事等報告結果 |
| 石綿障害予防規則第3條（依勞働安全衛生法） | 事業者事前調查石綿等之使用有無並保存記錄。為防止工作者健康障害之框架 |

同為事前調查，亦有二目的——防止向周邊飛散（環境側＝大氣汚染防止法）與工作者之健康（勞働側＝石綿障害予防規則）——報告可透過後述之一套系統進行。四葉行政書士事務所於行政書士業務範圍內，支援整理工程是否為報告或届出對象、届出文件之製作、發注者一方手續之代理。判定石綿有無之調查本身，由有資格之調查者進行。

## 事前調查由何人進行？（行政書士不得代行之處為何）

自2023年（令和5年）10月1日起，建築物之事前調查，須由具一定知見之有資格者進行。代表性資格如下。

| 資格 | 可調查之範圍（代表例） |
| --- | --- |
| 一般建築物石綿含有建材調查者 | 一般建築物之事前調查 |
| 特定建築物石綿含有建材調查者 | 於一般之外，專業性更高之建築物事前調查 |
| 一戶建等石綿含有建材調查者 | 限於一戶建住宅・集合住宅住戶內部之事前調查 |

此外，工作物（建築物以外之設備・構造物）之事前調查，亦自2026年（令和8年）1月1日起，義務化由資格者進行。

**此事前調查本身，並非行政書士得代行之業務。**行政書士擔任以調查結果為前提之報告或届出之文件製作・代理，惟建材是否含石綿之調查・判定，由有資格之調查者（必要時並有分析機關）進行。此處明確區分。

## 事前調查結果之報告於何種規模・樣式需要？

自2022年（令和4年）4月1日起，一定規模以上之工程須報告事前調查結果。報告對象如下。

| 工程種類 | 需報告之規模 |
| --- | --- |
| 建築物拆除工程 | 拆除部分之樓地板面積合計80㎡以上 |
| 建築物改修工程 | 請負代金合計額100萬日圓以上（含稅） |
| 工作物之拆除・改修工程 | 請負代金合計額100萬日圓以上（含稅） |

報告原則上透過「石綿事前調查結果報告系統」電子進行。此系統以一次操作即送達都道府縣等（大氣汚染防止法窗口）與勞働基準監督署（石綿障害予防規則窗口）雙方。負報告義務者，為承攬工程之元請業者或自主施工者，於工程著手前報告。發注者（屋主）本人並非報告者，惟發注者宜事先確認委託對象是否具備由有資格者事前調查並報告之體制。又，若達上述規模，不問石綿有無，皆須報告事前調查結果。

## 拆除時重疊之其他届出（建設回收法・勞働安全衛生法）為何？

拆除工程中，與石綿手續並行，尚重疊他法之届出・手續。

- **建設回收法第10條之届出**：建築物拆除達樓地板面積合計80㎡以上等一定規模以上之工程（對象建設工事），發注者或自主施工者須於工程著手日之7日前，向都道府縣知事届出分別拆除等之計畫。怠於届出者，處20萬日圓以下罰金。
- **拆除業者一方之制度**：承攬工程一方，依請負代金須有解體工事業登錄或建設業許可（解體工事業）。其切分見[解體工事業之登錄與建設業許可有何不同？](https://luck428.com/legal/column/kaitai-koji-gyo-touroku-kensetsu-kyoka-chigai)。
- **依勞働安全衛生法之體制**：對含石綿建材進行除去・拆除之作業，須選任石綿作業主任者（石綿作業主任者技能講習之修畢者），並對作業員施以特別教育。勞災保險・特別教育等勞務之體制建置，由與四葉行政書士事務所別事業體之社會保險勞務士（四葉社會保險勞務士事務所），以獨立的事業體個別簽約辦理。
- **瓦礫類之處理**：拆除所生之瓦礫類為產業廢棄物，收集運搬・處分由受許可業者為之。許可之取得方式見[產業廢棄物收集運搬業許可如何取得？](https://luck428.com/legal/column/sanpai-shushu-unpan-kyoka-torikata)。

若為繼承之老舊建物之拆除，拆除前後亦涉及繼承登記（司法書士）。繼承不動產名義變更之流程見[繼承登記如何進行？](https://luck428.com/legal/column/souzoku-touki-nagare)；整地出售或連同建物出售之窗口，為與四葉行政書士事務所別事業體之[不動產之繼承・出售窗口](https://luck428.com/souzoku)。

## 違反時將如何？（罰則・工程之停止）

怠於石綿手續，恐成罰則對象。

| 違反類型（大氣汚染防止法） | 罰則之例 |
| --- | --- |
| 不報告事前調查結果、或為虛偽報告 | 30萬日圓以下罰金 |
| 違反伴隨隔離等措施之特定粉塵排出等作業之作業基準 | 3月以下徒刑或30萬日圓以下罰金（直接罰） |

作業基準違反之直接罰，係於2021年（令和3年）4月1日之修正設置。怠於建設回收法第10條之届出者，亦有依該法之20萬日圓以下罰金。除罰則外，若未適正調查・報告・作業，恐招致行政之指導或作業中止，成為工程整體延遲及追加費用之原因。故於發注階段擬定手續之展望甚為重要。

## 調查・報告・工程・勞務分別委託何人（有資格調查者・行政書士・專業業者・社勞士）？

涉及石綿之拆除・改修，依領域分工如下。

- 石綿含有建材之事前調查・判定（必要時分析）→ 建築物石綿含有建材調查者等有資格之調查者・分析機關
- 事前調查結果之報告、建設回收法第10條之届出等之文件製作・代理 → 四葉行政書士事務所（行政書士）
- 石綿之除去・拆除工程（石綿作業主任者之選任）→ 受登錄・許可之專業拆除業者
- 勞災保險・特別教育等勞務 → 社會保險勞務士（四葉社會保險勞務士事務所）
- 繼承登記・公司設立等之登記 → 司法書士
- 建物滅失登記（表題部）→ 土地家屋調查士（申請對象為法務局）
- 讓渡所得・設備投資等稅務 → 稅理士
- 整地・連同建物之土地出售或物件手配 → 四葉不動產株式會社（宅地建物交易業者）

四葉行政書士事務所與四葉不動產株式會社為別事業體。含有資格之調查者・社會保險勞務士・司法書士・土地家屋調查士・稅理士之各領域，均以與各資格者作為獨立的事業體個別簽約為前提，本事務所不收取介紹費。受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)；取扱業務之全貌見[許認可・各種申請服務](https://luck428.com/legal/services)。

## 常見問題

**Q. 已知無石綿之建物，也須事前調查或報告嗎？**
A. 事前調查為確認無石綿亦原則上需要。進行書面調查與目視調查，無法判斷之建材以分析調查等確認。在此之上，若達建築物拆除80㎡以上，或改修、工作物請負代金100萬日圓以上（含稅）等規模，不問石綿有無，皆有報告事前調查結果之義務。

**Q. 事前調查或報告可委託行政書士嗎？**
A. 調查石綿有無之事前調查本身，自2023年（令和5年）10月1日起，屬建築物石綿含有建材調查者等有資格者進行之領域，行政書士不代行。行政書士擔任以調查結果為前提之報告及建設回收法第10條之届出等之文件製作・代理。調查係與有資格之調查者以獨立的事業體個別簽約後進行。本事務所不收取介紹費。

**Q. 報告由發注者（屋主）或工程業者何者為之？**
A. 大氣汚染防止法上，負事前調查結果報告義務者，為承攬工程之元請業者或自主施工者。發注者本人並非報告者。惟發注者宜於簽約前確認委託對象是否由有資格者事前調查，並透過石綿事前調查結果報告系統適切報告之體制。

**Q. 拆除繼承之老舊建物，須先辦繼承登記嗎？**
A. 建物之拆除或出售之前提，涉及名義及權利關係之整理。繼承不動產之名義變更（繼承登記）為司法書士之業務，且繼承登記自2024年（令和6年）4月1日起義務化。石綿之調查・拆除・登記・出售之順序，請與有資格之調查者・司法書士・不動產各擔任者個別簽約後個別確認。
