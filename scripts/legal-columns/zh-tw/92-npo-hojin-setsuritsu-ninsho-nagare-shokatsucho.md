**先講重點：**NPO法人（特定非營利活動法人）是依特定非營利活動促進法（平成10年〔1998年〕法律第7號）從事保健、醫療、福祉的增進與社區營造的推進等別表所列20個領域活動的非營利法人。設立需要所轄廳的「設立認證」——即主要事務所所在的都道府縣知事（事務所僅位於一個指定都市區域內時為該指定都市之長）（同法第9條、第10條）。認證採「認證主義」，只要符合法令、具備要件即可獲認證，與股份有限公司僅憑登記即可設立的制度不同。申請書須附定款與10人以上的社員名簿等（第10條第1項）；受理後有2週的公眾縱覽，所轄廳於縱覽期間屆滿後2個月內決定認證或不認證（第10條第2項、第12條）。收到認證通知後，於主要事務所所在地辦理設立登記，NPO法人即告成立（第13條第1項）。定款與設立認證申請書類的製作由行政書士負責，但設立登記由司法書士，收益事業的法人稅等稅務由稅理士，涉及身心障礙福祉、照護服務等指定時則交由另外的指定申請——各自以獨立的事業體、分別簽約為前提分工。作為活動據點的物件之買賣、租賃，由另一事業體四葉不動產股份有限公司負責。本文屬一般性資訊提供，不保證個別的設立可否或認證。本事務所不收取介紹費。

## NPO法人與股份有限公司、一般社團法人有何不同？

NPO法人、股份有限公司與一般社團法人都是法人，但依據法、設立方式與活動目的不同。NPO法人依特定非營利活動促進法，以增進不特定且多數人的利益（公益）為目的，從事別表所列20個領域之一的活動。

| 項目 | NPO法人 | 股份有限公司 | 一般社團法人 |
| --- | --- | --- | --- |
| 依據法 | 特定非營利活動促進法 | 公司法 | 一般社團法人及一般財團法人相關法律 |
| 設立方式 | 所轄廳的設立認證＋設立登記 | 僅設立登記（準則主義） | 僅設立登記（準則主義） |
| 活動領域 | 限別表的20個領域 | 無限制 | 無限制 |
| 社員（成員） | 須10人以上 | 股東1人亦可 | 社員2人以上 |
| 剩餘金分配 | 不得分配予成員 | 可對股東分紅 | 不得分配予社員 |

NPO法人不以營利為目的，也不將剩餘金分配予成員。且不得以傳播宗教教義、推進／支持／反對政治主張，或推薦／支持／反對特定公職候選人或政黨為主要目的（同法第2條第2項）。受領報酬的役員人數，須控制在役員總數的三分之一以下。何種法人格較適合，取決於活動內容與募資方式，這是制度差異的說明。最終選擇何種形式由本人判斷。以醫療為目的時的醫療法人制度另有不同，於[醫療法人設立認可的流程與必要書類](https://luck428.com/legal/column/iryohojin-setsuritsu-ninka-nagare-shorui)整理。

## 設立認證要向何處（所轄廳）申請？

設立認證的申請對象（所轄廳），是主要事務所所在的都道府縣知事。但該事務所僅位於一個指定都市區域內時，則以該指定都市之長為所轄廳（第9條）。即使事務所橫跨多個都道府縣，所轄廳仍由主要事務所的所在地決定。

所轄廳受理設立認證申請後，應立即公告或公表，並將一定書類供公眾縱覽2週（第10條第2項）。此縱覽期間，經令和3年〔2021年〕6月9日施行的改正，由原本的1個月縮短為2週。縱覽事項會透過所轄廳利用網際網路等方式公表。NPO法人的設立被設計為向市民廣泛開放的手續，正是此縱覽、公表的旨趣。

## 定款與申請書類需要哪些內容？

設立認證的申請，須於申請書附上下列書類（第10條第1項）。定款是規定名稱、目的、活動種類、事務所所在地、社員資格、役員、會議、資產、會計、事業年度等的法人基本規則。

| 主要附件書類 | 內容 |
| --- | --- |
| 定款 | 法人的基本規則（目的、名稱、活動種類、社員、役員、會計等） |
| 役員名簿 | 記載役員的姓名、住所或居所，以及有無報酬 |
| 就任承諾書、誓約書的謄本 | 各役員誓約未落入資格排除事由等 |
| 證明住所等的書面 | 證明役員住所或居所的書面 |
| 10人以上社員的名簿 | 顯示社員有10人以上 |
| 確認書 | 確認並非宗教、政治、選舉目的的團體等 |
| 設立趣旨書 | 為何設立的趣旨 |
| 證明設立意思決定的議事錄謄本 | 設立總會的議事錄等 |
| 事業計畫書、活動預算書 | 設立當初事業年度與翌事業年度各1份 |

社員（成員）有10人以上，是認證基準之一（第12條第1項）。役員須有理事3人以上、監事1人以上。由於定款與議事錄日後在登記與稅務申報也會使用，實務上一開始就使記載內容一致相當重要。定款與申請書類的製作、整理，可由行政書士支援。

## 從認證到登記、成立需要多久？

流程為：事前諮詢 → 申請、受理 → 2週縱覽 → 所轄廳認證或不認證的決定 → 認證通知 → 設立登記 → 成立，依此順序。除有正當理由外，所轄廳於縱覽期間（2週）屆滿之日起2個月內，作出認證或不認證的決定並以書面通知（第12條第2項）。所轄廳以條例定有更短期間時，則於該期間內。

| 手續 | 大致 | 依據、留意點 |
| --- | --- | --- |
| 縱覽 | 2週 | 受理後立即公告、縱覽（第10條第2項） |
| 認證、不認證的決定 | 縱覽期間屆滿後2個月內 | 可以條例定更短期間（第12條第2項） |
| 設立登記 | 自認證通知之日起2週內 | 因登記而法人成立（第13條第1項） |
| 成立後的申報 | 立即 | 附登記事項證明書與財產目錄向所轄廳申報 |

受設立認證者，自認證之日起經過6個月仍未辦理設立登記時，所轄廳得撤銷設立認證。整體而言，自申請至成立通常需數個月。具體的處理期間與必要書類，各所轄廳於手引（指引）中定有，故應在撰寫前確認該所轄廳的最新案內。

## 設立登記與稅務分別該找誰？

NPO法人的設立涉及多個專業領域。各自以獨立的事業體、分別簽約為前提分工。

- 定款與設立認證申請書類的製作、整理 → 行政書士
- 設立登記，以及成立後役員變更等登記 → 司法書士
- 收益事業的法人稅、消費稅、源泉徵收等稅務 → 稅理士
- 涉及身心障礙福祉服務、照護服務等指定時的指定申請 → 另外的指定申請（於[身心障礙福祉服務（生活介護等）的指定與物件要件](https://luck428.com/legal/column/seikatsu-kaigo-shitei-bukken-yoken)整理）
- 作為事務所、活動據點的物件之買賣、租賃 → 不動產經紀業者（另一事業體四葉不動產股份有限公司）

NPO法人在法人稅法上被視為公益法人等，原則上僅就收益事業所生所得課法人稅；但是否屬收益事業、是否須申報屬個別判斷，故由稅理士負責。行政書士負責的是定款與設立認證申請書類的製作、整理，交付各專家的資料整理，以及陪同諮詢。受任流程請見[受任的流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)，承辦業務的全貌請見[承辦業務](https://luck428.com/legal/services)。役員、社員中含外國籍者時的在留資格，亦請參見[外國人經營者的在留資格（經營・管理簽證）與公司設立](https://luck428.com/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)。本事務所不收取介紹費。

## 常見問題

**Q. 任何人都能設立NPO法人嗎？社員需要幾人？**
A. 社員（成員）有10人以上，是認證基準之一（特定非營利活動促進法第12條第1項）。此外，役員須有理事3人以上、監事1人以上。並須不以營利為目的，且不以宗教、政治、選舉為主要目的（第2條第2項）。是否個別具備要件，須備齊資料後確認。

**Q. 從認證申請到成立需要多久？**
A. 受理後有2週縱覽，其屆滿後2個月內由所轄廳決定認證或不認證（第10條第2項、第12條第2項）。認證通知後，於主要事務所所在地辦理設立登記而成立（第13條第1項）。整體自申請至成立通常需數個月，期間因所轄廳而異。

**Q. 只要受認證就一定能成為NPO法人嗎？**
A. 不是。認證是只要符合法令、具備要件即可取得的制度，但即使收到認證通知，若不據以辦理設立登記，法人仍不成立。自認證之日起經過6個月仍未登記時，所轄廳可能撤銷認證。登記由司法書士負責。

**Q. 從定款製作到登記、稅務，能在同一事務所一起委託嗎？**
A. 定款與設立認證申請書類的製作由行政書士、設立登記由司法書士、稅務由稅理士負責，各自以獨立的事業體、分別簽約。可於一個窗口受理諮詢並整理後交付各專家，但受任分開。本事務所不收取介紹費。
