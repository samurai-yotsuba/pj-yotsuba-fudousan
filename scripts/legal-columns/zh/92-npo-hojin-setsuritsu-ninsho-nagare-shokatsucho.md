**先讲重点：**NPO法人（特定非营利活动法人）是依特定非营利活动促进法（平成10年〔1998年〕法律第7号）从事保健、医疗、福祉的增进与社区营造的推进等别表所列20个领域活动的非营利法人。设立需要所辖厅的“设立认证”——即主要事务所所在的都道府县知事（事务所仅位于一个指定都市区域内时为该指定都市之长）（同法第9条、第10条）。认证采“认证主义”，只要符合法令、具备要件即可获认证，与股份有限公司仅凭登记即可设立的制度不同。申请书须附定款与10人以上的社员名簿等（第10条第1项）；受理后有2周的公众纵览，所辖厅于纵览期间届满后2个月内决定认证或不认证（第10条第2项、第12条）。收到认证通知后，于主要事务所所在地办理设立登记，NPO法人即告成立（第13条第1项）。定款与设立认证申请书类的制作由行政书士负责，但设立登记由司法书士，收益事业的法人税等税务由税理士，涉及身心障碍福祉、护理服务等指定时则交由另外的指定申请——各自以独立的事业体、分别签约为前提分工。作为活动据点的物件之买卖、租赁，由另一事业体四叶不动产股份有限公司负责。本文属一般性信息提供，不保证个别的设立可否或认证。本事务所不收取介绍费。

## NPO法人与股份有限公司、一般社团法人有何不同？

NPO法人、股份有限公司与一般社团法人都是法人，但依据法、设立方式与活动目的不同。NPO法人依特定非营利活动促进法，以增进不特定且多数人的利益（公益）为目的，从事别表所列20个领域之一的活动。

| 项目 | NPO法人 | 股份有限公司 | 一般社团法人 |
| --- | --- | --- | --- |
| 依据法 | 特定非营利活动促进法 | 公司法 | 一般社团法人及一般财团法人相关法律 |
| 设立方式 | 所辖厅的设立认证＋设立登记 | 仅设立登记（准则主义） | 仅设立登记（准则主义） |
| 活动领域 | 限别表的20个领域 | 无限制 | 无限制 |
| 社员（成员） | 须10人以上 | 股东1人亦可 | 社员2人以上 |
| 剩余金分配 | 不得分配予成员 | 可对股东分红 | 不得分配予社员 |

NPO法人不以营利为目的，也不将剩余金分配予成员。且不得以传播宗教教义、推进／支持／反对政治主张，或推荐／支持／反对特定公职候选人或政党为主要目的（同法第2条第2项）。受领报酬的役员人数，须控制在役员总数的三分之一以下。何种法人格较适合，取决于活动内容与募资方式，这是制度差异的说明。最终选择何种形式由本人判断。以医疗为目的时的医疗法人制度另有不同，于[医疗法人设立认可的流程与必要书类](https://luck428.com/legal/column/iryohojin-setsuritsu-ninka-nagare-shorui)整理。

## 设立认证要向何处（所辖厅）申请？

设立认证的申请对象（所辖厅），是主要事务所所在的都道府县知事。但该事务所仅位于一个指定都市区域内时，则以该指定都市之长为所辖厅（第9条）。即使事务所横跨多个都道府县，所辖厅仍由主要事务所的所在地决定。

所辖厅受理设立认证申请后，应立即公告或公表，并将一定书类供公众纵览2周（第10条第2项）。此纵览期间，经令和3年〔2021年〕6月9日施行的改正，由原本的1个月缩短为2周。纵览事项会透过所辖厅利用互联网等方式公表。NPO法人的设立被设计为向市民广泛开放的手续，正是此纵览、公表的旨趣。

## 定款与申请书类需要哪些内容？

设立认证的申请，须于申请书附上下列书类（第10条第1项）。定款是规定名称、目的、活动种类、事务所所在地、社员资格、役员、会议、资产、会计、事业年度等的法人基本规则。

| 主要附件书类 | 内容 |
| --- | --- |
| 定款 | 法人的基本规则（目的、名称、活动种类、社员、役员、会计等） |
| 役员名簿 | 记载役员的姓名、住所或居所，以及有无报酬 |
| 就任承诺书、誓约书的誊本 | 各役员誓约未落入资格排除事由等 |
| 证明住所等的书面 | 证明役员住所或居所的书面 |
| 10人以上社员的名簿 | 显示社员有10人以上 |
| 确认书 | 确认并非宗教、政治、选举目的的团体等 |
| 设立趣旨书 | 为何设立的趣旨 |
| 证明设立意思决定的议事录誊本 | 设立总会的议事录等 |
| 事业计划书、活动预算书 | 设立当初事业年度与翌事业年度各1份 |

社员（成员）有10人以上，是认证基准之一（第12条第1项）。役员须有理事3人以上、监事1人以上。由于定款与议事录日后在登记与税务申报也会使用，实务上一开始就使记载内容一致相当重要。定款与申请书类的制作、整理，可由行政书士支援。

## 从认证到登记、成立需要多久？

流程为：事前咨询 → 申请、受理 → 2周纵览 → 所辖厅认证或不认证的决定 → 认证通知 → 设立登记 → 成立，依此顺序。除有正当理由外，所辖厅于纵览期间（2周）届满之日起2个月内，作出认证或不认证的决定并以书面通知（第12条第2项）。所辖厅以条例定有更短期间时，则于该期间内。

| 手续 | 大致 | 依据、留意点 |
| --- | --- | --- |
| 纵览 | 2周 | 受理后立即公告、纵览（第10条第2项） |
| 认证、不认证的决定 | 纵览期间届满后2个月内 | 可以条例定更短期间（第12条第2项） |
| 设立登记 | 自认证通知之日起2周内 | 因登记而法人成立（第13条第1项） |
| 成立后的申报 | 立即 | 附登记事项证明书与财产目录向所辖厅申报 |

受设立认证者，自认证之日起经过6个月仍未办理设立登记时，所辖厅得撤销设立认证。整体而言，自申请至成立通常需数个月。具体的处理期间与必要书类，各所辖厅于手引（指引）中定有，故应在撰写前确认该所辖厅的最新案内。

## 设立登记与税务分别该找谁？

NPO法人的设立涉及多个专业领域。各自以独立的事业体、分别签约为前提分工。

- 定款与设立认证申请书类的制作、整理 → 行政书士
- 设立登记，以及成立后役员变更等登记 → 司法书士
- 收益事业的法人税、消费税、源泉征收等税务 → 税理士
- 涉及身心障碍福祉服务、护理服务等指定时的指定申请 → 另外的指定申请（于[身心障碍福祉服务（生活介护等）的指定与物件要件](https://luck428.com/legal/column/seikatsu-kaigo-shitei-bukken-yoken)整理）
- 作为事务所、活动据点的物件之买卖、租赁 → 不动产经纪业者（另一事业体四叶不动产股份有限公司）

NPO法人在法人税法上被视为公益法人等，原则上仅就收益事业所生所得课法人税；但是否属收益事业、是否须申报属个别判断，故由税理士负责。行政书士负责的是定款与设立认证申请书类的制作、整理，交付各专家的资料整理，以及陪同咨询。受任流程请见[受任的流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)，承办业务的全貌请见[承办业务](https://luck428.com/legal/services)。役员、社员中含外国籍者时的在留资格，亦请参见[外国人经营者的在留资格（经营・管理签证）与公司设立](https://luck428.com/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)。本事务所不收取介绍费。

## 常见问题

**Q. 任何人都能设立NPO法人吗？社员需要几人？**
A. 社员（成员）有10人以上，是认证基准之一（特定非营利活动促进法第12条第1项）。此外，役员须有理事3人以上、监事1人以上。并须不以营利为目的，且不以宗教、政治、选举为主要目的（第2条第2项）。是否个别具备要件，须备齐资料后确认。

**Q. 从认证申请到成立需要多久？**
A. 受理后有2周纵览，其届满后2个月内由所辖厅决定认证或不认证（第10条第2项、第12条第2项）。认证通知后，于主要事务所所在地办理设立登记而成立（第13条第1项）。整体自申请至成立通常需数个月，期间因所辖厅而异。

**Q. 只要受认证就一定能成为NPO法人吗？**
A. 不是。认证是只要符合法令、具备要件即可取得的制度，但即使收到认证通知，若不据以办理设立登记，法人仍不成立。自认证之日起经过6个月仍未登记时，所辖厅可能撤销认证。登记由司法书士负责。

**Q. 从定款制作到登记、税务，能在同一事务所一起委托吗？**
A. 定款与设立认证申请书类的制作由行政书士、设立登记由司法书士、税务由税理士负责，各自以独立的事业体、分别签约。可于一个窗口受理咨询并整理后交付各专家，但受任分开。本事务所不收取介绍费。
