**结论（先讲重点）**：作为营业常设经营、向公众展示或使其聆听音乐或演剧之设施——如Live House、小剧场、迷你剧院——可能该当兴行场法（昭和23年法律第137号）之「兴行场」。此时，拟作为营业经营者，须取得都道府县知事（市或特别区则为市长或区长，以下同）之兴行场营业许可（同法第2条第1项）。入场者卫生所必要之措施（换气・照明・防湿・清洁）之基准，以及设置场所・构造设备之公众卫生上必要基准，非由法律本体、而由都道府县（含设置保健所之市或特别区）之条例订定（同法第2条第2项・第3条）。本文为一般资讯提供，不判断・保证个别设施是否该当兴行场、许可之可否或对基准之适合。建筑基准法上之用途・特殊建筑物・检查完成证与用途变更之可否属建筑士与特定行政厅、消防设备属消防署、深夜提供酒类之申报与伴随接待时之许可属行政书士、物件之选定・租赁属别事业体之不动产业者领域。四叶集团之行政书士，以独立的事业体承办许可・申报之申请支援。

## Live House・小剧场需要兴行场营业许可吗？

首先，是否该当「兴行场」为出发点。兴行场法第1条将兴行场定义为「向公众展示或使其聆听电影、演剧、音乐、运动、曲艺或观赏物之设施」。常设之Live House、小剧场、迷你剧院，系向公众展示或使其聆听音乐・演剧・电影之常设设施，故作为营业经营时原则上该当兴行场，须取得第2条第1项之许可。

另一方面，以餐饮店营业为主、演奏仅属附随服务之「Live Bar」等，有被整理为不该当兴行场之情形。是否该当，由许可权者之自治体斟酌设施之规模・常设性・营业实态判断，故于企画早期阶段向所在地保健所确认不可或缺。

| 确认观点 | 内容 |
| --- | --- |
| 公众性 | 是否向不特定之客展示・使其聆听 |
| 常设性 | 常设设施，抑或逐一活动之临时利用 |
| 作为营业 | 是否反覆继续经营 |
| 主从关系 | 兴行为主，抑或餐饮等附随 |

同一建物中，另须餐饮店营业许可或深夜酒类提供餐饮店营业之申报之情形亦有，此等与兴行场营业许可为不同手续。伴随餐饮提供时，亦请一并确认[餐饮店营业许可与保健所之设备基准](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)。

## 兴行场之构造设备基准由何决定（法与都道府县条例之关系）？

兴行场法本体，就客席宽广或通路宽度等细部数值基准几无记载。具体基准由各都道府县（含设置保健所之市・特别区）之条例订定。第2条第2项规定，设置场所或构造设备经认定不适合条例所定公众卫生上必要之基准时得不予许可；第3条就入场者卫生所必要之措施（换气・照明・防湿・清洁）课营业者义务，并定其基准由都道府县以条例订定。

| 项目 | 由何处订定 | 常生问题之点 |
| --- | --- | --- |
| 营业许可之要否・许可权者 | 兴行场法（第1条・第2条） | 是否该当兴行场、许可权者为知事或市长・区长 |
| 换气・照明・防湿・清洁之卫生措施 | 都道府县等之条例（第3条） | 具体基准值因自治体而异 |
| 设置场所・构造设备之公众卫生上基准 | 都道府县等之条例（第2条第2项） | 便所・洗面・通路等之基准 |

故「他县曾如此」并不直接通用。确认计画地所在自治体之兴行场法施行条例・规则，并事前向保健所相谈，为实务之出发点。又，兴行场之营业者地位，于让渡・继承・合并・分割时承继并须申报（同法第2条之2）。

## 建筑基准法・消防法之用途，与兴行场许可如何契合？

与兴行场营业许可（卫生之许可）另外，建物本身须符合建筑基准法・消防法之基准。剧场、电影院、曲艺场、观览场、公会堂、集会场及类此者，该当建筑基准法别表第一（い）栏（一）项之特殊建筑物，受用途地域之建筑限制（同法第48条・别表第二）及特殊建筑物之构造・防火・避难规定。

| 法律 | 主要观点 | 负责 |
| --- | --- | --- |
| 建筑基准法 | 用途地域之可否、特殊建筑物之构造・双向避难、检查完成证、用途变更之要否 | 建筑士・特定行政厅 |
| 消防法 | 作为防火对象物之消防用设备・防火管理者 | 消防署 |
| 兴行场法 | 卫生所必要之措施・公众卫生上基准 | 保健所（许可权者） |

剧场・电影院・曲艺场・观览场，依客席部分之楼地板面积，可兴建之用途地域不同（例如客席是否未满200㎡），于住居系用途地域多受限制。将既有店舖或事务所改为Live House时，亦可能须用途变更之确认申请。此等可否・数值由建筑士与特定行政厅、消防用设备由消防署判断，非行政书士所能判断・保证。既有建物之遵法性（有无检查完成证等）为租赁前应确认之重要点。

## 深夜提供酒类时，是否另需申报？

Live House于深夜（午前0时以后）经营提供酒类之营业时，于兴行场营业许可与餐饮店营业许可之外，另须依风俗营业等之规制及业务适正化等相关法律为深夜酒类提供餐饮店营业之申报。此申报须于开始营业之日的10日前，向营业所所在地管辖之公安委员会（经由警察署）为之。

应留意者为「接待」之有无。伴随坐于客旁持续欢谈等接待时，非深夜酒类提供之申报，而成为风俗营业（接待餐饮等营业・1号营业）之许可问题，深夜0时以后之营业本身受限制。现场演奏原则上不该当接待，惟依营业形态判断有别，故亦请一并确认[深夜酒类提供餐饮店营业之申报与要件](https://luck428.com/legal/column/shinya-shurui-teikyo-todokede-yoken)。

| 营业形态 | 所需手续 |
| --- | --- |
| 无酒类提供・无深夜营业 | 兴行场营业许可（有餐饮则加餐饮店营业许可） |
| 深夜0时以后提供酒类・无接待 | 上述加深夜酒类提供餐饮店营业之申报 |
| 伴随接待 | 风俗营业之许可（深夜营业受限制） |

## 自物件寻找至取得许可・开业之手顺为何？

手续横跨卫生・建筑・消防・警察数者，顺序一错，即可能发生押下物件后方知无法使用之事态。概略流程如下，惟名称・顺序因自治体而异。

| 阶段 | 主要内容 |
| --- | --- |
| 物件一次调查 | 与建筑士确认用途地域・特殊建筑物・有无检查完成证 |
| 向保健所事前相谈 | 确认是否该当兴行场、条例之构造设备・卫生基准 |
| 向消防相谈 | 确认消防用设备・防火管理之要否 |
| 内装・设备之设计施工 | 符合条例基准・避难・防火之设计 |
| 兴行场营业许可之申请・检查 | 附图面，经现地检查而许可 |
| 深夜酒类提供之申报等 | 有酒类提供・深夜营业则于开业10日前申报 |

于缔结物件租赁契约前，先确认用途地域・遵法性・原状回复范围，对防止落空甚为重要。物件之选定・租赁之媒介，由别事业体之四叶不动产株式会社负责。

## 许可・建筑・消防・物件应委托何人（角色分工）？

因相关专业人士分属不同，基本上以各自独立的事业体个别签约。四叶集团之行政书士，以独立的事业体承担兴行场营业许可之申请书・附件之作成辅助、与保健所・消防・警察之事前相谈案内、深夜酒类提供餐饮店营业之申报支援。

| 委托对象 | 主要角色 |
| --- | --- |
| 行政书士（本事务所） | 兴行场营业许可・各种申报之申请支援 |
| 建筑士・特定行政厅 | 用途地域・特殊建筑物・用途变更・检查完成证之判断 |
| 消防署 | 消防用设备・防火管理之指导 |
| 公安委员会（警察） | 深夜酒类提供・风俗营业之申报・许可 |
| 不动产业者（别事业体之本公司） | 物件之选定・租赁之媒介 |
| 税理士 | 开业后之税务 |

## 常见问题

**Q. 即使是小型Live Bar也需要兴行场营业许可吗？**
A. 以餐饮为主、演奏属附随之Live Bar，有被整理为不该当兴行场之情形。另一方面，若作为向公众使其聆听音乐之常设设施经营，则该当兴行场，须取得兴行场法第2条第1项之许可。是否该当由自治体斟酌规模・常设性・营业实态判断，请事前向所在地保健所相谈。

**Q. 兴行场之构造设备基准看哪部法律可知？**
A. 兴行场法本体几无细部数值，换气・照明・防湿・清洁及其他卫生之措施，以及设置场所・构造设备之公众卫生上基准，由各都道府县（含设置保健所之市・特别区）之条例订定（同法第2条第2项・第3条）。确认当地施行条例并向保健所相谈为出发点。

**Q. 有了兴行场营业许可，是否即无须建筑与消防手续？**
A. 否。兴行场营业许可为卫生之许可，建筑基准法（用途地域・特殊建筑物・用途变更・检查完成证）与消防法（消防用设备・防火管理）为另外之手续。剧场・电影院・曲艺场・观览场・集会场该当特殊建筑物，须建筑士・特定行政厅、消防署之判断。

**Q. 深夜提供酒类需要什么？**
A. 于午前0时以后经营提供酒类之营业，须依风俗营业等之规制及业务适正化等相关法律为深夜酒类提供餐饮店营业之申报，于开业10日前向公安委员会（经由警察署）为之。伴随接待时，则成为风俗营业之许可问题，其深夜营业受限制。
