**结论（先说要点）**：拆除或改修建物时，调查石绵（石棉）含有建材有无之事前调查，原则上不问工程规模皆为义务。其依据为二法并列：大气污染防止法第18条之15（元请业者等之调查・记录・报告）与依劳动安全卫生法之石绵障害予防规则第3条。建筑物之事前调查，自2023年（令和5年）10月1日起，须由建筑物石绵含有建材调查者等有资格者进行，非行政书士得代行之领域。一定规模以上（建筑物拆除之拆除部分楼地板面积合计80㎡以上，或建筑物改修、工作物之请负代金合计额100万日圆以上〔含税〕）之工程，自2022年（令和4年）4月1日起，须将事前调查结果透过石绵事前调查结果报告系统，向都道府县等与劳动基准监督署报告。本文为一般资讯提供，自发注者（屋主）宜先掌握之顺序，整理事前调查、报告、其他届出、罚则与专家之分工，不就个别工程是否为调查・报告对象作最终判断。

## 拆除・改修前，石绵之事前调查为何为义务？

石绵（石棉）过去广泛用于建材，吸入会引起间皮瘤及肺癌。拆除或改修既有建物时，若不知情而破碎石绵含有建材，粉尘即飞散。故于工程着手前，调查建材石绵有无之「事前调查」，原则上对所有建筑物・工作物之拆除・改修工程皆为义务。

事前调查之依据横跨二部法律。

| 法令 | 主要内容 |
| --- | --- |
| 大气污染防止法第18条之15 | 拆除等工程之元请业者或自主施工者，调查特定建筑材料（石绵含有建材）之有无，制作・保存记录，一定规模以上并向都道府县知事等报告结果 |
| 石绵障害予防规则第3条（依劳动安全卫生法） | 事业者事前调查石绵等之使用有无并保存记录。为防止工作者健康障害之框架 |

同为事前调查，亦有二目的——防止向周边飞散（环境侧＝大气污染防止法）与工作者之健康（劳动侧＝石绵障害予防规则）——报告可透过后述之一套系统进行。四叶行政书士事务所于行政书士业务范围内，支援整理工程是否为报告或届出对象、届出文件之制作、发注者一方手续之代理。判定石绵有无之调查本身，由有资格之调查者进行。

## 事前调查由何人进行？（行政书士不得代行之处为何）

自2023年（令和5年）10月1日起，建筑物之事前调查，须由具一定知见之有资格者进行。代表性资格如下。

| 资格 | 可调查之范围（代表例） |
| --- | --- |
| 一般建筑物石绵含有建材调查者 | 一般建筑物之事前调查 |
| 特定建筑物石绵含有建材调查者 | 于一般之外，专业性更高之建筑物事前调查 |
| 一户建等石绵含有建材调查者 | 限于一户建住宅・集合住宅住户内部之事前调查 |

此外，工作物（建筑物以外之设备・构造物）之事前调查，亦自2026年（令和8年）1月1日起，义务化由资格者进行。

**此事前调查本身，并非行政书士得代行之业务。**行政书士担任以调查结果为前提之报告或届出之文件制作・代理，惟建材是否含石绵之调查・判定，由有资格之调查者（必要时并有分析机关）进行。此处明确区分。

## 事前调查结果之报告于何种规模・样式需要？

自2022年（令和4年）4月1日起，一定规模以上之工程须报告事前调查结果。报告对象如下。

| 工程种类 | 需报告之规模 |
| --- | --- |
| 建筑物拆除工程 | 拆除部分之楼地板面积合计80㎡以上 |
| 建筑物改修工程 | 请负代金合计额100万日圆以上（含税） |
| 工作物之拆除・改修工程 | 请负代金合计额100万日圆以上（含税） |

报告原则上透过「石绵事前调查结果报告系统」电子进行。此系统以一次操作即送达都道府县等（大气污染防止法窗口）与劳动基准监督署（石绵障害予防规则窗口）双方。负报告义务者，为承揽工程之元请业者或自主施工者，于工程着手前报告。发注者（屋主）本人并非报告者，惟发注者宜事先确认委托对象是否具备由有资格者事前调查并报告之体制。又，若达上述规模，不问石绵有无，皆须报告事前调查结果。

## 拆除时重叠之其他届出（建设回收法・劳动安全卫生法）为何？

拆除工程中，与石绵手续并行，尚重叠他法之届出・手续。

- **建设回收法第10条之届出**：建筑物拆除达楼地板面积合计80㎡以上等一定规模以上之工程（对象建设工事），发注者或自主施工者须于工程着手日之7日前，向都道府县知事届出分别拆除等之计画。怠于届出者，处20万日圆以下罚金。
- **拆除业者一方之制度**：承揽工程一方，依请负代金须有解体工事业登录或建设业许可（解体工事业）。其切分见[解体工事业之登录与建设业许可有何不同？](https://luck428.com/legal/column/kaitai-koji-gyo-touroku-kensetsu-kyoka-chigai)。
- **依劳动安全卫生法之体制**：对含石绵建材进行除去・拆除之作业，须选任石绵作业主任者（石绵作业主任者技能讲习之修毕者），并对作业员施以特别教育。劳灾保险・特别教育等劳务之体制建置，由与四叶行政书士事务所别事业体之社会保险劳务士（四叶社会保险劳务士事务所），以独立的事业体个别签约办理。
- **瓦砾类之处理**：拆除所生之瓦砾类为产业废弃物，收集运搬・处分由受许可业者为之。许可之取得方式见[产业废弃物收集运搬业许可如何取得？](https://luck428.com/legal/column/sanpai-shushu-unpan-kyoka-torikata)。

若为继承之老旧建物之拆除，拆除前后亦涉及继承登记（司法书士）。继承不动产名义变更之流程见[继承登记如何进行？](https://luck428.com/legal/column/souzoku-touki-nagare)；整地出售或连同建物出售之窗口，为与四叶行政书士事务所别事业体之[不动产之继承・出售窗口](https://luck428.com/souzoku)。

## 违反时将如何？（罚则・工程之停止）

怠于石绵手续，恐成罚则对象。

| 违反类型（大气污染防止法） | 罚则之例 |
| --- | --- |
| 不报告事前调查结果、或为虚伪报告 | 30万日圆以下罚金 |
| 违反伴随隔离等措施之特定粉尘排出等作业之作业基准 | 3月以下徒刑或30万日圆以下罚金（直接罚） |

作业基准违反之直接罚，系于2021年（令和3年）4月1日之修正设置。怠于建设回收法第10条之届出者，亦有依该法之20万日圆以下罚金。除罚则外，若未适正调查・报告・作业，恐招致行政之指导或作业中止，成为工程整体延迟及追加费用之原因。故于发注阶段拟定手续之展望甚为重要。

## 调查・报告・工程・劳务分别委托何人（有资格调查者・行政书士・专业业者・社劳士）？

涉及石绵之拆除・改修，依领域分工如下。

- 石绵含有建材之事前调查・判定（必要时分析）→ 建筑物石绵含有建材调查者等有资格之调查者・分析机关
- 事前调查结果之报告、建设回收法第10条之届出等之文件制作・代理 → 四叶行政书士事务所（行政书士）
- 石绵之除去・拆除工程（石绵作业主任者之选任）→ 受登录・许可之专业拆除业者
- 劳灾保险・特别教育等劳务 → 社会保险劳务士（四叶社会保险劳务士事务所）
- 继承登记・公司设立等之登记 → 司法书士
- 建物灭失登记（表题部）→ 土地家屋调查士（申请对象为法务局）
- 让渡所得・设备投资等税务 → 税理士
- 整地・连同建物之土地出售或物件手配 → 四叶不动产株式会社（宅地建物交易业者）

四叶行政书士事务所与四叶不动产株式会社为别事业体。含有资格之调查者・社会保险劳务士・司法书士・土地家屋调查士・税理士之各领域，均以与各资格者作为独立的事业体个别签约为前提，本事务所不收取介绍费。受任流程见[受任流程](https://luck428.com/legal/nagare)；费用见[报酬额表](https://luck428.com/legal/ryokin)；取扱业务之全貌见[许认可・各种申请服务](https://luck428.com/legal/services)。

## 常见问题

**Q. 已知无石绵之建物，也须事前调查或报告吗？**
A. 事前调查为确认无石绵亦原则上需要。进行书面调查与目视调查，无法判断之建材以分析调查等确认。在此之上，若达建筑物拆除80㎡以上，或改修、工作物请负代金100万日圆以上（含税）等规模，不问石绵有无，皆有报告事前调查结果之义务。

**Q. 事前调查或报告可委托行政书士吗？**
A. 调查石绵有无之事前调查本身，自2023年（令和5年）10月1日起，属建筑物石绵含有建材调查者等有资格者进行之领域，行政书士不代行。行政书士担任以调查结果为前提之报告及建设回收法第10条之届出等之文件制作・代理。调查系与有资格之调查者以独立的事业体个别签约后进行。本事务所不收取介绍费。

**Q. 报告由发注者（屋主）或工程业者何者为之？**
A. 大气污染防止法上，负事前调查结果报告义务者，为承揽工程之元请业者或自主施工者。发注者本人并非报告者。惟发注者宜于签约前确认委托对象是否由有资格者事前调查，并透过石绵事前调查结果报告系统适切报告之体制。

**Q. 拆除继承之老旧建物，须先办继承登记吗？**
A. 建物之拆除或出售之前提，涉及名义及权利关系之整理。继承不动产之名义变更（继承登记）为司法书士之业务，且继承登记自2024年（令和6年）4月1日起义务化。石绵之调查・拆除・登记・出售之顺序，请与有资格之调查者・司法书士・不动产各担任者个别签约后个别确认。
