**先讲重点：**归化是外国籍者提出申请、取得日本国籍的制度，需要法务大臣的许可（国籍法第4条）。普通归化的要件有六项：在日本连续有住所五年以上；年满18岁且依本国法有行为能力；素行善良；能够维持生计；原则上因归化而丧失原有国籍（防止双重国籍）；遵守宪法（国籍法第5条）。日本国民的配偶、子女等有放宽要件的简易归化（国籍法第6条、第7条、第8条）。归化许可申请书类的制作与咨询由行政书士负责，但申请原则上须由本人亲自到法务局、地方法务局出头办理，行政书士不能代替本人申请归化。国籍丧失、本国户籍或公证书的取得由本国的公证机关、领事馆办理；在留资格手续是入管的手续；涉及继承、登记时由司法书士或税理士负责——各自以独立的事业体、分别签约为前提分工。继承所得不动产的出售、管理，由另一事业体四叶不动产股份有限公司负责。本文属一般性信息提供，不保证个别归化的可否或要件的充足。最终准驳由法务大臣判断。本事务所不收取介绍费。

## 归化与永住有何不同，该如何选择？

归化与永住常被混淆，但是根本不同的制度。归化是取得日本国籍、成为日本人的制度（依据国籍法，窗口为法务局）；永住则是保有外国籍、取得在留资格之一“永住者”的制度（依据入管法，窗口为出入国在留管理厅）。

| 项目 | 归化 | 永住 |
| --- | --- | --- |
| 取得的地位 | 日本国籍（成为日本人） | 保有外国籍、在留资格“永住者” |
| 依据法 | 国籍法 | 出入国管理及难民认定法 |
| 窗口 | 法务局、地方法务局 | 出入国在留管理厅 |
| 原国籍 | 原则丧失（防止双重国籍） | 保留 |
| 选举权等 | 可取得 | 不可取得 |

何者较适合，取决于是否想保留原国籍、如何看待在日本的参政权与身分等个别情况。这是制度差异的说明，最终如何选择由本人决定。关于自在留资格转换的全貌，亦可参见处理外国人经营者在留资格的[外国人经营者的在留资格（经营・管理签证）与公司设立](https://luck428.com/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)。

## 归化的要件（住所、生计、素行、防止双重国籍等）是什么？

普通归化的要件规定于国籍法第5条第1项，共六项。

| 要件 | 内容 |
| --- | --- |
| 住所要件 | 在日本连续有住所五年以上 |
| 能力要件 | 年满18岁，且依本国法有行为能力 |
| 素行要件 | 素行善良（就纳税、守法等综合判断） |
| 生计要件 | 能以本人或与其共同维持生计的配偶、其他亲属的资产、技能维持生计 |
| 防止双重国籍要件 | 为无国籍，或原则上因归化而丧失原有国籍 |
| 遵守宪法要件 | 未曾企图以暴力破坏宪法或依宪法成立的政府等 |

能力要件的年龄自2022年4月1日起由“20岁以上”改为“18岁以上”。防止双重国籍要件另有例外，适用于本人非出于己意而无法丧失国籍的情形（国籍法第5条第2项）。此外，对日本国民的子女、配偶、在日本出生者等，另有放宽住所要件等的简易归化（国籍法第6条、第7条、第8条）。例如日本国民的配偶，可能就婚姻与一定期间居住的组合获得放宽。自己适用哪一条规定，须备齐资料后个别确认。

## 中国大陆、台湾的朋友在本国需要准备哪些书类？

在本国准备的身分关系书类，因各国制度而异。中国大陆没有像日本的户籍制度，因此以公证书证明身分关系；台湾设有户籍制度，因此使用户籍相关书类。

| 出身 | 主要准备的本国侧书类例 |
| --- | --- |
| 中国大陆 | 出生公证书、亲属关系公证书（载明父母、兄弟姊妹、子女等关系者）、证明国籍的书类等。如在日本出生等情形有些不需要 |
| 台湾 | 户籍誊本、除籍誊本、载明婚姻、出生等身分关系的书类等 |

中国不承认双重国籍，定居外国的中国公民自愿取得外国国籍时，自动丧失中国国籍（中华人民共和国国籍法第9条）。台湾（中华民国）则在归化许可之后于本国侧办理国籍丧失等手续。这些书类多半需要日文译本，视提出对象而定，可能要求公证、领事认证或海牙认证（Apostille）。要否因书类与提出对象而异，亦请一并参见处理本国关系书面认证区分的[外国关系书面的认证（Apostille、公证、领事认证）的区分使用](https://luck428.com/legal/column/gaikoku-kankei-shomen-ninsho-apostille-koushou-tsukaiwake)。

## 归化申请的流程与审查中容易卡关之处在哪？

归化许可申请，原则上由本人亲自到管辖住所地的法务局、地方法务局出头办理（未满15岁者由法定代理人代为申请）。先于事前咨询确认必要书类，备齐后受理，其后有面谈与调查，法务大臣许可后于官报告示，自告示日取得日本国籍（国籍法第10条）。

容易卡关之处在于：住所要件“连续”的持续性（长期出国可能被评价为中断）、与素行要件有关的纳税与交通违规、生计要件的说明，以及本国书类的取得与翻译准备。行政书士可协助这些书类的制作、整理，并就何处需补强提供咨询。但要件是否具备的最终判断由法务大臣进行，须本人出头的手续，行政书士不能代替本人办理。归化亦非入管申请取次制度的对象。

## 涉及在留资格、继承、登记时该找谁咨询？

归化前后可能涉及其他制度。各自以独立的事业体、分别签约为前提分工。

- 归化前在留资格的更新、变更 → 出入国在留管理厅的手续（在留手续）。与归化本身的窗口、依据法均不同
- 在本国办理国籍丧失、取得本国户籍或公证书 → 本国的公证机关、领事馆。并非由日本的行政书士代办
- 归化前后发生继承时的继承纠纷或外国法解释 → 律师
- 继承登记等不动产、公司登记 → 司法书士
- 遗产税、所得税等税务 → 税理士
- 继承所得不动产的出售、管理 → 不动产经纪业者（另一事业体四叶不动产股份有限公司）

行政书士负责的是归化许可申请书类的制作、整理，本国书类、翻译文件的整理，交付各专家的资料整理，以及陪同咨询。涉及外国籍的继承准据法，于[继承人在海外居住、外国籍时的手续](https://luck428.com/legal/column/souzoku-kaigai-gaikokuseki)整理。受任流程请见[受任的流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)，承办业务的全貌请见[承办业务](https://luck428.com/legal/services)。亦提供中文（繁体、简体）与英文咨询。本事务所不收取介绍费。

## 常见问题

**Q. 归化后原有国籍会如何？**
A. 因日本原则上不承认双重国籍，归化时原则上丧失原有国籍（防止双重国籍要件）。中国大陆的朋友一般于取得日本国籍时自动丧失中国国籍；台湾的朋友则于归化后在本国侧办理丧失等手续。个别处理依本国制度而定。

**Q. 归化申请能全部交给行政书士吗？**
A. 书类的制作、整理与咨询支援可由行政书士负责，但申请原则上须由本人到法务局、地方法务局出头办理。归化并非入管申请取次制度的对象，行政书士不能代替本人申请。

**Q. 住所要件的五年，中途出国会归零吗？**
A. 由于会审视“连续”的持续性，长期出国等可能被评价为居住中断。中断与否依个别情况判断，故应整理出入境记录事先确认。最终判断由法务大臣进行。

**Q. 行政书士会保证我符合归化要件吗？**
A. 不会。行政书士负责资料整理与咨询支援，但要件是否具备、归化是否准许，由法务大臣判断。本文亦属一般性信息提供，不保证个别许可。
