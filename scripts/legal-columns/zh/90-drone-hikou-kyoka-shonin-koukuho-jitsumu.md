**先讲重点：**在日本以工作为目的飞行无人机（航拍机），要掌握两套制度。一是机体登录（含电池重量100克以上，自2022年6月20日起义务化）；二是在指定空域或以指定方式飞行时所需的飞行许可与批准（航空法第132条之85、第132条之86）。登录与许可、批准是不同的手续，完成登录并不代表就不需要许可。飞行许可与批准申请、机体登录的文书制作与代理，由行政书士负责；无线电相关事项（技术基准适合、无线电台执照）是总务省依电波法办理的另一套手续；事故后的赔偿责任与纠纷由律师负责；业务委托合同的税务由税理士负责——各自以独立的事业体、分别签约为前提分工。办公室或起降场所的租赁、购买，由另一事业体四叶不动产股份有限公司负责。本文属一般性信息提供，不保证特定飞行计划是否属于许可、批准的对象、能否通过审查、何时可以飞行。最终的适格判断与法令解释由有资格者与行政机关进行。本事务所不收取介绍费。

## 用无人机从事业务时，登录与许可、批准有何不同？

“登录”与“飞行许可、批准”是目的不同的两套制度。混淆两者，容易只办其中一项就起飞。

机体登录是替无人机分配登录记号、掌握所有人的制度，自2022年6月20日起义务化。同时，规范对象由200克以上扩大为100克以上（含电池）。已登录的机体须在机体上标示登录记号，原则上并须具备以无线电发送识别信息的功能（Remote ID）。

另一方面，飞行许可与批准，是当飞行落入指定空域（航空法第132条之85）或使用指定飞行方式（同法第132条之86）时，取得国土交通大臣许可、批准的制度。登录是“把机体登记到登录簿上”的入口手续，许可、批准则是“可否那样飞”的手续，角色不同。

| 制度 | 依据 | 用途 |
| --- | --- | --- |
| 机体登录 | 航空法（2020年修法新设、2022年6月20日施行） | 替100克以上机体分配登录记号、掌握所有人；原则搭载Remote ID |
| 飞行许可 | 航空法第132条之85 | 在禁止空域飞行的许可 |
| 飞行批准 | 航空法第132条之86 | 不依指定方式飞行的批准 |

## 哪些飞行（空域、方式）需要许可或批准？

航空法第132条之85规定了不得飞行的空域。大致是：可能影响航空器航行安全的空域（机场周边的进入表面等区域、地表或水面150米以上高度的空域），以及人口或家屋密集地区（人口集中地区）上空。灾害时设定的紧急用务空域也包含在内。在这些空域飞行需要许可。

航空法第132条之86规定了飞行方式。基本规则必须始终遵守：不在酒精等影响下飞行、飞行前确认、与其他航空器或物件的防撞、不以造成他人困扰的方式飞行。在此之上，下列方式飞行需要批准。

| 需要批准的飞行方式 | 内容 |
| --- | --- |
| 夜间飞行 | 日间（日出至日落）以外的飞行 |
| 目视外飞行 | 未以目视持续监视的飞行 |
| 无法确保距离的飞行 | 与人或物件之间无法保持省令所定距离（30米）的飞行 |
| 活动场所上空飞行 | 祭典、庙会等众人聚集的活动场所上空 |
| 危险物运送 | 运送危险物的飞行 |
| 投下物件 | 投下物件的飞行 |

此外，持有技能证明者，在一定条件下飞行取得机体认证的机体时，可省略部分许可、批准（第四级〔Level 4〕飞行制度于2022年12月5日施行）。可否省略，依飞行类别而不同，须个别确认。

## 包括申请与个别申请如何区分使用？

申请分为以特定日期、地点的飞行为对象的个别申请，以及以一定期间、一定范围的飞行整批为对象的包括申请。反复、持续进行航拍或巡检的业者，一般使用整合期间或飞行路线的包括申请。以期间为准的包括申请，最长可涵盖一年。

| 种类 | 适合的用法 |
| --- | --- |
| 个别申请 | 特定日、特定地点的单次飞行 |
| 包括申请（期间） | 反复、持续进行的类似飞行（最长一年） |
| 包括申请（路线） | 不特定飞行路线，在一定范围内反复进行 |

即使是包括申请，活动场所上空、危险物运送、投下物件等高风险飞行，也可能无法整批纳入。可用何种形式，取决于飞行内容，并非一律。

## 申请文书与审查会看哪些重点（飞行手册、技能）？

申请时要提出机体信息、操纵者的飞行经历、知识与技能，以及确保安全的体制（飞行手册）。审查会看机体是否符合安全基准、操纵者是否具备必要的飞行经历与能力、是否订有防止事故的程序。

申请原则上通过线上的无人机信息基础系统（DIPS2.0）进行，须于预定飞行开始日的至少10个开厅日前提出。文书制作，以及为满足要件而整理需补强之处，是行政书士可代理、代办的部分。但飞行本身的安全判断，以及机体、操纵者是否满足要件的实质确认，由业者本人与国土交通省、登录检查机关进行。行政书士无法保证飞行本身的可行性。

## 无线电、保险、事故应对该找谁咨询？

无人机飞行也涉及航空法以外的手续。各自以独立的事业体、分别签约为前提分工。

- 图像传输等所用无线设备的技术基准适合（技适）、无线电台执照 → 依电波法由总务省办理的手续。与本事务所依航空法的许可、批准是不同手续
- 事故发生时的损害赔偿责任、当事人间的纠纷、围绕保险金的争议 → 律师
- 无人机事业的业务委托合同所涉所得税、法人税等税务 → 税理士
- 办公室、仓库、起降场所的租赁或购买 → 不动产经纪业者（另一事业体四叶不动产股份有限公司）

此外，若飞行中造成人员受伤、第三人物件损毁、与航空器碰撞或接近等，须向国土交通大臣报告事故等情形。行政书士负责的是飞行许可、批准申请与机体登录的文书制作、代理，飞行手册的整理，以及交付各专家的资料整理。受任流程请见[受任的流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)，承办业务的全貌请见[承办业务](https://luck428.com/legal/services)。亦提供中文（繁体、简体）与英文咨询。本事务所不收取介绍费。

## 常见问题

**Q. 100克以下的小型无人机，登录与许可都不需要吗？**
A. 100克以下的机体不属于航空法上的无人航空机，因此不在登录以及第132条之85、第132条之86许可、批准的对象范围内。但小型无人机等飞行禁止法或地方条例等其他规范，可能在某些地点适用。请依飞行地点逐一确认。

**Q. 只要办过一次包括申请，就能到处自由飞行吗？**
A. 不行。包括申请仅在其涵盖的空域、方式、期间范围内有效。活动场所上空、危险物运送等高风险飞行可能无法整批纳入，范围外的飞行需另行取得许可、批准。

**Q. 取得资格（技能证明）后，许可、批准就不需要了吗？**
A. 无法一概而论。虽然有“持技能证明者在一定条件下飞行取得机体认证的机体时，可省略部分许可、批准”的机制，但取决于飞行类别与条件。可否省略须个别确认。

**Q. 行政书士能做与不能做的是什么？**
A. 行政书士负责飞行许可、批准申请与机体登录的文书制作、代理，以及飞行手册的整理。无线电技适与无线电台执照是总务省的另一套手续，事故后的赔偿责任与纠纷属律师领域，税务属税理士领域。飞行本身的安全判断与要件充足的实质确认，由业者与行政机关进行。
