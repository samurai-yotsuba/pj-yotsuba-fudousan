**結論（先に要点）**：NPO法人（特定非営利活動法人）は、特定非営利活動促進法（平成10年法律第7号）に基づき、保健・医療・福祉の増進やまちづくりの推進など別表の20分野の活動を行う非営利の法人です。設立には、主たる事務所を置く都道府県の知事（事務所が一の指定都市の区域内だけにあるときはその指定都市の長）＝所轄庁の「設立の認証」が必要です（同法第9条・第10条）。認証は、法令に適合し要件を満たせば認証される「認証主義」で、株式会社のように登記だけで設立できる仕組みとは異なります。申請書には定款や社員のうち10人以上の名簿などを添付し（第10条第1項）、受理後は2週間の縦覧を経て、所轄庁が縦覧期間経過後2か月以内に認証・不認証を決定します（第10条第2項・第12条）。認証の通知を受けたら主たる事務所の所在地で設立の登記をすることでNPO法人は成立します（第13条第1項）。定款作成・設立認証申請書類の作成は行政書士の業務ですが、設立の登記は司法書士、収益事業に対する法人税など税務は税理士、障害福祉・介護サービスなどの指定を伴う場合は別途の指定申請へ、それぞれ独立した事業体として別々にご契約いただく前提で分けて振ります。活動拠点となる物件の売買・賃貸は別事業体の四葉不動産株式会社が担当します。本記事は一般的な情報提供であり、個別の設立の可否や認証を保証するものではありません。当事務所は紹介料を受け取りません。

## NPO法人は株式会社や一般社団法人と何が違う？

NPO法人・株式会社・一般社団法人は、いずれも法人ですが、根拠法・設立の仕組み・活動の目的が異なります。NPO法人は、特定非営利活動促進法に基づき、別表に掲げる20分野のいずれかの活動を、不特定かつ多数のものの利益（公益）の増進に寄与することを目的として行う法人です。

| 項目 | NPO法人 | 株式会社 | 一般社団法人 |
| --- | --- | --- | --- |
| 根拠法 | 特定非営利活動促進法 | 会社法 | 一般社団法人及び一般財団法人に関する法律 |
| 設立の仕組み | 所轄庁の設立認証＋設立登記 | 設立登記のみ（準則主義） | 設立登記のみ（準則主義） |
| 活動分野 | 別表の20分野に限られる | 制限なし | 制限なし |
| 社員（構成員） | 10人以上が必要 | 株主1人でも可 | 社員2人以上 |
| 剰余金の分配 | 構成員へ分配できない | 株主へ配当できる | 社員へ分配できない |

NPO法人は、営利を目的とせず、剰余金を構成員に分配しません。また、宗教の教義を広めることや、政治上の主義を推進・支持・反対すること、特定の公職の候補者・政党を推薦・支持・反対することを主たる目的とすることはできません（同法第2条第2項）。役員のうち報酬を受ける者の数は、役員総数の3分の1以下に抑える必要があります。どの法人格が適するかは活動の内容や資金の集め方で変わり、これは制度の違いの説明です。最終的にどの形を選ぶかはご本人が判断します。医療を目的とする場合の医療法人は仕組みが別で、[医療法人の設立認可の流れと必要書類](/legal/column/iryohojin-setsuritsu-ninka-nagare-shorui)で整理しています。

## 設立の認証はどこ（所轄庁）に申請する？

設立認証の申請先（所轄庁）は、主たる事務所が所在する都道府県の知事です。ただし、その事務所が一の指定都市の区域内のみに所在する場合は、その指定都市の長が所轄庁となります（同法第9条）。都道府県をまたいで事務所を置く場合でも、所轄庁は主たる事務所の場所で決まります。

所轄庁は、設立認証の申請を受理したら、遅滞なくその旨を公告し、または公表するとともに、一定の書類を2週間、公衆の縦覧に供します（同法第10条第2項）。この縦覧期間は、令和3年6月9日施行の改正で、それまでの1か月から2週間に短縮されました。縦覧事項は、所轄庁のインターネットの利用などによって公表される扱いになっています。NPO法人の設立が広く市民に開かれた手続として設計されているのが、この縦覧・公表の趣旨です。

## 定款と申請書類には何が要る？

設立認証の申請には、申請書に次の書類を添付します（同法第10条第1項）。定款は、名称・目的・活動の種類・事務所の所在地・社員の資格・役員・会議・資産・会計・事業年度などを定める、法人の基本ルールです。

| 主な添付書類 | 内容 |
| --- | --- |
| 定款 | 法人の基本規則（目的・名称・活動の種類・社員・役員・会計など） |
| 役員名簿 | 役員の氏名・住所または居所、報酬の有無を記載 |
| 就任承諾書・誓約書の謄本 | 各役員が欠格事由に当たらないことなどを誓約 |
| 住所等を証する書面 | 役員の住所または居所を証する書面 |
| 社員のうち10人以上の者の名簿 | 社員が10人以上いることを示す |
| 確認書 | 宗教・政治・選挙目的の団体でないこと等を確認 |
| 設立趣旨書 | なぜ設立するかの趣旨 |
| 設立についての意思の決定を証する議事録の謄本 | 設立総会の議事録など |
| 事業計画書・活動予算書 | 設立当初の事業年度と翌事業年度の各1通 |

社員（構成員）が10人以上いることは、認証の基準の一つです（同法第12条第1項）。役員は、理事3人以上・監事1人以上が必要です。定款や議事録は、後の登記や税務の届出でも使うため、記載の整合性を最初にそろえておくことが実務では重要になります。定款作成と申請書類の作成・整理は行政書士が支援できます。

## 認証から登記・設立までどれくらいかかる？

流れは、事前相談 → 申請・受理 → 2週間の縦覧 → 所轄庁の認証・不認証の決定 → 認証の通知 → 設立の登記 → 成立、という順序です。所轄庁は、正当な理由がない限り、縦覧期間（2週間）を経過した日から2か月以内に、認証・不認証の決定をして書面で通知します（同法第12条第2項）。所轄庁が条例でより短い期間を定めている場合は、その期間内です。

| 手続 | 目安 | 根拠・留意点 |
| --- | --- | --- |
| 縦覧 | 2週間 | 受理後、遅滞なく公告・縦覧（第10条第2項） |
| 認証・不認証の決定 | 縦覧期間経過後2か月以内 | 条例でより短い期間を定めることがある（第12条第2項） |
| 設立の登記 | 認証の通知があった日から2週間以内 | 登記で法人が成立（第13条第1項） |
| 成立後の届出 | 遅滞なく | 登記事項証明書と財産目録を添えて所轄庁へ届出 |

設立の認証を受けた者が、認証のあった日から6か月を経過しても設立の登記をしないときは、所轄庁は設立の認証を取り消すことができます。全体では、申請から成立まで数か月かかるのが一般的です。具体的な処理期間や必要書類は所轄庁ごとに手引きで定められているため、書く直前に当該所轄庁の最新の案内を確認します。

## 設立登記や税務はそれぞれ誰に頼めばよい？

NPO法人の設立では、複数の専門分野が関わります。それぞれ独立した事業体として別々にご契約いただく前提で分けて振ります。

- 定款作成・設立認証申請書類の作成・整理 → 行政書士
- 設立の登記、成立後の役員変更などの登記 → 司法書士
- 収益事業に対する法人税、消費税、源泉徴収など税務 → 税理士
- 障害福祉サービス・介護サービスなどの指定を伴う場合の指定申請 → 別途の指定申請（[障害福祉サービス（生活介護等）の指定と物件の要件](/legal/column/seikatsu-kaigo-shitei-bukken-yoken)などで整理）
- 事務所・活動拠点となる物件の売買・賃貸 → 宅地建物取引業者（別事業体の四葉不動産株式会社）

NPO法人は、法人税法上の公益法人等として扱われ、収益事業から生じた所得にのみ法人税が課されるのが原則ですが、収益事業に当たるかどうかや申告の要否は個別の判断になるため税理士が担当します。行政書士が担当するのは、定款作成・設立認証申請書類の作成・整理、各専門家へ渡す資料の整理と、相談への同席です。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、対応業務の全体像は[取扱業務](/legal/services)をご覧ください。外国籍の方が役員・社員に含まれる場合の在留資格は[外国人経営者の在留資格（経営・管理ビザ）と会社設立](/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)もあわせてご覧ください。当事務所は紹介料を受け取りません。

## よくある質問

**Q. NPO法人は誰でも設立できますか？社員は何人必要ですか？**
A. 社員（構成員）が10人以上いることが認証の基準の一つです（特定非営利活動促進法第12条第1項）。加えて、役員は理事3人以上・監事1人以上が必要です。営利を目的とせず、宗教・政治・選挙を主たる目的としないことも要件です（第2条第2項）。個別に要件を満たすかは、資料をそろえたうえで確認します。

**Q. 設立の認証申請から成立まで、どのくらいかかりますか？**
A. 受理後に2週間の縦覧があり、その経過後2か月以内に所轄庁が認証・不認証を決定します（第10条第2項・第12条第2項）。認証の通知後、主たる事務所の所在地で設立の登記をすることで成立します（第13条第1項）。全体では申請から成立まで数か月かかるのが一般的で、期間は所轄庁により異なります。

**Q. 認証を受ければ必ずNPO法人になれますか？**
A. いいえ。認証は、法令に適合し要件を満たせば受けられる仕組みですが、認証の通知を受けても、そこから設立の登記をしなければ法人は成立しません。認証のあった日から6か月を経過しても登記をしないと、所轄庁が認証を取り消すことがあります。登記は司法書士が担当します。

**Q. 定款作成から登記・税務まで、まとめて一つの事務所で頼めますか？**
A. 定款作成・設立認証申請書類の作成は行政書士、設立の登記は司法書士、税務は税理士が担当し、それぞれ独立した事業体として別々にご契約いただきます。一つの窓口でご相談を受けて各専門家に整理してお渡しすることはできますが、受任は分かれます。当事務所は紹介料を受け取りません。
