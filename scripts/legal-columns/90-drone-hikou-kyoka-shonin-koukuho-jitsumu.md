**結論（先に要点）**：仕事でドローン（無人航空機）を飛ばすには、大きく分けて二つの制度をおさえます。一つは機体の登録（重さ100グラム以上は2022年6月20日から義務）、もう一つは決められた空域や方法で飛ばすときに要る飛行の許可・承認（航空法第132条の85・第132条の86）です。登録と許可・承認は別の手続で、登録したから許可も要らなくなる、という関係ではありません。飛行許可・承認申請と機体登録の書類作成・代理は行政書士が担当し、無線（技適・無線局免許）は電波法にもとづく総務省の別手続、事故時の賠償責任や紛争は弁護士、業務委託契約にかかる税務は税理士へ、それぞれ独立した事業体として別々にご契約いただく前提で分けて振ります。事務所や離着陸場所の賃貸・購入は別事業体の四葉不動産株式会社が担当します。本記事は一般的な情報提供であり、個別の飛行計画が許可・承認の対象か、審査に通るか、いつ飛ばせるかを保証するものではありません。最終的な適否の判断や法令解釈は資格者・行政機関が行います。当事務所は紹介料を受け取りません。

## 業務でドローンを飛ばすとき、登録と許可・承認は何が違うのか？

「登録」と「飛行の許可・承認」は目的の異なる別々の制度です。混同すると、片方だけ済ませて飛ばしてしまう事故のもとになります。

機体の登録は、無人航空機に登録記号を割り当てて所有者を把握する制度で、2022年6月20日から義務化されました。あわせて規制の対象が重さ200グラム以上から100グラム以上（バッテリーを含む）へ広がっています。登録した機体は登録記号を機体に表示し、識別情報を電波で発信する機能（リモートID）を備えることが原則です。

一方、飛行の許可・承認は、決められた空域（航空法第132条の85）や決められた飛行の方法（同第132条の86）に当たる飛行をするときに、国土交通大臣の許可・承認を得る制度です。登録は「機体を登録簿にのせる」入口の手続、許可・承認は「その飛ばし方をしてよいか」の手続で、役割が違います。

| 制度 | 根拠 | 何のための手続か |
| --- | --- | --- |
| 機体登録 | 航空法（2020年改正で創設・2022年6月20日施行） | 100グラム以上の機体に登録記号を割り当て所有者を把握。リモートID搭載が原則 |
| 飛行の許可 | 航空法第132条の85 | 禁止された空域で飛ばすための許可 |
| 飛行の承認 | 航空法第132条の86 | 定められた方法によらずに飛ばすための承認 |

## 許可・承認が必要になる飛行（空域・方法）はどれか？

航空法第132条の85は、飛ばしてはならない空域を定めています。おおまかには、航空機の航行の安全に影響を及ぼすおそれがある空域（空港周辺の進入表面等の区域や、地表・水面から150メートル以上の高さの空域）と、人または家屋の密集している地域の上空（いわゆる人口集中地区）です。災害時などに設定される緊急用務空域も含まれます。これらで飛ばすには許可が要ります。

航空法第132条の86は、飛行の方法を定めています。飲酒などアルコール等の影響下で飛ばさない、飛行前の確認、他の航空機や物件との衝突予防、他人に迷惑を及ぼす方法で飛ばさない、といった基本ルールは常に守る必要があります。そのうえで、次の方法で飛ばすには承認が要ります。

| 承認が必要な飛行の方法 | 内容 |
| --- | --- |
| 夜間飛行 | 日中（日出から日没まで）以外の飛行 |
| 目視外飛行 | 目視で常時監視しない飛行 |
| 距離の確保できない飛行 | 人または物件との間に国土交通省令で定める距離（30メートル）を保てない飛行 |
| 催し場所上空の飛行 | 祭礼・縁日など多数の人が集まる催し場所の上空 |
| 危険物の輸送 | 危険物を輸送する飛行 |
| 物件の投下 | 物件を投下する飛行 |

なお、機体認証を受けた機体を、技能証明を受けた人が一定の条件で飛ばす場合には、許可・承認の一部が省略される仕組みがあります（レベル4飛行の制度は2022年12月5日施行）。省略できるかは飛行のカテゴリーによって変わるため、個別に確認します。

## 包括申請と個別申請はどう使い分けるのか？

申請には、特定の日時・場所の飛行を対象にする個別申請と、一定期間・一定範囲の飛行をまとめて対象にする包括申請があります。空撮や点検を反復・継続して行う事業者は、期間や飛行経路をまとめた包括申請を使うのが一般的です。期間を定める包括申請は、最長で1年間を対象にできます。

| 区分 | 向いている使い方 |
| --- | --- |
| 個別申請 | 特定の日・特定の場所での単発の飛行 |
| 包括申請（期間） | 同じような飛行を反復・継続して行う場合（最長1年） |
| 包括申請（飛行経路） | 飛行経路を特定せず一定の範囲で反復して行う場合 |

包括申請でも、催し場所上空の飛行や危険物輸送・物件投下など、リスクの高い飛行はまとめての対象にできないことがあります。どの形が使えるかは飛行の内容しだいで、一律ではありません。

## 申請の書類と審査で見られる点は何か（飛行マニュアル・技能）？

申請では、機体の情報、操縦する人の飛行経歴・知識・技能、安全を確保するための体制（飛行マニュアル）などを示します。審査では、機体が安全基準に適合しているか、操縦者が必要な飛行経歴や能力を備えているか、事故を防ぐ手順が定められているかが見られます。

申請は原則としてオンラインのドローン情報基盤システム（DIPS2.0）で行い、飛行開始予定日の少なくとも10開庁日以上前に提出します。書類の作成や、要件を満たすためにどこを補うかの整理は、行政書士が代理・代行できる部分です。ただし、飛行そのものの安全判断や、機体・操縦者が要件を満たすかの実質的な確認は、事業者自身と国土交通省・登録検査機関が行います。行政書士が飛行の可否そのものを保証することはできません。

## 電波・保険・事故対応は誰に相談すればよいのか？

ドローンの飛行には航空法以外の手続も関わります。それぞれ独立した事業体として別々にご契約いただく前提で分けて振ります。

- 映像伝送などに使う無線設備の技術基準適合（技適）・無線局免許 → 電波法にもとづく総務省の手続。当事務所の航空法の許可・承認とは別の手続です
- 事故が起きたときの損害賠償責任・当事者間の紛争・保険金をめぐる争い → 弁護士
- ドローン事業の業務委託契約にかかる所得税・法人税などの税務 → 税理士
- 事務所・倉庫・離着陸場所の賃貸や購入 → 宅地建物取引業者（別事業体の四葉不動産株式会社）

なお、飛行中に人の負傷や第三者の物件の損壊、航空機との衝突・接近などが生じた場合は、国土交通大臣への事故等の報告が義務づけられています。行政書士が担当するのは、飛行許可・承認申請と機体登録の書類作成・代理、飛行マニュアルの整理、各専門家へ渡す資料の整理です。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、対応業務の全体像は[取扱業務](/legal/services)をご覧ください。中国語（繁体字・簡体字）・英語での相談にも対応します。当事務所は紹介料を受け取りません。

## よくある質問

**Q. 100グラム未満の小さなドローンなら登録も許可も要りませんか？**
A. 100グラム未満の機体は航空法上の無人航空機に当たらず、機体登録や第132条の85・第132条の86の許可・承認の対象外です。ただし、小型無人機等飛行禁止法や条例など別の規制が及ぶ場所があります。飛ばす場所ごとに確認が必要です。

**Q. 一度包括申請をすれば、どこでも自由に飛ばせますか？**
A. いいえ。包括申請は対象にした空域・方法・期間の範囲でだけ有効です。催し場所上空や危険物輸送などリスクの高い飛行は包括の対象にできないことがあり、範囲外の飛行には別の許可・承認が要ります。

**Q. 資格（技能証明）を取れば許可・承認は不要になりますか？**
A. 一概にはいえません。機体認証を受けた機体を、技能証明を受けた人が一定の条件で飛ばす場合に許可・承認の一部が省略される仕組みはありますが、飛行のカテゴリーや条件によります。省略できるかは個別に確認します。

**Q. 行政書士に頼めることと頼めないことは何ですか？**
A. 行政書士は、飛行許可・承認申請と機体登録の書類作成・代理、飛行マニュアルの整理を担当します。無線の技適・無線局免許は総務省の別手続、事故時の賠償責任や紛争は弁護士、税務は税理士の領域です。飛行の安全そのものの判断や要件充足の実質確認は事業者と行政機関が行います。
