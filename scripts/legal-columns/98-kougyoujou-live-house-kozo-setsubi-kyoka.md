**結論（先に要点）**：ライブハウスや小劇場を業として常設で経営し、公衆に音楽や演劇を見せ・聞かせる施設は、興行場法（昭和23年法律第137号）上の「興行場」に当たり得ます。この場合、業として経営しようとする者は都道府県知事（保健所を設置する市又は特別区にあっては市長又は区長。以下同じ）の興行場営業許可を受けなければなりません（同法第2条第1項）。換気・照明・防湿・清潔その他入場者の衛生に必要な措置の基準や、設置場所・構造設備に関する公衆衛生上必要な基準は、法律本体ではなく都道府県（保健所設置市・特別区を含む）の条例で定められます（同法第2条第2項・第3条）。本記事は一般的な情報提供で、個別の施設が興行場に当たるか、許可の可否や基準への適合を判断・保証するものではありません。建築基準法上の用途・特殊建築物・検査済証の判断と用途変更の可否は建築士と特定行政庁、消防設備は消防署、深夜に酒類を提供する場合の届出や接待を伴う場合の許可は行政書士、物件の選定・賃貸借は別事業体である不動産業者の領域です。四葉グループの行政書士は、許可・届出の申請支援を独立した事業体として受任します。

## ライブハウス・小劇場に興行場営業許可は必要なのか？

まず「興行場」に当たるかどうかが出発点です。興行場法第1条は、興行場を「映画、演劇、音楽、スポーツ、演芸又は観せ物を、公衆に見せ、又は聞かせる施設」と定義しています。常設のライブハウスや小劇場、ミニシアターは、音楽・演劇・映画を公衆に見せ・聞かせる常設施設ですから、業として経営する場合は興行場に該当し、第2条第1項の許可が必要になるのが原則です。

一方で、飲食店営業が主体で、演奏がその付随的なサービスにとどまるような「ライブバー」などは、興行場に当たらないと整理される場合があります。該当するか否かは施設の規模・常設性・営業実態をふまえて許可権者である自治体が判断するため、企画の早い段階で所在地の保健所に確認することが欠かせません。

| 確認する観点 | 内容 |
| --- | --- |
| 公衆性 | 不特定の客に見せ・聞かせる施設か |
| 常設性 | 常設の施設か、イベントごとの一時的利用か |
| 業として | 反復継続して経営するか |
| 主従関係 | 興行が主か、飲食等の付随か |

同じ建物でも飲食店営業許可や深夜酒類提供飲食店営業の届出が別に必要になることがあり、これらは興行場営業許可とは別の手続です。飲食提供を伴う場合は[飲食店営業許可と保健所の設備基準](/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)もあわせてご確認ください。

## 興行場の構造設備基準は何で決まるのか（法と都道府県条例の関係）？

興行場法本体には、客席の広さや通路幅といった細かい数値基準はほとんど書かれていません。具体的な基準は、各都道府県（保健所設置市・特別区を含む）の条例で定められます。第2条第2項は、設置の場所又は構造設備が条例で定める公衆衛生上必要な基準に適合しないと認めるときは許可を与えないことができるとし、第3条は換気・照明・防湿・清潔その他入場者の衛生に必要な措置を営業者に義務づけ、その基準は都道府県が条例で定めるとしています。

| 項目 | どこで定まるか | よく問題になる点 |
| --- | --- | --- |
| 営業許可の要否・許可権者 | 興行場法（第1条・第2条） | 興行場に当たるかの判断、許可権者が知事か市長・区長か |
| 換気・照明・防湿・清潔の衛生措置 | 都道府県等の条例（第3条） | 具体的な基準値が自治体で異なる |
| 設置場所・構造設備の公衆衛生上の基準 | 都道府県等の条例（第2条第2項） | 便所・洗面・通路などの基準 |

そのため、「他県ではこうだった」という基準はそのままは通用しません。計画地のある自治体の興行場法施行条例・規則を確認し、保健所と事前に相談することが実務の出発点になります。なお、興行場の営業者の地位は、譲渡・相続・合併・分割があったときに承継し届け出る仕組みがあります（同法第2条の2）。

## 建築基準法・消防法の用途と、興行場許可はどう噛み合うのか？

興行場営業許可（衛生の許可）とは別に、建物そのものが建築基準法・消防法の基準を満たしている必要があります。劇場、映画館、演芸場、観覧場、公会堂、集会場その他これらに類するものは、建築基準法別表第一（い）欄（一）項の特殊建築物に当たり、用途地域による建築制限（同法第48条・別表第二）や、特殊建築物としての構造・防火・避難の規定がかかります。

| 法律 | 主な観点 | 担当 |
| --- | --- | --- |
| 建築基準法 | 用途地域での可否、特殊建築物の構造・2方向避難、検査済証、用途変更の要否 | 建築士・特定行政庁 |
| 消防法 | 防火対象物としての消防用設備・防火管理者 | 消防署 |
| 興行場法 | 衛生に必要な措置・公衆衛生上の基準 | 保健所（許可権者） |

劇場・映画館・演芸場・観覧場は、客席部分の床面積によって建てられる用途地域が変わり（例えば客席200㎡未満かどうか）、住居系の用途地域では制限されることが多い類型です。既存の店舗や事務所をライブハウスに変える場合、用途変更の確認申請が必要になることもあります。これらの可否・数値は建築士と特定行政庁、消防用設備は消防署が判断する領域で、行政書士が判断・保証するものではありません。既存建物の遵法性（検査済証の有無など）は賃貸借の前に確認すべき重要な点です。

## 深夜に酒類を出す場合は別の届出が要るのか？

ライブハウスで深夜（午前0時以降）に酒類を提供する営業を営む場合は、興行場営業許可や飲食店営業許可とは別に、風俗営業等の規制及び業務の適正化等に関する法律に基づく深夜における酒類提供飲食店営業の届出が必要です。この届出は、営業を開始する日の10日前までに、営業所の所在地を管轄する公安委員会（警察署経由）に対して行います。

注意したいのは「接待」の有無です。客の隣に座って継続して歓談するなどの接待を伴う場合は、深夜酒類提供の届出ではなく風俗営業（接待飲食等営業・1号営業）の許可の問題になり、深夜0時以降の営業自体が制限されます。ライブ演奏は原則として接待には当たりませんが、営業形態によって判断が変わるため、[深夜酒類提供飲食店営業の届出と要件](/legal/column/shinya-shurui-teikyo-todokede-yoken)もあわせてご確認ください。

| 営業形態 | 必要な手続 |
| --- | --- |
| 酒類提供なし・深夜営業なし | 興行場営業許可（＋飲食があれば飲食店営業許可） |
| 深夜0時以降に酒類提供・接待なし | 上記＋深夜酒類提供飲食店営業の届出 |
| 接待を伴う | 風俗営業の許可（深夜営業は制限） |

## 物件探しから許可取得・開業までの手順は？

手続は衛生・建築・消防・警察の複数にまたがり、順序を誤ると物件を押さえてから使えないと分かる事態が起こります。おおまかな流れは次のとおりですが、名称・順序は自治体により異なります。

| 段階 | 主な内容 |
| --- | --- |
| 物件の一次調査 | 用途地域・特殊建築物・検査済証の有無を建築士と確認 |
| 保健所への事前相談 | 興行場に当たるか、条例の構造設備・衛生基準を確認 |
| 消防への相談 | 消防用設備・防火管理の要否を確認 |
| 内装・設備の設計施工 | 条例基準・避難・防火に適合する設計 |
| 興行場営業許可の申請・検査 | 図面添付、現地検査を経て許可 |
| 深夜酒類提供の届出等 | 酒類提供・深夜営業があれば営業開始10日前までに届出 |

物件の賃貸借契約を結ぶ前に、用途地域・遵法性・原状回復の範囲を確認しておくことが、空振りを防ぐうえで重要です。物件の選定・賃貸借の媒介は、別事業体である四葉不動産株式会社が担当します。

## よくある質問

**Q. 小さなライブバーでも興行場営業許可は必要ですか？**
A. 飲食が主体で演奏が付随的なライブバーは、興行場に当たらないと整理される場合があります。一方、音楽を公衆に聞かせる常設施設として経営するなら興行場に該当し、興行場法第2条第1項の許可が必要です。該当の有無は規模・常設性・営業実態をふまえて自治体が判断するため、所在地の保健所に事前相談してください。

**Q. 興行場の構造設備基準はどの法律を見ればわかりますか？**
A. 興行場法本体には細かい数値基準はほとんどなく、換気・照明・防湿・清潔その他の衛生措置や設置場所・構造設備の公衆衛生上の基準は、各都道府県（保健所設置市・特別区を含む）の条例で定められます（同法第2条第2項・第3条）。計画地のある自治体の施行条例を確認し、保健所に相談することが出発点です。

**Q. 興行場営業許可があれば建築や消防の手続は不要ですか？**
A. いいえ。興行場営業許可は衛生の許可で、建築基準法（用途地域・特殊建築物・用途変更・検査済証）や消防法（消防用設備・防火管理）は別の手続です。劇場・映画館・演芸場・観覧場・集会場は特殊建築物に当たり、建築士・特定行政庁、消防署の判断が必要です。

**Q. 深夜に酒類を提供するには何が要りますか？**
A. 午前0時以降に酒類を提供する営業を営むには、風俗営業等の規制及び業務の適正化等に関する法律に基づく深夜における酒類提供飲食店営業の届出を、営業開始の10日前までに公安委員会（警察署経由）に行います。接待を伴う場合は深夜営業が制限される風俗営業の許可の問題になります。
