**結論（先に要点）**：帰化とは、外国籍の人が申請して日本国籍を取得する制度で、法務大臣の許可が必要です（国籍法第4条）。普通帰化の要件は、引き続き5年以上日本に住所があること、18歳以上で本国法上の行為能力があること、素行が善良であること、生計を営めること、原則として帰化によってそれまでの国籍を失うこと（重国籍防止）、憲法を遵守することの6つです（国籍法第5条）。日本国民の配偶者や子などは要件が緩和される簡易帰化があります（国籍法第6条・第7条・第8条）。帰化許可申請書類の作成・相談は行政書士が担当しますが、申請は本人が法務局・地方法務局に出頭して行うのが原則で、行政書士が本人に代わって帰化を申請することはできません。国籍離脱や本国戸籍・公証書の取得は本国の公証機関・領事館、在留資格の手続は入管の手続、相続・登記が絡む場合は司法書士や税理士へ、それぞれ独立した事業体として別々にご契約いただく前提で分けて振ります。相続した不動産の売却・管理は別事業体の四葉不動産株式会社が担当します。本記事は一般的な情報提供であり、個別の帰化の可否や要件の充足を保証するものではありません。最終的な許否は法務大臣が判断します。当事務所は紹介料を受け取りません。

## 帰化と永住は何が違い、どちらを選ぶべきなのか？

帰化と永住はよく混同されますが、根本的に別の制度です。帰化は日本国籍を取得して日本人になる制度（根拠は国籍法、窓口は法務局）で、永住は外国籍のまま在留資格の一つ「永住者」を得る制度（根拠は入管法、窓口は出入国在留管理庁）です。

| 項目 | 帰化 | 永住 |
| --- | --- | --- |
| 得られる地位 | 日本国籍（日本人になる） | 外国籍のまま在留資格「永住者」 |
| 根拠法 | 国籍法 | 出入国管理及び難民認定法 |
| 窓口 | 法務局・地方法務局 | 出入国在留管理庁 |
| 元の国籍 | 原則として失う（重国籍防止） | 保持する |
| 選挙権など | 得られる | 得られない |

どちらが適するかは、元の国籍を残したいか、日本での参政権や身分をどう考えるかなど個々の事情で変わります。これは制度の違いの説明であり、どちらを選ぶべきかの最終判断は本人が行います。在留資格からの切替の全体像は、外国人経営者の在留資格を扱う[外国人経営者の在留資格（経営・管理ビザ）と会社設立](/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)もあわせてご覧ください。

## 帰化の要件（住所・生計・素行・重国籍防止など）は何か？

普通帰化の要件は国籍法第5条第1項に定められています。次の6つです。

| 要件 | 内容 |
| --- | --- |
| 住所要件 | 引き続き5年以上、日本に住所を有すること |
| 能力要件 | 18歳以上で、本国法によって行為能力を有すること |
| 素行要件 | 素行が善良であること（納税・法令遵守などを総合的に判断） |
| 生計要件 | 自己または生計を一にする配偶者その他の親族の資産・技能によって生計を営むことができること |
| 重国籍防止要件 | 無国籍であるか、原則として帰化によってそれまでの国籍を失うべきこと |
| 憲法遵守要件 | 憲法またはその下に成立した政府を暴力で破壊することを企てるなどしていないこと |

能力要件の年齢は、2022年4月1日から「20歳以上」が「18歳以上」に変わりました。重国籍防止要件には、本人の意思にかかわらず国籍を失うことができない場合の例外もあります（国籍法第5条第2項）。また、日本国民の子や配偶者、日本で生まれた人などには、住所要件などを緩和する簡易帰化があります（国籍法第6条・第7条・第8条）。たとえば日本国民の配偶者は、婚姻と一定期間の居住を組み合わせた緩和が受けられる場合があります。個別に自分がどの規定に当たるかは、資料をそろえたうえで確認します。

## 中国大陸・台湾の方が本国側で用意する書類は何か？

本国で用意する身分関係の書類は、国によって仕組みが違います。中国大陸には日本のような戸籍制度がないため、公証書で身分関係を証明します。台湾には戸籍制度があるため、戸籍関係の書類を用います。

| 出身 | 主に用意する本国側の書類の例 |
| --- | --- |
| 中国大陸 | 出生公証書、親族関係公証書（親・兄弟姉妹・子などの関係を示すもの）、国籍を証する書類など。日本で生まれた場合など不要なものもある |
| 台湾 | 戸籍謄本、除籍謄本、婚姻・出生などの身分関係を示す書類など |

中国は二重国籍を認めておらず、外国に定住する中国公民が自らの意思で外国籍を取得したときは中国国籍を自動的に失うとされています（中華人民共和国国籍法第9条）。台湾（中華民国）は、帰化許可の後に本国側で国籍喪失などの手続を行う扱いです。これらの書類には日本語訳が必要になることが多く、提出先によっては公証・領事認証・アポスティーユを求められます。要否は書類と提出先ごとに異なるため、本国関係書面の認証の使い分けを扱う[外国関係書面の認証（アポスティーユ・公証・領事認証）の使い分け](/legal/column/gaikoku-kankei-shomen-ninsho-apostille-koushou-tsukaiwake)もあわせて確認してください。

## 帰化申請の流れと審査でつまずきやすい点はどこか？

帰化許可申請は、住所地を管轄する法務局・地方法務局に、原則として本人が出頭して行います（15歳未満は法定代理人が代わって申請します）。事前相談で必要書類を確認し、書類をそろえてから受付、その後に面接や調査があり、法務大臣が許可すると官報に告示され、告示の日から日本国籍を取得します（国籍法第10条）。

つまずきやすいのは、住所要件の「引き続き」の継続性（長期の出国で途切れる場合がある）、素行要件にかかわる納税や交通違反、生計要件の説明、本国書類の取得と翻訳の準備です。行政書士は、これらの書類の作成・整理と、どこを補えばよいかの相談を支援できます。ただし、要件を満たすかどうかの最終的な判断は法務大臣が行い、本人の出頭が必要な手続を行政書士が代わって行うことはできません。帰化は入管の申請取次制度の対象でもありません。

## 在留資格・相続・登記が絡む場合は誰に相談すればよいのか？

帰化の前後には、他の制度が関わることがあります。それぞれ独立した事業体として別々にご契約いただく前提で分けて振ります。

- 帰化前の在留資格の更新・変更 → 出入国在留管理庁の手続（在留手続）。帰化そのものとは窓口も根拠法も別です
- 本国での国籍離脱・喪失、本国戸籍や公証書の取得 → 本国の公証機関・領事館。日本の行政書士が代わって行うものではありません
- 帰化前後に相続が生じた場合の相続争いや外国法の解釈 → 弁護士
- 相続登記など不動産・会社の登記 → 司法書士
- 相続税・所得税など税務 → 税理士
- 相続した不動産の売却・管理 → 宅地建物取引業者（別事業体の四葉不動産株式会社）

行政書士が担当するのは、帰化許可申請書類の作成・整理、本国書類・翻訳文書の整理、各専門家へ渡す資料の整理と、相談への同席です。外国籍が絡む相続の準拠法は[相続人が海外在住・外国籍の場合の手続](/legal/column/souzoku-kaigai-gaikokuseki)で整理しています。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、対応業務の全体像は[取扱業務](/legal/services)をご覧ください。中国語（繁体字・簡体字）・英語での相談にも対応します。当事務所は紹介料を受け取りません。

## よくある質問

**Q. 帰化すると元の国籍はどうなりますか？**
A. 日本は原則として重国籍を認めていないため、帰化により、それまでの国籍を失うのが原則です（重国籍防止要件）。中国大陸の方は日本国籍取得により中国国籍を自動的に失うとされ、台湾の方は帰化後に本国側で喪失などの手続を行う扱いです。個別の取扱いは本国の制度によります。

**Q. 帰化の申請を行政書士に全部任せられますか？**
A. 書類の作成・整理と相談の支援は行政書士が担当できますが、申請は原則として本人が法務局・地方法務局に出頭して行います。帰化は入管の申請取次制度の対象ではなく、行政書士が本人に代わって申請することはできません。

**Q. 住所要件の5年は、途中で海外に行くとリセットされますか？**
A. 「引き続き」の継続性が問われるため、長期の出国などで居住が途切れたと評価される場合があります。どの程度で途切れるかは個別の事情で判断されるため、出入国の記録を整理して事前に確認します。最終的な判断は法務大臣が行います。

**Q. 帰化の要件を満たしているか、行政書士が保証してくれますか？**
A. できません。行政書士は資料の整理と相談支援を担当しますが、要件の充足や帰化の許否は法務大臣が判断します。本記事も一般的な情報提供であり、個別の許可を保証するものではありません。
