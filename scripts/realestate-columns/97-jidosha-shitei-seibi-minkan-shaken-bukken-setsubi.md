**結論（先に要点）**：民間車検場（指定自動車整備事業、道路運送車両法第94条の2）にできる物件は、①まず認証工場の要件を満たすこと②それに加えて完成検査場（検査ラインが取れる長さ・天井高）が取れる敷地か③ブレーキテスタ等の検査用機械器具を据えられる床・電源か、の3点で決まります。指定は地方運輸局長が行い、自動車検査員の選任も要ります。いずれも物件を契約する前に見当をつけられます。

整備した車を運輸支局の車検場へ持ち込まず、自社の工場内で検査（完成検査）まで済ませられるのが「民間車検場」です。正式には指定自動車整備事業といい、地方運輸局長の指定を受けた工場だけが保安基準適合証を交付できます。指定は「認証工場であること」を土台に、検査の設備・人・場所がそろってはじめて下ります。「認証工場の物件を借りたあとで指定を目指したら、完成検査場を置く奥行きが足りなかった」——これは介護事業所やクリニックで起きる手戻りと同じ構造です。本記事は、東京で自動車整備工場を開業・拡張し、いずれ自社で車検まで行いたい事業者の方と、整備工場向けの物件を扱う不動産の担当者に向けて、契約前に確認できることを順に並べたものです。可否の最終確認は、営業所を管轄する地方運輸局・運輸支局の窓口で行います。

## 民間車検場（指定整備工場）と認証工場は何が違いますか？

認証工場は「整備できる」工場、指定工場（民間車検場）は「整備に加えて検査まで自社でできる」工場です。物件・設備・人の要件が一段重くなります。

認証工場（道路運送車両法第78条）は、分解整備・電子制御装置整備を行うために地方運輸局長の認証を受けた工場で、整備した車は運輸支局の車検場へ持ち込んで検査を受けます。これに対し指定自動車整備事業（同法第94条の2）は、**認証工場のうち、検査の設備と自動車検査員を備え、地方運輸局長の「指定」を受けた工場**です。指定工場では自動車検査員が保安基準への適合を検査し、適合すれば保安基準適合証・保安基準適合標章を交付できます。持ち込みを省ける代わりに、物件・設備・人の負担が増えます。

| 区分 | 根拠 | できること | 物件・人の要件 |
|---|---|---|---|
| 認証工場 | 第78条（地方運輸局長の認証） | 分解整備・電子制御装置整備 | 作業場・点検作業場・部品整備作業場・車両置場、整備主任者ほか |
| 指定工場（民間車検場） | 第94条の2（地方運輸局長の指定） | 上に加えて完成検査・保安基準適合証の交付 | 認証工場の要件＋完成検査場・検査用機械器具・自動車検査員の選任 |

つまり順序は「まず認証工場、次に指定工場」です。**指定は認証の上に積む制度**なので、認証工場としての物件要件は先に押さえる必要があります。認証工場そのものの物件要件（作業場の面積・天井高・用途地域）は[「自動車整備工場（特定整備の認証工場）に使える物件の要件は？」](/column/jidosha-tokutei-seibi-ninsho-koujou-bukken-youken)に整理しました。事業用物件全般は[投資用・事業用不動産](/toushi)、事務所と会社設立の関係は[会社設立とオフィス選び](/office)をご覧ください。

## 指定を受けるには物件・敷地にどんな広さが要りますか？

認証工場に必要な作業場に加えて、**完成検査場（検査ライン）を通せる長さと天井高**が要ります。テスタ上で実際に車を走行・停止・測定するため、まっすぐな検査レーンの奥行きが鍵になります。

指定自動車整備事業の設備・技術・管理組織の基準は、道路運送車両法第94条の2と指定自動車整備事業規則（運輸省令）に定められています。具体的な数値は対象とする自動車の種類（普通・小型・大型など）や地方運輸局の運用で変わりますが、物件を見るときの勘どころは次のとおりです。

| 見る場所 | 何を確認するか |
|---|---|
| 完成検査場（検査ライン） | ブレーキテスタ・スピードメータテスタ・サイドスリップテスタ・ヘッドライトテスタ等を直線に並べ、車を走らせて測れる奥行きと幅が取れるか |
| 天井高 | リフトアップやヘッドライト測定ができる高さがあるか。対象車が大型だとさらに高さが要る |
| 床 | テスタ（特にブレーキテスタ）を埋め込み固定でき、走行時の荷重・振動に耐える平滑な舗装か |
| 電源・ピット | 三相200Vの動力、テスタやコンプレッサーの電源、ピットを設けられるか |
| 前面道路・出入口 | 検査を受ける車が支障なく出入りできる間口・幅員か |

数値は指定自動車整備事業規則の基準と運輸局の運用で定まるため、**物件段階では「検査ラインを一直線に取れる奥行きがあるか」を先に見る**のが実際的です。認証工場としての作業場が取れても、その先に検査ラインを足す余地がないと指定は難しくなります。用途地域・容積率が敷地の値づけにどう効くかは[「日本の土地値はなぜ『容積率』で変わるのか」](/column/yosekiritsu-hosei-tochine)に整理しています。

## 必要な検査機器・設備には何がありますか？

完成検査に使う検査用機械器具（テスタ類）と、検査の記録・管理の仕組みが要ります。認証工場の整備機械とは別に、検査のための機器を据える前提で物件を見ます。

指定自動車整備事業規則は、完成検査を行うための検査用機械器具の備付けを求めています。一般に次のような機器が挙げられますが、対象車種や運用で品目は変わります。

| 区分 | 主な機器・設備（例） |
|---|---|
| 走行・制動の検査 | ブレーキテスタ、スピードメータテスタ、サイドスリップテスタ |
| 灯火・排出ガスの検査 | ヘッドライトテスタ、CO・HC等の排出ガステスタ |
| 寸法・重量・下回り | 車両重量計、ジャッキ・リフト、下回りを点検できる設備 |
| 記録・管理 | 検査結果の記録、自動車検査員による検査の管理組織 |

これらは重量物・埋め込み据付けになるものが多く、**あとから床を斫って設置できるか**が物件選びに直結します。賃貸なら、テスタの据付け・床の斫り・動力の引き込みを原状回復の範囲とあわせて契約前に合意しておきます。賃貸借契約書のどこを読むかは[「賃貸借契約書、どこを読めばいいか」](/column/chintaishaku-keiyakusho-doko-wo-yomu)に整理しました。機器の品目・基準の細部は運輸支局にご確認ください。

## 用途地域や建築基準法で気をつける点はありますか？

あります。指定工場も自動車修理工場として建築基準法の用途地域制限を受け、**完成検査場を足すことで作業場の床面積が増え、用途地域の上限を超えやすくなる**点に注意が要ります。

自動車修理工場は建築基準法（昭和25年法律第201号）第48条と別表第二により、作業場の床面積の合計に応じて建てられる用途地域が分かれます。国土交通省の用途制限の整理によれば、おおむね次のとおりです。

| 用途地域 | 自動車修理工場の可否（作業場の床面積の合計） |
|---|---|
| 低層・中高層住専、田園住居、第一種・第二種住居 | 建てられない |
| 準住居地域 | 150㎡以下なら可 |
| 近隣商業・商業・準工業地域 | 300㎡以下なら可 |
| 工業地域・工業専用地域 | 面積の制限なし |

指定工場は認証工場に完成検査場を足すぶん、作業場の床面積が大きくなりがちです。準住居（150㎡以下）や近隣商業・準工業（300㎡以下）では上限を超えやすく、**準工業・工業系の区域が向く**のはこのためです。さらに、指定を受けるには認証工場として使える建物であること（検査済証・用途変更の確認申請の履歴）も前提になります。周辺環境（騒音・検査時の空ぶかし・出入りする車列）で近隣とぶつからないかも契約前の論点です。運送業の営業所・車庫の当たりの付け方は[「運送業を始めるなら、営業所と車庫の物件はどこを見て選ぶか」](/column/unsou-eigyosho-shako-bukken-yoken)に書きました。

## 指定の申請や関連手続きは、それぞれ誰に頼めばよいですか？

物件（不動産）、指定・認証の申請（行政手続）、建築確認、登記、税務は、担い手が分かれます。指定は認証を前提にするため、順序を踏んで進めます。

指定自動車整備事業の指定は、認証工場であることが土台です。人（整備主任者・自動車検査員）と検査設備が基準を満たしているかは申請の中で審査されるため、**先に物件だけを決めてしまうと、完成検査場の余地や床・天井が足りずやり直しになる**——だからこそ上の論点を契約前に並べます。指定の前提となる認証申請の人的要件・書類・運輸支局での手続きは、対になる記事[自動車の特定整備（分解整備）の認証申請は、どんな要件でどう進める？](/legal/column/jidosha-tokutei-seibi-ninsho-shinsei-nagare-youken)（行政書士側）に整理しています。

| 事項 | 担い手・窓口 |
|---|---|
| 物件の調査・媒介、作業場・完成検査場の賃貸借・売買契約 | 宅地建物取引業者 |
| 特定整備事業の認証申請・指定自動車整備事業の指定申請、官公署へ提出する書類の作成 | 行政書士 |
| 完成検査場に係る建築確認・用途変更の申請、増築の設計 | 建築士・行政書士 |
| 自動車検査員の選任・教習の手続き | 事業者（運輸支局へ） |
| 会社を設立するときの設立登記、所有権・賃貸借の登記 | 司法書士 |
| 会計・税務 | 税理士 |
| 賃料・原状回復・立退きなどの紛争 | 弁護士 |

## よくある質問

**Q. 民間車検場（指定工場）の指定は、誰が行うのですか？**
A. 地方運輸局長が行います（道路運送車両法第94条の2）。指定を受けられるのは、同法第78条の認証を受けた事業場のうち、指定自動車整備事業規則の定める設備・技術・管理組織を備え、自動車検査員を選任して検査をさせると認められる工場です。指定工場では自動車検査員が保安基準への適合を検査し、適合すれば保安基準適合証・保安基準適合標章を交付できます。具体的な基準は運輸支局にご確認ください。

**Q. 認証工場を先に開いてから、あとで指定を目指せますか？**
A. はい、それが一般的な順序です。指定は認証工場であることを前提にするため、まず認証工場として物件を選び、事業が育ってから完成検査場・検査用機械器具・自動車検査員をそろえて指定を申請します。ただし後から完成検査場を足せるだけの敷地・天井高・床の余地がないと指定は難しくなるため、**将来指定を目指すなら物件を選ぶ段階で検査ラインの余地を見ておく**と手戻りが減ります。

**Q. 完成検査場には、どれくらいの広さ・天井高が要りますか？**
A. 検査用機械器具（ブレーキテスタ・スピードメータテスタ・サイドスリップテスタ・ヘッドライトテスタ・排出ガステスタ等）を直線に並べ、車を走らせて測れる奥行きと、リフトアップ・灯火測定ができる天井高が要ります。具体的な数値は対象とする自動車の種類（普通・小型・大型）や地方運輸局の運用、指定自動車整備事業規則の基準で変わります。物件段階では「検査ラインを一直線に取れる奥行きがあるか」を先に見て、詳細は運輸支局にご確認ください。

**Q. 賃貸物件でも民間車検場にできますか？**
A. 可能ですが、テスタの埋め込み据付け・床の斫り・動力（三相200V）の引き込み・ピットの設置ができるか、完成検査場を足せる奥行きがあるか、使用目的に「自動車整備（特定整備）」が入っているかを契約前に確かめます。これらを契約後に「不可」と分かると、指定の設計ごとやり直しになります。原状回復と造作の範囲を契約前に書面で合意しておくのが安全です。
