**結論（先說重點）**：把日本的中古區分大樓介紹給華語圈買主時，在重要事項說明的一般確認之前該讀的，是管理組合的**營運風險**。具體為四點：①有無長期修繕計畫・何時改定，修繕積立金是否預定調漲或徵收一次金②管理規約的用途限制（禁止住宅宿泊事業＝民泊、寵物、專有部分的用途）③管理費・修繕積立金的滯納（滯納依區分所有法第8條承繼給買主＝特定承繼人）④管理公司的變更・大規模修繕的履歷。這些在重要事項說明中也會作為管理費・修繕積立金・滯納額等成為說明事項（宅地建物取引業法第35條第1項第6號・同法施行規則第16條之2），但專業買主不宜等到簽約前才聽說明，先以資料讀過較安全。重要事項說明與買賣契約由宅建業者（當方），取得後的固定資產稅・都市計畫稅的納稅管理人或申報由稅理士，各自作為獨立的事業體分別承擔。

本文寫給經手日本中古區分大樓的中國大陸・台灣・香港的不動產仲介或買方仲介（專業人士）。它整理的不是重要事項說明的一般確認，而是在契約前讀**管理組合的營運風險**的觀點，依據建物的區分所有等相關法律（區分所有法）・宅地建物取引業法與國土交通省的資料。以繁體字／簡體字閱讀為前提，示明條文與資料的對應。本公司負責日本一側的物件介紹・調查・重要事項說明・仲介；取得後的稅務交由稅理士。本文不保證個別的投資判斷或管理狀態的良否。

## 為何要在重要事項說明之前讀管理規約與長期修繕計畫？

在中古區分大樓，不只是專有部分（住戶），管理組合如何營運整棟建物，會左右取得後的負擔與出場的價值。重要事項說明（宅地建物取引業法第35條）是在契約成立前由宅地建物取引士以書面說明的法定手續，但**專業買主不宜等到簽約前才聽說明，先以資料讀透管理規約・長期修繕計畫・總會議事錄・管理費等的滯納狀況**較安全。

在區分大樓，重要事項說明的對象會加上區分所有建物固有的項目。宅地建物取引業法第35條第1項第6號與同法施行規則第16條之2，把下列事項列為說明事項。

| 說明事項（區分所有建物） | 能得知什麼 |
|---|---|
| 共用部分相關規約的定（含案） | 共用部分的範圍・使用規則 |
| 專有部分用途及其他利用限制相關規約的定 | 民泊・寵物・事務所使用等的可否 |
| 專用使用權相關規約的定 | 停車場・陽台・專用庭的處理 |
| 修繕積立金等相關規約的定與已積立的額 | 積立金的水準・餘額 |
| 通常的管理費用額 | 每月的管理費 |
| 委託管理時的委託對象 | 管理公司 |
| 建物維持修繕的實施狀況紀錄 | 大規模修繕的履歷 |

這些映照的不是「物件本身」，而是「管理組合的營運」。管理規約的基礎在國土交通省的「大樓標準管理規約（單棟型）」，各大樓的規約以此為本製作。重要事項說明的一般確認整理在[把日本的收益物件介紹給華語圈買主之前該讀的重要事項說明要點](https://luck428.com/column/chugokugo-buyer-juyojiko-check-toushi-bukken)，本文聚焦於管理面。

## 長期修繕計畫與修繕積立金的「調漲・一次金」從哪裡看得出來？

長期修繕計畫是估算未來大規模修繕（外牆・屋頂防水・給排水管・電梯等）的時期與費用，並導出所需修繕積立金額的計畫。國土交通省在「長期修繕計畫製作指引」示明其製作的參考。**積立金相對計畫不足時，會導致調漲或徵收一次金，直接關係取得後的負擔。**

契約前該讀的資料與在那裡看的點如下。

| 要讀的資料 | 看的點 |
|---|---|
| 長期修繕計畫書 | 計畫的有無、最近的改定時期、今後的修繕時期與預估費用、積立金未來的調漲預定 |
| 修繕積立金的餘額・會計資料 | 現在的餘額、相對計畫的過不足、有無借款 |
| 總會・理事會的議事錄 | 積立金調漲・徵收一次金的議案・決議，大規模修繕的決定 |
| 重要事項相關調查報告書（管理公司發行） | 管理費・積立金的額、滯納額、修繕計畫的概要 |

**要注意的是，現在的積立金低，未必意味「好物件」。** 積立金被壓得低於實態時，日後可能需要大幅調漲或一次金。取得後的高樓層大樓的修繕積立金與滯納的承繼，[相續的高樓層大樓要賣時](https://luck428.com/column/souzoku-tower-mansion-reiwa6-hyoka-baikyaku)也觸及管理費・修繕積立金的清算。這些資料由本公司向管理公司・賣主取得並整理，亦對應繁體字／簡體字的資料提供。

## 管理規約的禁止民泊・寵物・用途限制如何影響投資？

管理規約會束縛專有部分的使用。華語圈買主在投資上特別想確認的，是**住宅宿泊事業（民泊）的可否**。依住宅宿泊事業法（平成29年法律第65號）的民泊，即使在法律上可以申報經營，**若管理規約定有「禁止住宅宿泊事業」，在該棟建物就不能進行。** 國土交通省的標準管理規約也示明把住宅宿泊事業要允許或禁止定於規約的思路。

| 規約的限制 | 對投資的影響 |
|---|---|
| 住宅宿泊事業（民泊）的可否 | 以民泊營運為前提的投資，若有禁止規約就不成立 |
| 寵物飼養的可否 | 影響出租的招租・入住者層 |
| 專有部分的用途（限住宅・事務所使用的可否） | 若設想事務所・SOHO利用需確認 |
| 專用使用權（停車場等）的處理 | 停車場是否另行契約，使用費由誰負擔 |

規約以區分所有者及議決權的各4分之3以上的總會決議設定・變更・廢止（區分所有法第31條第1項）。**也就是說，現在民泊可，未來的總會決議也可能變成禁止。** 不只看現在的規約，連總會討論的方向也以議事錄確認較安全。若以民泊可否或用途作為投資前提，請在契約前掌握規約的現狀與改定的動向。與當地專業人士合作推進的方式，整理在[與當地專業人士合作經手日本不動產](https://luck428.com/column/chuka-fudosan-pro-kyodo-torihiki)。

## 滯納・管理公司變更・大規模修繕的履歷如何確認？

管理費・修繕積立金的**滯納**，是買主難以看見的風險。區分所有法第7條承認管理組合的先取特權，第8條定有，管理費等的債權**對債務人即區分所有者的特定承繼人（買主等）也可行使**。也就是說，前所有者滯納的管理費・修繕積立金，不論買賣契約如何約定，管理組合都可向買主請求。

| 要確認的項目 | 看什麼 | 確認對象 |
|---|---|---|
| 該住戶的滯納 | 賣主（前所有者）的管理費・修繕積立金滯納額、遲延損害金 | 管理公司・管理組合 |
| 管理組合整體的滯納 | 他戶滯納多時，影響管理組合的財政・修繕 | 管理公司・會計資料 |
| 管理公司・管理方式 | 全部委託或一部委託或自主管理，管理公司的變更履歷 | 管理公司・總會議事錄 |
| 大規模修繕的履歷與預定 | 過去修繕的時期・內容，下次的預定與資金計畫 | 管理公司・長期修繕計畫 |

**留著滯納取得，因會承繼給買主，在價格交涉或清算上不利。** 契約前向管理公司・管理組合照會餘額，必要時在交割時清算的安排要組好。重要事項說明中，管理費・修繕積立金的額與有無滯納也是說明事項（宅地建物取引業法第35條第1項第6號・同法施行規則第16條之2）。這些照會與整理、重要事項說明由本公司作為宅建業者承擔。

## 常見問題

**Q. 管理規約與長期修繕計畫在重要事項說明會被說明，為何要先讀？**
A. 重要事項說明是契約成立前由宅地建物取引士以書面說明的法定手續，管理費・修繕積立金・滯納額是說明事項（宅地建物取引業法第35條第1項第6號・同法施行規則第16條之2）。但對專業買主而言，與其在簽約前聽，不如先讀透管理規約・長期修繕計畫・總會議事錄・會計資料，掌握積立金的調漲預定、滯納與用途限制後再進入價格交涉更有利。資料由本公司向管理公司・賣主取得並整理。

**Q. 我想做民泊，法律上能申報就一定能做嗎？**
A. 不。即使依住宅宿泊事業法（平成29年法律第65號）能申報，若管理規約定有「禁止住宅宿泊事業」，在該棟建物就不能進行。國土交通省的標準管理規約也示明把住宅宿泊事業要允許或禁止定於規約的思路。再者，規約可由區分所有者及議決權的各4分之3以上的總會決議變更（區分所有法第31條第1項），故請在契約前確認現在的規約與總會討論的方向。

**Q. 前所有者滯納的管理費，會變成由買主支付嗎？**
A. 管理組合可向買主（特定承繼人）請求滯納的管理費・修繕積立金（區分所有法第8條）。遲延損害金也可能成為對象。即使買賣契約約定由賣主負擔，就對管理組合的關係而言買主仍可能被請求，故請在契約前向管理公司・管理組合照會滯納額，必要時在交割時清算的安排要組好。重要事項說明中有無滯納也是說明事項。

**Q. 取得後的稅金或申報，日本一側的不動產公司會幫忙處理嗎？**
A. 不會。固定資產稅・都市計畫稅的納稅、出租時的申報・源泉、納稅管理人的申報，是稅理士的業務。本公司負責物件介紹・調查・重要事項說明・仲介，但不計算稅額、也不判斷源泉的要否。稅務請找稅理士，所有權移轉登記請找司法書士，各自作為獨立的事業體直接委託。本公司沒有介紹費・轉介費的往來。
