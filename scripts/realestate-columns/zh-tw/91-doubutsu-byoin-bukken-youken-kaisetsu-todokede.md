**結論（先說重點）**：動物醫院（獸醫師進行診療的診療設施）的物件，最先卡關的是三點——①用途地域能否設「動物醫院」（建築基準法上常比照店舖而非診療所，住居專用地域受限）②能否具備符合獸醫療法構造設備基準（消毒設備・防逃逸・疑似傳染病的隔離；進行手術則內壁與地面須耐水；進行調劑則須冷暗貯藏）的素地③排水・隔音・臭味會不會與鄰居衝突。診療設施開設申報（獸醫療法第3條）是開設後10日內的「事後申報」，但物件不符合基準就無法使用。簽約前確認用途地域・給排水・換氣與出租人意向，就能避免返工。

「先租下物件」再著手動物醫院裝潢，卻發現手術室的地面或排水達不到獸醫療法施行規則的基準而要重做。餐飲店、人的診所會發生的返工，動物醫院同樣會發生。本文寫給在東京要新開動物醫院的獸醫師・法人代表，以及把物件租給他們的人：簽租約前能確認的事，依獸醫療法及其施行規則、建築基準法的條文順序整理。不觸及診療的可否或治療內容。物件能否符合基準的最終確認，在申報對象的都道府縣（家畜保健衛生所等）與特定行政廳的窗口。

## 動物醫院的物件，和普通租賃有何不同？

首先，動物醫院與「人的診所」受不同法律規範。人的診所依醫療法，動物醫院則以**獸醫療法（平成4年法律第46號・平成4年9月1日施行）**為根據。

同法第2條規定，本法所稱「診療設施」，指獸醫師進行飼育動物診療業務的設施。對象飼育動物為牛・馬・綿羊・山羊・豬・犬・貓・雞・鵪鶉及其他政令所定者（**2026年9月27日參照**）。街上的寵物診所也屬此「診療設施」。

| 動物醫院特別有效的點 | 與普通店舖租賃的不同 |
|---|---|
| 構造設備基準 | 消毒設備・防逃逸・隔離、手術室耐水等，物件須具備符合施行規則的素地 |
| 排水・臭味・吠叫 | 對鄰居的影響大幅左右物件選擇，排氣・隔音的作法比餐飲店更關鍵 |
| 申報與物件的關係 | 屬開設後的事後申報，但不符合基準的物件無法使用 |

非診療的動物取扱（美容・寵物旅館）根據法與所管都不同（動物的愛護及管理相關法律的第一種動物取扱業），其物件要件整理於[「寵物美容・寵物店的物件，開業前要確認什麼？」](https://luck428.com/column/doubutsu-toriatsukai-bukken-youken)。本文只針對「獸醫師進行診療的動物醫院」。

## 作為獸醫療法的診療設施，物件須符合的構造・設備為何？

診療設施的構造設備，須符合農林水產省令所定基準（獸醫療法第4條）。具體由**獸醫療法施行規則（平成4年農林水產省令第44號）第2條**規定（**2026年9月27日參照**）。

| 基準（施行規則第2條等） | 物件要確認的素地 |
|---|---|
| 防止飼育動物逃逸的必要設備 | 出入口・窗・區劃的作法；能否加入防逃逸造作 |
| 收容疑似傳染病動物的設備，須有防止感染其他動物的設備 | 可隔離的區劃；空調與區劃分法 |
| 設置消毒設備 | 能洗淨消毒的給排水與作業空間 |
| 進行調劑的設施 | 採光・照明・換氣充分並保持清潔、冷暗貯藏設備、調劑器具的擺放區劃 |
| 進行手術的設施 | 內壁及地面以耐水材料覆蓋，能保持清潔的構造 |
| 設置X光裝置時 | 施行規則第6條〜第6條之11的防護基準；裝置設置另需設置申報 |

**要注意，這些是「為診療」的基準，而建物裡什麼能放在哪，由物件的給排水・換氣・區劃素地決定。** 事後想在單層店舖裝入手術室耐水地面、消毒洗淨設備或隔離區劃，會牽動給排水增設・防水工程・區劃造作的費用與工期。要放X光裝置，能遮蔽的牆厚與配置也依物件而定。

| 簽約前確認 | 為何有效 |
|---|---|
| 給排水的位置與口徑 | 消毒・洗淨・手術室清掃必備；也需污水排出路徑 |
| 換氣・排氣路徑 | 臭味・消毒藥・麻醉的排氣；鄰居糾紛主因 |
| 電力容量 | 手術・檢查機器・空調・給湯需容量 |
| 耐水地牆的造作餘地 | 手術室・處置室「保持清潔」的素地；與回復原狀範圍相關 |
| 隔音餘地 | 吠叫・夜間住院對策；木造・輕量鐵骨易傳聲 |
| 天花板高・樓板荷重 | X光、手術台、住院籠的設置 |

**給排水・換氣・隔音・耐水地面的設計，以及是否需要變更用途確認申請的判斷，屬建築士・設計者的領域。本公司（不動產公司）協助調查物件能否符合這些條件，並在與出租人的條件交涉上伴走。** 不進行設備設計或構造適合的判斷本身。人的診所發生相同返工的理由整理於[「診所的物件，簽約前要確認什麼」](https://luck428.com/column/clinic-bukken-youto-chiiki-kaisetsu-todokede)；治療室的給排水與保健所議題見[「找針灸院・整骨院物件時」](https://luck428.com/column/shinkyu-seikotsuin-bukken-youto-hokenjo-todokede)。

## 用途地域與對鄰居的顧慮，如何影響物件選擇？

與人的診所不同，動物醫院是**臭味・吠叫・排水這些對鄰居的影響大幅左右選擇**，且**用途地域的扱い未必與「診療所」相同**。

第一是用途地域。人的診所在建築基準法別表第二中包含住居專用地域廣受認可，但**動物醫院並非「診療所」，實務上常比照「店舖」或「服務業店舖」**，此時與美容院同樣受用途地域限制。第一種低層住居專用地域難設單獨店舖，第二種低層住居專用地域則有樓地板面積合計150㎡以內等限制。**由於動物醫院在建築基準法上的扱い會因樓地板面積・規模與特定行政廳判斷而變，可否的最終確認須在特定行政廳（建築指導課）窗口進行。** 用途地域與容積率如何影響地價整理於[「日本地價為何隨『容積率』而變」](https://luck428.com/column/yosekiritsu-hosei-tochine)。

第二是**變更用途的確認申請**。將原本的店舖或事務所改為動物醫院，若屬特殊建築物且規模達一定以上，可能需要確認申請。**是否適用屬建築士的判斷**，簽約前先評估可避免返工。

第三是鄰居與租約。吠叫・臭味・夜間住院會透過自治體生活環境條例與鄰居投訴影響醫院存續。集合住宅・雜居大樓的契約書常限制動物飼養・攜入，因此**須在申請前先讀作為動物醫院的使用是否被允許**。契約書該讀哪裡見[「租賃契約書該讀哪裡」](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。**排氣方向、營業・住院時間、隔音作法，以及出租人與鄰居的狀況，最好在簽約前確認。**

## 診療設施開設申報由誰、何時提出？不動產公司做到哪裡？

開設動物醫院屬**事後申報**。獸醫療法第3條規定，開設診療設施者，須自開設之日起**10日內**，向該診療設施所在地管轄的都道府縣知事，申報農林水產省令所定事項；變更申報事項、休止・廢止時亦同（**2026年9月27日參照**）。與人的診所部分採「事前開設許可」不同，動物醫院是開設後再申報。

但這不表示物件可延後。**申報雖在開設後，物件若不符合構造設備基準就無法作為診療設施使用。** 順序是「選擇能符合基準的物件 → 整備裝潢・設備 → 開設 → 10日內申報」。設置X光裝置者，就裝置的設置另需申報（設置之日起10日內）。

| 要做的事 | 承擔者 |
|---|---|
| 物件調查・仲介・租賃契約 | 宅地建物取引業者（本公司） |
| 變更用途確認申請的要否判斷、構造適合、給排水・換氣・隔音・耐水地面的設計 | 建築士・設計者 |
| 診療設施開設申報等向官公署提出的文件之製作 | 行政書士 |
| 診療的可否・治療內容 | 獸醫師（本公司・本事務所不介入） |

診療設施開設申報等向官公署提出的文件之製作，由四葉行政書士事務所承接。**行政窗口・樣式・申報事項・受理運用會變。著手時請直接確認管轄都道府縣（家畜保健衛生所等）的頁面。** 事業用物件全般見[投資用・事業用不動產](https://luck428.com/toushi)，事務所與許認可的關係見[公司設立與辦公室選擇](https://luck428.com/office)。

## 常見問題

**Q. 開動物醫院，租物件前需要許可嗎？**
A. 不是事前許可，而是事後申報。依獸醫療法第3條，開設診療設施者須自開設之日起10日內向管轄的都道府縣知事申報。但即使申報在後，物件若不符合獸醫療法施行規則的構造設備基準就無法使用。應選能符合基準的物件，整備裝潢後再開設・申報。

**Q. 住宅區公寓的一室也能開動物醫院嗎？**
A. 依用途地域與建物而定。動物醫院與人的診所不同，建築基準法上常比照「店舖」或「服務業店舖」，在住居專用地域受限。加上排水・臭味・吠叫對鄰居影響大，租約是否允許作為動物醫院使用與造作也需確認。可否的最終確認請向特定行政廳與出租人進行。

**Q. 有手術室或X光室，物件選擇會怎麼變？**
A. 進行手術的設施依施行規則第2條，內壁及地面須以耐水材料覆蓋並能保持清潔。設置X光裝置須符合施行規則第6條以下的防護基準，並提出裝置設置申報（設置之日起10日內）。這些牽動耐水地面造作、遮蔽牆、給排水、電力容量、樓板荷重，宜在看屋階段確認物件素地。適合與否由建築士判斷。

**Q. 診療設施開設申報可以委託不動產公司嗎？**
A. 不行。向官公署提出的開設申報等文件之製作屬行政書士業務，由四葉行政書士事務所承接。物件的調查・仲介・租賃契約由四葉不動產株式會社承接。兩者為各自獨立的事業體，請各自直接簽約。變更用途確認申請要否與構造適合由建築士判斷，診療內容屬獸醫師的領域。
