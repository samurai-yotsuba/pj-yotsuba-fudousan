**結論（先に要点）**：指定自動車教習所にできる物件は、①用途地域（自動車教習所は第一種住居地域で床面積3,000㎡以下、第二種住居・準住居・近隣商業・商業・準工業・工業・工業専用では制限なしで建てられ、低層住居専用・中高層住居専用・田園住居では建てられません。建築基準法別表第二）②コース（走路）の広さ（指定自動車教習所に関する内閣府令で原則8,000㎡以上、専ら大型・普通自動二輪免許を扱う教習所は3,500㎡以上）③学科教室・待合・休憩室・便所がとれる建物か、の3点でおおむね決まります。物件段階で見当はつけられますが、指定の可否の最終確認は都道府県公安委員会です。

自動車教習所の物件は、介護事業所やクリニックのように「用途地域で詰まる」のではなく、**コース用地という広い土地と、学科教室・技能教習の待合・休憩室という建物を、一つの敷地にまとめて確保できるか**で詰まります。「建物は見つけたがコースを置く土地が足りなかった」「土地はあるが学科教室にできる床がなかった」——これは契約後に気づくと設計ごとやり直しになります。本記事は、新規に指定自動車教習所（またはペーパードライバー向けの届出教習所）を開きたい事業者・投資家の方で、物件探しの段階にある方に向けて、契約前に確認できることを道路交通法・建築基準法・内閣府令の条文から順に並べたものです。可否の最終確認は、所在地を管轄する都道府県公安委員会（警察本部の運転免許関係窓口）で行います。

## 指定自動車教習所にできる物件は、用途地域のどこなら建てられますか？

自動車教習所は建築基準法で用途地域の制限を受ける建築物です。**住居系の低層・中高層の専用地域と田園住居地域では建てられず、第一種住居地域では床面積3,000㎡以下、第二種住居地域から工業専用地域までは制限なし**で建てられます。

自動車教習所は、建築基準法（昭和25年法律第201号）第48条と別表第二により、用途地域ごとに建てられるかどうかが分かれます。コース用地は広く、学科棟・技能待合・車庫などの建物も伴うため、用途地域の確認は土地選びの出発点になります。国土交通省の用途制限の整理によれば、おおむね次のとおりです。

| 用途地域 | 自動車教習所の可否 |
|---|---|
| 第一種・第二種低層住居専用地域、田園住居地域 | 建てられない |
| 第一種・第二種中高層住居専用地域 | 建てられない |
| 第一種住居地域 | 床面積3,000㎡以下なら可 |
| 第二種住居地域、準住居地域 | 制限なしで可 |
| 近隣商業地域、商業地域 | 制限なしで可 |
| 準工業地域、工業地域、工業専用地域 | 制限なしで可 |

コース用地は広いため、まとまった土地が出やすい第二種住居・準住居や準工業・工業系の区域が候補になりやすい一方、第一種住居地域では建物部分の床面積3,000㎡の上限に注意が要ります。市街化調整区域では開発許可（都市計画法第29条）の論点が重なるため、所在する区域区分を先に確認します。用途地域・容積率が土地の値づけにどう効くかは[「日本の土地値はなぜ『容積率』で変わるのか」](/column/yosekiritsu-hosei-tochine)に整理しました。事業用物件全般は[投資用・事業用不動産](/toushi)、事務所と会社設立の関係は[会社設立とオフィス選び](/office)をご覧ください。

## コース（走路）はどれくらいの広さ・形状が要りますか？

指定自動車教習所のコースは、**原則8,000㎡以上**（専ら大型自動二輪・普通自動二輪免許の技能教習・技能検定を行う教習所は3,500㎡以上）の広さが要ります。加えて、周回・幹線・坂道・屈折・曲線・方向変換などの走路を、一団の土地にまとめて取れることが前提です。

指定自動車教習所の物的基準は、道路交通法第99条第1項を受けて「指定自動車教習所に関する内閣府令」に定められています。同府令は、コース（技能教習・技能検定に用いる走路）の面積について、**原則として8,000㎡以上**（専ら大型自動二輪車免許又は普通自動二輪車免許に係る技能教習及び技能検定を行う自動車教習所は3,500㎡以上）とし、普通免許の教習に必要な走路の種類を定めています。物件（土地）を見るときの勘どころは次のとおりです。

| 見る場所 | 何を確認するか |
|---|---|
| コースの面積 | 原則8,000㎡以上（二輪専用は3,500㎡以上）を、一団の土地として確保できるか。緑地・路側帯を含むが、学科教室等の建物の敷地は含めずに考える |
| コースの形状 | 周回・幹線・坂道・屈折・曲線・方向変換等の走路を無理なく配置できる形か。細長い土地・分断された土地では取りにくい |
| 出入口と前面道路 | 教習車・検査車両が支障なく出入りできる間口・幅員か。近隣への騒音・出入りの動線が問題にならないか |
| 高低差・造成 | 坂道コースに使える勾配が取れるか。造成・排水の費用が見合うか |

数値と走路の細目は内閣府令の基準と各都道府県公安委員会の審査基準・運用で定まるため、**土地段階では「8,000㎡（二輪は3,500㎡）の一団の土地に、必要な走路を配置できる形か」を先に見る**のが実際的です。具体の基準は管轄の公安委員会（警察本部）にご確認ください。

## 学科教室・技能教習の待合・休憩室には何㎡・どんな設備が要りますか？

学科教室は、法令上「教習を受ける者の数に応じた適当な大きさ・数」とされ、**一律の床面積（1人あたり何㎡）は法令に定めがありません**。待合所・休憩所・便所などの附属施設とあわせ、建物側で確保できるかを見ます。

「指定自動車教習所に関する内閣府令」は、学科教習を行う教室について「教習を受ける者の数に応じて適当な大きさ及び数」を求めており、座学の受講人数に見合う広さ・室数を確保できることが要件です。したがって、**本記事では学科教室の1人あたり床面積を特定の数値では示しません**（法令が一律の数値を定めていないため）。具体の床面積・室数は各都道府県公安委員会の審査基準と運用で判断されます。建物を見るときに確認できるのは次の点です。

| 見る場所 | 何を確認するか |
|---|---|
| 学科教室 | 想定する1回の受講人数に見合う広さ・室数を取れるか。採光・換気・空調・視聴覚設備を置けるか |
| 技能教習の待合・休憩室 | 教習生が待機・休憩できる室を確保できるか |
| 事務室・受付 | 受付・配車・証明書発行などの事務を行う室を取れるか |
| 便所・附属施設 | 受講人数に見合う便所などの附属施設を設けられるか |

具体の面積・室数は公安委員会の審査基準によるため、**建物段階では「想定受講人数に見合う教室・待合・事務室・便所を無理なく割り付けられる床があるか」を見て、数値の当否は公安委員会に確認する**のが安全です。賃貸借で借りる場合は、用途（自動車教習所）・内装造作・原状回復の範囲を契約前に書面で合意しておきます。賃貸借契約書のどこを読むかは[「賃貸借契約書、どこを読めばいいか」](/column/chintaishaku-keiyakusho-doko-wo-yomu)に整理しました。

## 届出教習所（ペーパードライバー講習）と指定教習所で物件の見方はどう違いますか？

届出教習所は技能検定・卒業証明による技能試験免除の制度を持たないため、**指定教習所のようなコース面積（8,000㎡）の物的基準を一律には求められません**。一方、指定教習所を目指すなら、はじめからコース用地と学科教室・待合・休憩室の両方がとれる物件を選ぶ必要があります。

道路交通法では、自動車教習所を設置する者が公安委員会に届け出る「届出教習所」（第98条第2項）と、その届出をした教習所のうち職員・設備等の基準に適合するものを公安委員会が指定する「指定自動車教習所」（第99条第1項）が区別されます。指定を受けると、技能検定に合格した卒業者は運転免許試験場での技能試験が免除されます（第99条の2）。ペーパードライバー向けの講習などを行う届出教習所は、この技能試験免除の制度を持たないため、物件に求められる水準が変わります。

| 区分 | 根拠 | できること | 物件・用地の見方 |
|---|---|---|---|
| 届出教習所 | 第98条第2項（公安委員会への届出） | 教習・講習（ペーパードライバー講習など）。技能試験の免除は伴わない | コース面積の一律基準は求められない。講習に使える場所・設備を確保できるか |
| 指定自動車教習所 | 第99条第1項（公安委員会の指定） | 上に加えて技能検定・卒業証明による技能試験の免除（第99条の2） | 原則8,000㎡以上のコース＋学科教室・待合・休憩室・事務室・便所をまとめて確保 |

つまり、将来指定を目指すなら、**届出で始めてあとから指定に切り替える場合でも、コース用地を足せる土地と学科教室にできる建物を最初から視野に入れておく**と手戻りが減ります。届出・指定とも、設備・教習の基準は公安委員会の判断によります。

## 契約前に、指定の可否は誰に確認すればよいですか？

物件（不動産）、指定・届出の要件判定と公安委員会への申請、建築確認・用途適合、指導員・検査員の労務、税務は担い手が分かれます。指定の可否そのものは公安委員会が判断します。

指定自動車教習所の指定は、コース・教室などの物的基準に加え、管理者・技能検定員・教習指導員といった人的基準（第99条第1項各号）も審査されます。**先に物件だけを決めてしまうと、コース面積や教室・待合の余地が足りずやり直しになる**——だからこそ上の論点を契約前に並べます。指定の要件判定（人的・物的基準の該当性）と公安委員会への指定申請の書類作成は行政書士の業務です。指定申請側の要件と手続きは、対になる記事[指定自動車教習所の指定を受けるには？道路交通法99条の指定基準と公安委員会への手続](/legal/column/shitei-jidosha-kyoshujo-shitei-youken-koan)（行政書士側）に整理しています。

| 事項 | 担い手・窓口 |
|---|---|
| コース用地・教室棟の物件調査・媒介、売買・賃貸借契約 | 宅地建物取引業者 |
| 指定・届出の要件判定、公安委員会へ提出する指定申請・届出書類の作成 | 行政書士 |
| 建築確認・用途変更の確認申請、コース造成・建物の設計 | 建築士 |
| 指導員・技能検定員・事務職員の雇用・社会保険・労働時間 | 社会保険労務士 |
| 会社設立の登記、所有権・賃貸借の登記 | 司法書士 |
| 譲渡所得・会計・税務 | 税理士 |
| 賃料・原状回復・立退きなどの紛争 | 弁護士 |

## よくある質問

**Q. 指定自動車教習所のコースは、最低どれくらいの面積が要りますか？**
A. 「指定自動車教習所に関する内閣府令」は、コース（技能教習・技能検定に用いる走路）の面積を原則8,000㎡以上（専ら大型自動二輪車免許又は普通自動二輪車免許に係る技能教習及び技能検定を行う自動車教習所は3,500㎡以上）としています。緑地や路側帯は面積に含みますが、学科教室などの建物の敷地は含めずに考えます。走路（周回・幹線・坂道・屈折・曲線・方向変換等）を一団の土地に無理なく配置できる形かも重要です。具体の基準と運用は管轄の都道府県公安委員会にご確認ください。

**Q. 学科教室は1人あたり何㎡と決まっていますか？**
A. 法令は学科教室の1人あたり床面積を一律の数値では定めていません。「指定自動車教習所に関する内閣府令」は、学科教習を行う教室について「教習を受ける者の数に応じて適当な大きさ及び数」を求めています。したがって、想定する受講人数に見合う広さ・室数を確保できるかが論点で、具体の面積・室数は各都道府県公安委員会の審査基準と運用で判断されます。数値の当否は公安委員会にご確認ください。

**Q. 自動車教習所は、どの用途地域なら建てられますか？**
A. 建築基準法別表第二により、第一種住居地域では床面積3,000㎡以下、第二種住居・準住居・近隣商業・商業・準工業・工業・工業専用の各地域では制限なしで建てられます。第一種・第二種低層住居専用地域、第一種・第二種中高層住居専用地域、田園住居地域では建てられません。市街化調整区域では開発許可（都市計画法第29条）の論点が重なるため、所在する区域区分を先に確認してください。

**Q. ペーパードライバー講習だけなら、8,000㎡のコースは要りませんか？**
A. ペーパードライバー講習などを行う「届出教習所」（道路交通法第98条第2項）は、技能検定・卒業証明による技能試験免除の制度を持たないため、指定自動車教習所のようなコース面積の一律基準を求められるわけではありません。ただし、将来「指定」を目指すなら、はじめからコース用地と学科教室・待合・休憩室の両方がとれる物件を選んでおくと手戻りが減ります。届出・指定とも設備・教習の基準は公安委員会の判断によります。
