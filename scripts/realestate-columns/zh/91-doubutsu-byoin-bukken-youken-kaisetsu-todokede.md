**结论（先说要点）**：动物医院（兽医师进行诊疗的诊疗设施）的物件，最先卡关的是三点——①用途地域能否设“动物医院”（建筑基准法上常比照店铺而非诊疗所，住居专用地域受限）②能否具备符合兽医疗法构造设备基准（消毒设备・防逃逸・疑似传染病的隔离；进行手术则内壁与地面须耐水；进行调剂则须冷暗贮藏）的素地③排水・隔音・气味会不会与邻居冲突。诊疗设施开设申报（兽医疗法第3条）是开设后10日内的“事后申报”，但物件不符合基准就无法使用。签约前确认用途地域・给排水・换气与出租人意向，就能避免返工。

“先租下物件”再着手动物医院装修，却发现手术室的地面或排水达不到兽医疗法施行规则的基准而要重做。餐饮店、人的诊所会发生的返工，动物医院同样会发生。本文写给在东京要新开动物医院的兽医师・法人代表，以及把物件租给他们的人：签租约前能确认的事，依兽医疗法及其施行规则、建筑基准法的条文顺序整理。不触及诊疗的可否或治疗内容。物件能否符合基准的最终确认，在申报对象的都道府县（家畜保健卫生所等）与特定行政厅的窗口。

## 动物医院的物件，和普通租赁有何不同？

首先，动物医院与“人的诊所”受不同法律规范。人的诊所依医疗法，动物医院则以**兽医疗法（平成4年法律第46号・平成4年9月1日施行）**为根据。

同法第2条规定，本法所称“诊疗设施”，指兽医师进行饲育动物诊疗业务的设施。对象饲育动物为牛・马・绵羊・山羊・猪・犬・猫・鸡・鹌鹑及其他政令所定者（**2026年9月27日参照**）。街上的宠物诊所也属此“诊疗设施”。

| 动物医院特别有效的点 | 与普通店铺租赁的不同 |
|---|---|
| 构造设备基准 | 消毒设备・防逃逸・隔离、手术室耐水等，物件须具备符合施行规则的素地 |
| 排水・气味・吠叫 | 对邻居的影响大幅左右物件选择，排气・隔音的作法比餐饮店更关键 |
| 申报与物件的关系 | 属开设后的事后申报，但不符合基准的物件无法使用 |

非诊疗的动物取扱（美容・宠物旅馆）根据法与所管都不同（动物的爱护及管理相关法律的第一种动物取扱业），其物件要件整理于[「宠物美容・宠物店的物件，开业前要确认什么？」](https://luck428.com/column/doubutsu-toriatsukai-bukken-youken)。本文只针对“兽医师进行诊疗的动物医院”。

## 作为兽医疗法的诊疗设施，物件须符合的构造・设备为何？

诊疗设施的构造设备，须符合农林水产省令所定基准（兽医疗法第4条）。具体由**兽医疗法施行规则（平成4年农林水产省令第44号）第2条**规定（**2026年9月27日参照**）。

| 基准（施行规则第2条等） | 物件要确认的素地 |
|---|---|
| 防止饲育动物逃逸的必要设备 | 出入口・窗・区划的作法；能否加入防逃逸造作 |
| 收容疑似传染病动物的设备，须有防止感染其他动物的设备 | 可隔离的区划；空调与区划分法 |
| 设置消毒设备 | 能洗净消毒的给排水与作业空间 |
| 进行调剂的设施 | 采光・照明・换气充分并保持清洁、冷暗贮藏设备、调剂器具的摆放区划 |
| 进行手术的设施 | 内壁及地面以耐水材料覆盖，能保持清洁的构造 |
| 设置X光装置时 | 施行规则第6条〜第6条之11的防护基准；装置设置另需设置申报 |

**要注意，这些是“为诊疗”的基准，而建物里什么能放在哪，由物件的给排水・换气・区划素地决定。** 事后想在单层店铺装入手术室耐水地面、消毒洗净设备或隔离区划，会牵动给排水增设・防水工程・区划造作的费用与工期。要放X光装置，能遮蔽的墙厚与配置也依物件而定。

| 签约前确认 | 为何有效 |
|---|---|
| 给排水的位置与口径 | 消毒・洗净・手术室清扫必备；也需污水排出路径 |
| 换气・排气路径 | 气味・消毒药・麻醉的排气；邻居纠纷主因 |
| 电力容量 | 手术・检查机器・空调・给汤需容量 |
| 耐水地墙的造作余地 | 手术室・处置室“保持清洁”的素地；与恢复原状范围相关 |
| 隔音余地 | 吠叫・夜间住院对策；木造・轻量铁骨易传声 |
| 天花板高・楼板荷重 | X光、手术台、住院笼的设置 |

**给排水・换气・隔音・耐水地面的设计，以及是否需要变更用途确认申请的判断，属建筑士・设计者的领域。本公司（不动产公司）协助调查物件能否符合这些条件，并在与出租人的条件交涉上伴走。** 不进行设备设计或构造适合的判断本身。人的诊所发生相同返工的理由整理于[「诊所的物件，签约前要确认什么」](https://luck428.com/column/clinic-bukken-youto-chiiki-kaisetsu-todokede)；治疗室的给排水与保健所议题见[「找针灸院・整骨院物件时」](https://luck428.com/column/shinkyu-seikotsuin-bukken-youto-hokenjo-todokede)。

## 用途地域与对邻居的顾虑，如何影响物件选择？

与人的诊所不同，动物医院是**气味・吠叫・排水这些对邻居的影响大幅左右选择**，且**用途地域的处理未必与“诊疗所”相同**。

第一是用途地域。人的诊所在建筑基准法别表第二中包含住居专用地域广受认可，但**动物医院并非“诊疗所”，实务上常比照“店铺”或“服务业店铺”**，此时与美容院同样受用途地域限制。第一种低层住居专用地域难设单独店铺，第二种低层住居专用地域则有楼地板面积合计150㎡以内等限制。**由于动物医院在建筑基准法上的处理会因楼地板面积・规模与特定行政厅判断而变，可否的最终确认须在特定行政厅（建筑指导课）窗口进行。** 用途地域与容积率如何影响地价整理于[「日本地价为何随『容积率』而变」](https://luck428.com/column/yosekiritsu-hosei-tochine)。

第二是**变更用途的确认申请**。将原本的店铺或事务所改为动物医院，若属特殊建筑物且规模达一定以上，可能需要确认申请。**是否适用属建筑士的判断**，签约前先评估可避免返工。

第三是邻居与租约。吠叫・气味・夜间住院会透过自治体生活环境条例与邻居投诉影响医院存续。集合住宅・杂居大楼的契约书常限制动物饲养・带入，因此**须在申请前先读作为动物医院的使用是否被允许**。契约书该读哪里见[「租赁契约书该读哪里」](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。**排气方向、营业・住院时间、隔音作法，以及出租人与邻居的状况，最好在签约前确认。**

## 诊疗设施开设申报由谁、何时提出？不动产公司做到哪里？

开设动物医院属**事后申报**。兽医疗法第3条规定，开设诊疗设施者，须自开设之日起**10日内**，向该诊疗设施所在地管辖的都道府县知事，申报农林水产省令所定事项；变更申报事项、休止・废止时亦同（**2026年9月27日参照**）。与人的诊所部分采“事前开设许可”不同，动物医院是开设后再申报。

但这不表示物件可延后。**申报虽在开设后，物件若不符合构造设备基准就无法作为诊疗设施使用。** 顺序是“选择能符合基准的物件 → 整备装修・设备 → 开设 → 10日内申报”。设置X光装置者，就装置的设置另需申报（设置之日起10日内）。

| 要做的事 | 承担者 |
|---|---|
| 物件调查・中介・租赁契约 | 宅地建物取引业者（本公司） |
| 变更用途确认申请的要否判断、构造适合、给排水・换气・隔音・耐水地面的设计 | 建筑士・设计者 |
| 诊疗设施开设申报等向官公署提出的文件之制作 | 行政书士 |
| 诊疗的可否・治疗内容 | 兽医师（本公司・本事务所不介入） |

诊疗设施开设申报等向官公署提出的文件之制作，由四叶行政书士事务所承接。**行政窗口・样式・申报事项・受理运用会变。着手时请直接确认管辖都道府县（家畜保健卫生所等）的页面。** 事业用物件全般见[投资用・事业用不动产](https://luck428.com/toushi)，事务所与许认可的关系见[公司设立与办公室选择](https://luck428.com/office)。

## 常见问题

**Q. 开动物医院，租物件前需要许可吗？**
A. 不是事前许可，而是事后申报。依兽医疗法第3条，开设诊疗设施者须自开设之日起10日内向管辖的都道府县知事申报。但即使申报在后，物件若不符合兽医疗法施行规则的构造设备基准就无法使用。应选能符合基准的物件，整备装修后再开设・申报。

**Q. 住宅区公寓的一室也能开动物医院吗？**
A. 依用途地域与建物而定。动物医院与人的诊所不同，建筑基准法上常比照“店铺”或“服务业店铺”，在住居专用地域受限。加上排水・气味・吠叫对邻居影响大，租约是否允许作为动物医院使用与造作也需确认。可否的最终确认请向特定行政厅与出租人进行。

**Q. 有手术室或X光室，物件选择会怎么变？**
A. 进行手术的设施依施行规则第2条，内壁及地面须以耐水材料覆盖并能保持清洁。设置X光装置须符合施行规则第6条以下的防护基准，并提出装置设置申报（设置之日起10日内）。这些牵动耐水地面造作、遮蔽墙、给排水、电力容量、楼板荷重，宜在看房阶段确认物件素地。适合与否由建筑士判断。

**Q. 诊疗设施开设申报可以委托不动产公司吗？**
A. 不行。向官公署提出的开设申报等文件之制作属行政书士业务，由四叶行政书士事务所承接。物件的调查・中介・租赁契约由四叶不动产株式会社承接。两者为各自独立的事业体，请各自直接签约。变更用途确认申请要否与构造适合由建筑士判断，诊疗内容属兽医师的领域。
