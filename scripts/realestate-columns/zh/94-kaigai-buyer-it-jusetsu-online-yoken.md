**结论（先说要点）**：对住在海外的买方线上做重要事项说明（IT重说），在买卖也获得认可。日本国土交通省就不动产买卖的IT重说，自令和3年（2021年）3月30日起正式运用，海外居住者亦为对象。成立要件的支柱是——①宅建士与买方能视认图面等书面・影像并能双向沟通的环境②事前送达重要事项说明书等且买方已收到③在画面上出示宅地建物取引士证并确认买方已视认。重要事项说明书（宅建业法第35条）・37条书面，依令和4年5月18日施行的修正，可经对方同意电子交付。先定好本人确认与代替实印的签名（Sign）证明的步骤是重点。

告诉海外买方“不来日本就无法签约”而让商谈停摆——以时差与语言为由使交易停滞的场面，如今在制度上是可避免的。本文写给向海外居住的外国人・日本人买方出售的卖方・宅建业者，以及在当地仲介的中文圈专业人士：把IT重说的实施要件・书面的电子交付・海外居住者的本人确认，依宅地建物取引业法与国土交通省的手册顺序整理。重要事项说明本身由宅地建物取引士（本公司的宅建士）进行。翻译・签名证明・登记・税务，各自交由不同的专业人士（皆为独立事业体、分别签约）。不就个别契约内容的可否作判断。

## 对住在海外的买方，IT重说获得认可吗？

先说结论：**对住在海外的买方，IT重说在买卖也获得认可。** 国土交通省就“不动产买卖的线上重要事项说明（IT重说）”，自**令和3年（2021年）3月30日起正式运用**，其目的之一即为减轻远方・海外客户的移动与费用负担（**2026年9月28日参照**）。租赁的IT重说先行运用，买卖自该日进入正式运用。

重要事项的说明，依宅地建物取引业法第35条，由宅地建物取引士出示宅地建物取引士证，交付书面（经对方同意可用电磁方法）进行。**IT重说只是把“说明的方法”改为线上，说明主体为宅建士、须交付35条书面这点与面对面相同。**

即使居住海外，此架构亦同。惟实务上，时差・通讯环境・本人确认・书面的收受，会比面对面更重。整理如下。

| 论点 | 海外居住买方特别有效之点 |
|---|---|
| 可否实施 | 买卖的IT重说自令和3年3月30日正式运用，海外居住者亦为对象 |
| 通讯环境 | 影像・声音稳定且能双向沟通；时差的调整 |
| 书面收受 | 重要事项说明书等的事前送达。国际邮寄，或经同意的电子交付 |
| 本人确认 | 犯罪收益移转防止法的交易时确认，采非面对面的方法 |

## 让IT重说成立的要件（影像・声音・书面的事前送达）是什么？

国土交通省的IT重说实施手册，就宅建业者应遵守之事项，大致要求下列（**2026年9月28日参照**）。

| 要件 | 内容 |
|---|---|
| 双向的环境 | 在宅建士与受说明者能视认图面等书面及影像、且能双向沟通的环境实施 |
| 书面的事前送达 | 受说明者已事前收到重要事项说明书及附件 |
| 开始前的确认 | 受说明者能一边确认书面一边受说明；宅建士在说明开始前已确认影像・声音的状况 |
| 出示宅建士证 | 宅建士出示宅地建物取引士证，并确认受说明者能在画面上视认 |

**重点是“事前送达”与“双向”。** 重要事项说明书与附图尚未送达买方手中的状态下，IT重说不成立。影像・声音中断、宅建士证读不清时，先中断改为面对面，或重整环境。**与海外连线时，通讯不稳时如何处理，宜事先与买方・卖方定好。**

## 要电子交付重要事项说明书・37条书面需要什么？

关于书面的交付，有**依“为形成数字社会之相关法律整备法”（令和3年法律第37号）对宅地建物取引业法的修正**，并**自令和4年（2022年）5月18日施行**（**2026年9月28日参照**）。由此，下列书面可经对方同意以电磁方法（电子交付）提供。

| 书面 | 依据 | 电子交付的条件 |
|---|---|---|
| 重要事项说明书 | 宅建业法第35条 | 经对方同意以电磁方法提供 |
| 缔约时书面（37条书面） | 宅建业法第37条 | 经对方同意以电磁方法提供 |
| 媒介契约书面 | 宅建业法第34条之2 | 经对方同意以电磁方法提供 |

同时，此修正**废止了宅地建物取引士的用印**，35条书面・37条书面以宅建士的记名即可。对国际邮寄需时的海外买方，电子交付尤其有效。

惟须注意：**电子交付与IT重说（以影像说明）是不同的制度。** 做IT重说仍可用纸本邮寄书面，面对面说明亦可电子交付书面。**电子交付需对方同意，并有技术条件，例如须以能将电磁记录输出制成书面的方法。** 以何种方法交付，配合买方的环境（电子签章・可否收受PDF）事先定好。重说中应确认的项目本身，整理于[「向中文圈买方介绍日本收益物件前该读的重要事项说明要点」](https://luck428.com/column/chugokugo-buyer-juyojiko-check-toushi-bukken)。

## 海外居住者的本人确认・代替实印的签名证明怎么处理？

海外买方与面对面交易最不同的，是**本人确认，以及代替实印・印鉴证明的书面**。

第一是本人确认。宅地建物取引业者是犯罪收益移转防止法（犯收法）上的特定事业者，负有交易时确认义务。非面对面（线上）时，采本人确认书面复印件的寄送与不可转送邮件，或线上完结的方法等，依犯收法施行规则所定的非面对面方法。**海外居住往往无法使用国内用的不可转送邮件，因此应在交易前确认能与护照等并用的方法。**

第二是代替实印・印鉴证明。海外居住者无日本住民登录、无法办印鉴登录，故一般在**在外公馆（日本国大使馆・总领事馆）取得“签名（Sign）证明”**，代替实印・印鉴证明使用。用于所有权移转登记与契约书的签名。在日本国内签名时，亦可在公证役场就私署证书取得认证。

| 要做的事 | 负责者 |
|---|---|
| 重要事项说明・IT重说的实施、35条书面・37条书面的交付、媒介 | 宅地建物取引业者（本公司的宅建士） |
| 契约书・重要事项说明书的外语译文制作 | 行政书士 |
| 私署证书的认证（国内）／签名证明（海外在在外公馆） | 公证役场・在外公馆 |
| 所有权移转登记 | 司法书士 |
| 向非居住者购买所伴随的源泉征收、海外汇款相关税务 | 税理士 |

**本公司所做的是IT重说的实施・书面的交付・媒介。** 翻译的制作由行政书士，签名的认证由公证役场・在外公馆，登记由司法书士，税务由税理士，皆请您分别直接委托。与当地中文圈专业人士协作的思路，整理于[「与中华圈不动产专业人士共同处理日本物件」](https://luck428.com/column/chuka-fudosan-pro-kyodo-torihiki)；海外居住业主的物件管理，见[「海外居住业主的日本不动产管理」](https://luck428.com/column/kaigai-kyoju-fudosan-kanri-chinese)。

## 为了不让实务因时差・语言停下，该如何安排？

跨境交易停下的原因，多半不是“制度”而是“安排”。先定好能避免停滞。

| 安排 | 要定好的事 |
|---|---|
| 日程 | 考量时差的IT重说日时；也留预备日 |
| 书面 | 重说书面等用纸本邮寄或电子交付；电子交付则取得同意 |
| 语言 | 翻译的要否与负责者（行政书士）；专业用语事前共享 |
| 本人确认 | 犯收法的非面对面确认方法；必要书面的取得途径 |
| 签名 | 签名证明（在外公馆）・认证（公证役场）的取得时程 |
| 结济・登记 | 汇款途径与到账确认、与司法书士的登记日程、与税理士确认源泉征收 |

**尤其签名证明与登记・汇款，在在外公馆与金融机构的手续需时。** 从结济日反推，把翻译・本人确认・签名证明的取得并行推进，商谈就不会因时差或语言停下。事业用・投资用物件全般见[投资用・事业用不动产](https://luck428.com/toushi)。

## 常见问题

**Q. 能不让海外买方来日本，就线上做重要事项说明吗？**
A. 能。国土交通省就不动产买卖的IT重说自令和3年（2021年）3月30日起正式运用，海外居住者亦为对象。要件包括宅地建物取引士在画面上出示宅地建物取引士证、以影像・声音双向沟通、买方已事前收到重要事项说明书等。先安排好时差・通讯环境・本人确认就不会停滞。

**Q. 重要事项说明书一定要纸本邮寄吗？**
A. 不必。令和4年（2022年）5月18日施行的宅地建物取引业法修正，经对方同意即可将重要事项说明书（第35条）・37条书面以电磁方法交付。宅地建物取引士的用印亦废止，记名即可。对国际邮寄需时的海外买方，电子交付有效。惟电子交付与IT重说是不同制度，电子交付需对方同意与技术条件。

**Q. 海外居住的买方没有实印，怎么办？**
A. 无日本住民登录、无法办印鉴登录的海外居住者，一般在在外公馆（日本国大使馆・总领事馆）取得签名（Sign）证明，代替实印・印鉴证明使用。用于所有权移转登记与契约书的签名。在日本国内签名时，亦可在公证役场就私署证书取得认证。因取得需时，宜从结济日反推、及早着手。登记本身由司法书士处理。

**Q. 契约书或重要事项说明书的翻译，不动产公司会做吗？**
A. 本公司所做的是重要事项说明・IT重说的实施与书面的交付、媒介。契约书・重要事项说明书的外语译文制作属行政书士的业务，由四叶行政书士事务所承接。签名的认证由公证役场・在外公馆，登记由司法书士，向非居住者购买所伴随的源泉征收与海外汇款的税务由税理士处理。皆为独立事业体，分别直接签约。
