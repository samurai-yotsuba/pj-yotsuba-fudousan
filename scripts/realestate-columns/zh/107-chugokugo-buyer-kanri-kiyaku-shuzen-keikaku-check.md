**结论（先说重点）**：把日本的中古区分大楼介绍给华语圈买主时，在重要事项说明的一般确认之前该读的，是管理组合的**营运风险**。具体为四点：①有无长期修缮计划・何时改定，修缮积立金是否预定调涨或征收一次金②管理规约的用途限制（禁止住宅宿泊事业＝民泊、宠物、专有部分的用途）③管理费・修缮积立金的滞纳（滞纳依区分所有法第8条承继给买主＝特定承继人）④管理公司的变更・大规模修缮的履历。这些在重要事项说明中也会作为管理费・修缮积立金・滞纳额等成为说明事项（宅地建物取引业法第35条第1项第6号・同法施行规则第16条之2），但专业买主不宜等到签约前才听说明，先以资料读过较安全。重要事项说明与买卖契约由宅建业者（当方），取得后的固定资产税・都市计划税的纳税管理人或申报由税理士，各自作为独立的事业体分别承担。

本文写给经手日本中古区分大楼的中国大陆・台湾・香港的不动产仲介或买方仲介（专业人士）。它整理的不是重要事项说明的一般确认，而是在契约前读**管理组合的营运风险**的观点，依据建物的区分所有等相关法律（区分所有法）・宅地建物取引业法与国土交通省的资料。以繁体字／简体字阅读为前提，示明条文与资料的对应。本公司负责日本一侧的物件介绍・调查・重要事项说明・居间；取得后的税务交由税理士。本文不保证个别的投资判断或管理状态的良否。

## 为何要在重要事项说明之前读管理规约与长期修缮计划？

在中古区分大楼，不只是专有部分（住户），管理组合如何营运整栋建物，会左右取得后的负担与出场的价值。重要事项说明（宅地建物取引业法第35条）是在契约成立前由宅地建物取引士以书面说明的法定手续，但**专业买主不宜等到签约前才听说明，先以资料读透管理规约・长期修缮计划・总会议事录・管理费等的滞纳状况**较安全。

在区分大楼，重要事项说明的对象会加上区分所有建物固有的项目。宅地建物取引业法第35条第1项第6号与同法施行规则第16条之2，把下列事项列为说明事项。

| 说明事项（区分所有建物） | 能得知什么 |
|---|---|
| 共用部分相关规约的定（含案） | 共用部分的范围・使用规则 |
| 专有部分用途及其他利用限制相关规约的定 | 民泊・宠物・事务所使用等的可否 |
| 专用使用权相关规约的定 | 停车场・阳台・专用庭的处理 |
| 修缮积立金等相关规约的定与已积立的额 | 积立金的水准・余额 |
| 通常的管理费用额 | 每月的管理费 |
| 委托管理时的委托对象 | 管理公司 |
| 建物维持修缮的实施状况纪录 | 大规模修缮的履历 |

这些映照的不是「物件本身」，而是「管理组合的营运」。管理规约的基础在国土交通省的「大楼标准管理规约（单栋型）」，各大楼的规约以此为本制作。重要事项说明的一般确认整理在[把日本的收益物件介绍给华语圈买主之前该读的重要事项说明要点](https://luck428.com/column/chugokugo-buyer-juyojiko-check-toushi-bukken)，本文聚焦于管理面。

## 长期修缮计划与修缮积立金的「调涨・一次金」从哪里看得出来？

长期修缮计划是估算未来大规模修缮（外墙・屋顶防水・给排水管・电梯等）的时期与费用，并导出所需修缮积立金额的计划。国土交通省在「长期修缮计划制作指引」示明其制作的参考。**积立金相对计划不足时，会导致调涨或征收一次金，直接关系取得后的负担。**

契约前该读的资料与在那里看的点如下。

| 要读的资料 | 看的点 |
|---|---|
| 长期修缮计划书 | 计划的有无、最近的改定时期、今后的修缮时期与预估费用、积立金未来的调涨预定 |
| 修缮积立金的余额・会计资料 | 现在的余额、相对计划的过不足、有无借款 |
| 总会・理事会的议事录 | 积立金调涨・征收一次金的议案・决议，大规模修缮的决定 |
| 重要事项相关调查报告书（管理公司发行） | 管理费・积立金的额、滞纳额、修缮计划的概要 |

**要注意的是，现在的积立金低，未必意味「好物件」。** 积立金被压得低于实态时，日后可能需要大幅调涨或一次金。取得后的高楼层大楼的修缮积立金与滞纳的承继，[相续的高楼层大楼要卖时](https://luck428.com/column/souzoku-tower-mansion-reiwa6-hyoka-baikyaku)也触及管理费・修缮积立金的清算。这些资料由本公司向管理公司・卖主取得并整理，亦对应繁体字／简体字的资料提供。

## 管理规约的禁止民泊・宠物・用途限制如何影响投资？

管理规约会束缚专有部分的使用。华语圈买主在投资上特别想确认的，是**住宅宿泊事业（民泊）的可否**。依住宅宿泊事业法（平成29年法律第65号）的民泊，即使在法律上可以申报经营，**若管理规约定有「禁止住宅宿泊事业」，在该栋建物就不能进行。** 国土交通省的标准管理规约也示明把住宅宿泊事业要允许或禁止定于规约的思路。

| 规约的限制 | 对投资的影响 |
|---|---|
| 住宅宿泊事业（民泊）的可否 | 以民泊营运为前提的投资，若有禁止规约就不成立 |
| 宠物饲养的可否 | 影响出租的招租・入住者层 |
| 专有部分的用途（限住宅・事务所使用的可否） | 若设想事务所・SOHO利用需确认 |
| 专用使用权（停车场等）的处理 | 停车场是否另行契约，使用费由谁负担 |

规约以区分所有者及议决权的各4分之3以上的总会决议设定・变更・废止（区分所有法第31条第1项）。**也就是说，现在民泊可，未来的总会决议也可能变成禁止。** 不只看现在的规约，连总会讨论的方向也以议事录确认较安全。若以民泊可否或用途作为投资前提，请在契约前掌握规约的现状与改定的动向。与当地专业人士合作推进的方式，整理在[与当地专业人士合作经手日本不动产](https://luck428.com/column/chuka-fudosan-pro-kyodo-torihiki)。

## 滞纳・管理公司变更・大规模修缮的履历如何确认？

管理费・修缮积立金的**滞纳**，是买主难以看见的风险。区分所有法第7条承认管理组合的先取特权，第8条定有，管理费等的债权**对债务人即区分所有者的特定承继人（买主等）也可行使**。也就是说，前所有者滞纳的管理费・修缮积立金，不论买卖契约如何约定，管理组合都可向买主请求。

| 要确认的项目 | 看什么 | 确认对象 |
|---|---|---|
| 该住户的滞纳 | 卖主（前所有者）的管理费・修缮积立金滞纳额、迟延损害金 | 管理公司・管理组合 |
| 管理组合整体的滞纳 | 他户滞纳多时，影响管理组合的财政・修缮 | 管理公司・会计资料 |
| 管理公司・管理方式 | 全部委托或一部委托或自主管理，管理公司的变更履历 | 管理公司・总会议事录 |
| 大规模修缮的履历与预定 | 过去修缮的时期・内容，下次的预定与资金计划 | 管理公司・长期修缮计划 |

**留着滞纳取得，因会承继给买主，在价格交涉或清算上不利。** 契约前向管理公司・管理组合照会余额，必要时在交割时清算的安排要组好。重要事项说明中，管理费・修缮积立金的额与有无滞纳也是说明事项（宅地建物取引业法第35条第1项第6号・同法施行规则第16条之2）。这些照会与整理、重要事项说明由本公司作为宅建业者承担。

## 常见问题

**Q. 管理规约与长期修缮计划在重要事项说明会被说明，为何要先读？**
A. 重要事项说明是契约成立前由宅地建物取引士以书面说明的法定手续，管理费・修缮积立金・滞纳额是说明事项（宅地建物取引业法第35条第1项第6号・同法施行规则第16条之2）。但对专业买主而言，与其在签约前听，不如先读透管理规约・长期修缮计划・总会议事录・会计资料，掌握积立金的调涨预定、滞纳与用途限制后再进入价格交涉更有利。资料由本公司向管理公司・卖主取得并整理。

**Q. 我想做民泊，法律上能申报就一定能做吗？**
A. 不。即使依住宅宿泊事业法（平成29年法律第65号）能申报，若管理规约定有「禁止住宅宿泊事业」，在该栋建物就不能进行。国土交通省的标准管理规约也示明把住宅宿泊事业要允许或禁止定于规约的思路。再者，规约可由区分所有者及议决权的各4分之3以上的总会决议变更（区分所有法第31条第1项），故请在契约前确认现在的规约与总会讨论的方向。

**Q. 前所有者滞纳的管理费，会变成由买主支付吗？**
A. 管理组合可向买主（特定承继人）请求滞纳的管理费・修缮积立金（区分所有法第8条）。迟延损害金也可能成为对象。即使买卖契约约定由卖主负担，就对管理组合的关系而言买主仍可能被请求，故请在契约前向管理公司・管理组合照会滞纳额，必要时在交割时清算的安排要组好。重要事项说明中有无滞纳也是说明事项。

**Q. 取得后的税金或申报，日本一侧的不动产公司会帮忙处理吗？**
A. 不会。固定资产税・都市计划税的纳税、出租时的申报・源泉、纳税管理人的申报，是税理士的业务。本公司负责物件介绍・调查・重要事项说明・居间，但不计算税额、也不判断源泉的要否。税务请找税理士，所有权移转登记请找司法书士，各自作为独立的事业体直接委托。本公司没有介绍费・转介费的往来。
