**结论（先说重点）**：能成为指定汽车驾校的物件，大致由三点决定——①用途地域（依建筑基准法别表第二，汽车驾校在第一种住居地域可建至楼地板面积3,000㎡以下，第二种住居地域至工业专用地域无限制可建，低层住居专用・中高层住居专用・田园住居地域则不可建）②场地（跑道）的面积（依「指定汽车驾校相关内阁府令」原则8,000㎡以上，专办大型・普通自动二轮执照的驾校为3,500㎡以上）③建物能否容纳学科教室・候客・休息室・厕所。物件阶段可先作判断，但指定可否的最终确认在都道府县公安委员会。

汽车驾校的物件，不像养老护理事业所或诊所那样「卡在用途地域」，而是卡在**能否于同一块基地同时确保场地（跑道）这块大片土地，与学科教室・技能教学的候客・休息室这些建物**。「找到建物却没有摆跑道的土地」「有土地却没有能作学科教室的楼地板」——签约后才发现，就得连设计一起重来。本文写给想新设指定汽车驾校（或面向生疏驾驶的申报驾校）、正在找物件阶段的事业者・投资家，从道路交通法・建筑基准法・内阁府令，依序整理签约前可确认的事项。可否的最终确认，在管辖所在地的都道府县公安委员会（警察本部的驾照相关窗口）。

## 能成为指定汽车驾校的物件，哪些用途地域可建？

汽车驾校是建筑基准法下受用途地域限制的建筑物。**在低层・中高层的住居专用地域与田园住居地域不可建；第一种住居地域可建至楼地板3,000㎡以下，第二种住居地域至工业专用地域则无限制可建。**

依建筑基准法（昭和25年法律第201号）第48条与别表第二，汽车驾校可否兴建依用途地域而分。场地用地广，又伴随学科栋・技能候客・车库等建物，因此确认用途地域是选地的起点。依国土交通省的用途限制整理，大致如下。

| 用途地域 | 汽车驾校可否 |
|---|---|
| 第一种・第二种低层住居专用、田园住居地域 | 不可建 |
| 第一种・第二种中高层住居专用地域 | 不可建 |
| 第一种住居地域 | 楼地板3,000㎡以下可建 |
| 第二种住居地域、准住居地域 | 无限制可建 |
| 近邻商业地域、商业地域 | 无限制可建 |
| 准工业地域、工业地域、工业专用地域 | 无限制可建 |

因场地用地广，较易出现整片土地的第二种住居・准住居与准工业・工业系地域容易成为候选；而第一种住居地域须留意建物部分楼地板3,000㎡的上限。市街化调整区域还会叠上开发许可（城市规划法第29条）的论点，故先确认所在的区域区分。用途地域・容积率如何影响土地估值，见[日本的土地值为何因「容积率」而变](https://luck428.com/column/yosekiritsu-hosei-tochine)。事业用物件整体见[投资用・事业用不动产](https://luck428.com/toushi)，事务所与公司设立的关系见[公司设立与办公室选择](https://luck428.com/office)。

## 场地（跑道）要多大的面积・何种形状？

指定汽车驾校的场地，**原则须8,000㎡以上**（专办大型自动二轮・普通自动二轮执照的技能教学・技能检定者为3,500㎡以上）。此外，周回・干线・坡道・转折・曲线・方向变换等跑道，须能在一整片土地上集中配置。

指定汽车驾校的物的基准，系依道路交通法第99条第1项，规定于「指定汽车驾校相关内阁府令」。该府令就场地（供技能教学・技能检定使用的跑道）面积，定为**原则8,000㎡以上**（专办大型自动二轮车执照或普通自动二轮车执照的技能教学及技能检定的驾校为3,500㎡以上），并规定普通执照教学所需跑道的种类。看土地（场地）时的要领如下。

| 观察处 | 确认什么 |
|---|---|
| 场地面积 | 能否以一整片土地确保8,000㎡以上（二轮专用3,500㎡以上）。绿地・路肩计入，但学科教室等建物的基地另计 |
| 场地形状 | 周回・干线・坡道・转折・曲线・方向变换等跑道能否顺利配置的形状。细长・被切割的土地不易取得 |
| 出入口与前面道路 | 教学车・检定车能否顺利进出的间口・宽度。噪音・进出动线会否与邻地冲突 |
| 高低差・造地 | 能否取得坡道跑道可用的坡度；造地・排水费用是否划算 |

数值与跑道细目由内阁府令的基准与各都道府县公安委员会的审查基准・运用决定，故**土地阶段先看「能否在一整片8,000㎡（二轮3,500㎡）土地上配置所需跑道的形状」**较为实际。具体基准请向管辖的公安委员会（警察本部）确认。

## 学科教室・技能教学的候客・休息室要几㎡・何种设备？

学科教室，法令上为「依受教学者人数的适当大小・数量」，**一律的楼地板面积（每人几㎡）法令并无规定**。连同候客所・休息所・厕所等附属设施，看建物侧能否确保。

「指定汽车驾校相关内阁府令」就进行学科教学的教室，要求「依受教学者人数的适当大小及数量」，须确保与座学听讲人数相称的大小・室数。因此，**本文不以特定数值标示学科教室每人楼地板面积**（因法令未定一律数值）。具体的楼地板面积・室数由各都道府县公安委员会的审查基准与运用判断。看建物时可确认的点如下。

| 观察处 | 确认什么 |
|---|---|
| 学科教室 | 能否取得与单次听讲人数相称的大小・室数；能否设采光・通风・空调・视听设备 |
| 技能教学的候客・休息室 | 能否确保学员可等候・休息的室 |
| 事务室・柜台 | 能否取得受理・调车・证明发行等事务用的室 |
| 厕所・附属设施 | 能否设与听讲人数相称的厕所等附属设施 |

具体面积・室数依公安委员会的审查基准，故**建物阶段先看「能否无勉强地配置与预想听讲人数相称的教室・候客・事务室・厕所的楼地板」，数值妥当与否向公安委员会确认**较安全。以租赁承租时，用途（汽车驾校）・装修造作・恢复原状的范围，签约前以书面议定。租赁契约书该读何处，见[租赁契约书该读哪里](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 申报驾校（生疏驾驶讲习）与指定驾校，看物件的方式有何不同？

申报驾校因无以技能检定・毕业证明免除技能测验的制度，**不会一律被要求达到指定驾校的场地面积（8,000㎡）物的基准**。另一方面，若要以指定驾校为目标，须从一开始就选能同时容纳场地用地与学科教室・候客・休息室的物件。

道路交通法区分：设置汽车驾校者向公安委员会申报的「申报驾校」（第98条第2项），与公安委员会从申报驾校中指定符合职员・设备等基准者的「指定汽车驾校」（第99条第1项）。受指定后，技能检定合格的毕业者可免除驾照考场的技能测验（第99条之2）。办生疏驾驶讲习等的申报驾校无此免除制度，故对物件要求的水准不同。

| 区分 | 依据 | 能做什么 | 物件・用地的看法 |
|---|---|---|---|
| 申报驾校 | 第98条第2项（向公安委员会申报） | 教学・讲习（生疏驾驶讲习等）。不伴随技能测验免除 | 不要求一律的场地面积基准。能否确保讲习可用的场所・设备 |
| 指定汽车驾校 | 第99条第1项（公安委员会的指定） | 另加以技能检定・毕业证明免除技能测验（第99条之2） | 须集中确保原则8,000㎡以上的场地＋学科教室・候客・休息室・事务室・厕所 |

也就是说，若日后要以指定为目标，**即使先以申报起步、之后再转指定，从一开始就把可增设场地用地的土地与可作学科教室的建物纳入视野**，较能减少重做。申报・指定的设备・教学基准，皆由公安委员会判断。

## 签约前，指定可否该向谁确认？

物件（不动产）、指定・申报的要件判定与向公安委员会的申请、建筑确认・用途适合、指导员・检定员的劳务、税务，承办者各异。指定可否本身由公安委员会判断。

指定汽车驾校的指定，除场地・教室等物的基准外，管理者・技能检定员・教习指导员等人的基准（第99条第1项各款）也会受审查。**先把物件定下来，可能因场地面积或教室・候客的余地不足而重做**——正因如此才在签约前排出上述论点。指定的要件判定（人的・物的基准的该当性）与向公安委员会的指定申请书类制作，是行政书士的业务。申请侧的要件与手续，整理于成对文章[如何取得指定汽车驾校的指定？道路交通法99条的指定基准与向公安委员会的手续](https://luck428.com/legal/column/shitei-jidosha-kyoshujo-shitei-youken-koan)（行政书士侧）。

| 事项 | 承办者・窗口 |
|---|---|
| 场地用地・教室栋的物件调查・中介，买卖・租赁契约 | 宅地建物交易业者 |
| 指定・申报的要件判定、向公安委员会提出的指定申请・申报书类制作 | 行政书士 |
| 建筑确认・用途变更的确认申请，场地造地・建物的设计 | 建筑士 |
| 指导员・技能检定员・事务职员的雇用・社会保险・劳动时间 | 社会保险劳务士 |
| 公司设立的登记，所有权・租赁的登记 | 司法书士 |
| 让渡所得・会计・税务 | 税理士 |
| 租金・恢复原状・迁让等纠纷 | 律师 |

## 常见问题

**Q. 指定汽车驾校的场地，最少要多大面积？**
A. 「指定汽车驾校相关内阁府令」就场地（供技能教学・技能检定使用的跑道）面积，定为原则8,000㎡以上（专办大型自动二轮车执照或普通自动二轮车执照的技能教学及技能检定的驾校为3,500㎡以上）。绿地与路肩计入面积，但学科教室等建物的基地另计。跑道（周回・干线・坡道・转折・曲线・方向变换等）能否在一整片土地上无勉强配置的形状也很重要。具体基准与运用请向管辖的都道府县公安委员会确认。

**Q. 学科教室是否规定每人几㎡？**
A. 不是。法令未以一律数值规定学科教室每人楼地板面积。「指定汽车驾校相关内阁府令」就学科教学的教室，要求「依受教学者人数的适当大小及数量」。因此论点在于能否确保与预想听讲人数相称的大小・室数，具体的面积・室数由各都道府县公安委员会的审查基准与运用判断。数值妥当与否请向公安委员会确认。

**Q. 汽车驾校在哪些用途地域可建？**
A. 依建筑基准法别表第二，在第一种住居地域可建至楼地板3,000㎡以下，在第二种住居・准住居・近邻商业・商业・准工业・工业・工业专用各地域则无限制可建。在第一种・第二种低层住居专用地域、第一种・第二种中高层住居专用地域、田园住居地域不可建。市街化调整区域还会叠上开发许可（城市规划法第29条）的论点，故请先确认所在的区域区分。

**Q. 若只办生疏驾驶讲习，就不需要8,000㎡的场地吗？**
A. 办生疏驾驶讲习等的「申报驾校」（道路交通法第98条第2项），因无以技能检定・毕业证明免除技能测验的制度，并不会被要求达到指定汽车驾校那样一律的场地面积基准。不过，若日后要以「指定」为目标，从一开始就选能同时容纳场地用地与学科教室・候客・休息室的物件，较能减少重做。申报・指定的设备・教学基准，皆由公安委员会判断。
