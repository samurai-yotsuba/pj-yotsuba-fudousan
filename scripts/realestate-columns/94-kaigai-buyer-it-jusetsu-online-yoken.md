**結論（先に要点）**：海外に住む買主へのオンラインの重要事項説明（IT重説）は、売買でも認められています。国土交通省は不動産の売買取引に係るIT重説を令和3年（2021年）3月30日から本格運用しており、海外在住者も対象です。成立の要件は、①宅建士と買主が図面等の書類・映像を視認でき双方向でやりとりできる環境②重要事項説明書等を事前に送付し買主が受領していること③宅地建物取引士証を画面上で提示し買主が視認できたことを確認、の3点が柱です。重要事項説明書（宅建業法第35条）・37条書面は、令和4年5月18日施行の改正で相手方の承諾を得て電子交付できます。本人確認と実印に代わる署名（サイン）証明の段取りを先に決めておくのが要点です。

海外在住の買主に「来日しないと契約できません」と伝えて商談が止まる——時差と言語を理由に取引が滞る場面は、今は制度上、避けられます。本記事は、海外在住の外国人・日本人の買主に売買する売主・宅建業者と、現地で仲介する中国語圏の専門家に向けて、IT重説の実施要件・書面の電子交付・海外在住者の本人確認を、宅地建物取引業法と国土交通省のマニュアルから順に整理したものです。重要事項説明そのものは宅地建物取引士（当社の宅建士）が行います。翻訳・署名証明・登記・税務は、それぞれ別の専門家に振ります（いずれも独立した事業体として別々にご契約いただきます）。個別の契約内容の可否は判断しません。

## 海外在住の買主にIT重説は認められているのか？

まず結論として、**海外在住の買主へのIT重説は、売買でも認められています。** 国土交通省は「不動産の売買取引に係るオンラインによる重要事項説明（IT重説）」を**令和3年（2021年）3月30日から本格運用**しており、遠隔地・海外に所在する顧客の移動や費用の負担軽減を目的の一つに挙げています（**2026年9月28日参照**）。賃貸取引のIT重説は先行して運用されていましたが、売買もこの日から本格運用に入りました。

重要事項の説明は、宅地建物取引業法第35条により、宅地建物取引士が、宅地建物取引士証を提示して、書面（相手方の承諾を得れば電磁的方法）を交付して行うものです。**IT重説は「説明の方法」をオンラインにするだけで、説明する主体が宅建士であること、35条書面を交付することは対面と変わりません。**

海外在住であっても、この枠組みは同じです。ただし実務では、時差・通信環境・本人確認・書面の受領方法が対面より重くなります。整理すると次のとおりです。

| 論点 | 海外在住の買主で特に効く点 |
|---|---|
| 実施の可否 | 売買のIT重説は令和3年3月30日から本格運用。海外在住者も対象 |
| 通信環境 | 映像・音声が安定して双方向でやりとりできること。時差の調整 |
| 書面の受領 | 重要事項説明書等の事前送付。国際郵送か、承諾を得ての電子交付 |
| 本人確認 | 犯罪収益移転防止法の取引時確認。非対面の方法を用いる |

## IT重説を成立させる要件（映像・音声・書面の事前送付）とは何か？

国土交通省のIT重説の実施マニュアルは、宅建業者が守るべき事項として、おおむね次を求めています（**2026年9月28日参照**）。

| 要件 | 内容 |
|---|---|
| 双方向の環境 | 宅建士及び説明を受ける者が、図面等の書類及び映像を視認でき、かつ、双方向でやりとりできる環境で実施する |
| 書面の事前送付 | 説明を受ける者が、重要事項説明書及び添付書類を、あらかじめ受領していること |
| 開始前の確認 | 説明を受ける者が書類を確認しながら説明を受けられる状態にあること、映像・音声の状況を宅建士が説明開始前に確認していること |
| 宅建士証の提示 | 宅建士が宅地建物取引士証を提示し、説明を受ける者が画面上で視認できたことを確認していること |

**要点は「事前送付」と「双方向」です。** 重要事項説明書と添付図面が買主の手元に届いていない状態では、IT重説は成立しません。映像・音声が途切れる、宅建士証が読み取れないといった場合は、いったん中断して対面に切り替えるか、環境を整え直します。**海外との接続では、通信が不安定になった時にどう扱うかを、あらかじめ買主・売主と決めておくのが安全です。**

## 重要事項説明書・37条書面を電子交付するには何が要るのか？

書面の交付については、**デジタル社会の形成を図るための関係法律の整備に関する法律（令和3年法律第37号）による宅地建物取引業法の改正**があり、**令和4年（2022年）5月18日から施行**されています（**2026年9月28日参照**）。これにより、次の書面を相手方の承諾を得て電磁的方法（電子交付）で提供できるようになりました。

| 書面 | 根拠 | 電子交付の条件 |
|---|---|---|
| 重要事項説明書 | 宅建業法第35条 | 相手方の承諾を得て電磁的方法で提供可 |
| 契約締結時の書面（37条書面） | 宅建業法第37条 | 相手方の承諾を得て電磁的方法で提供可 |
| 媒介契約書面 | 宅建業法第34条の2 | 相手方の承諾を得て電磁的方法で提供可 |

あわせて、この改正で**宅地建物取引士の押印は廃止**され、35条書面・37条書面は宅建士の記名で足りることになりました。国際郵送に日数がかかる海外在住の買主とのやりとりでは、電子交付は特に効きます。

ただし注意点があります。**電子交付とIT重説（映像による説明）は別の制度です。** IT重説をしても書面を紙で郵送することはできますし、対面で説明しても書面を電子交付することもできます。**電子交付には相手方の承諾が要り、承諾の取得や、電磁的記録を出力して書面を作成できる方法によることなどの技術的な条件があります。** どの方法で交付するかは、買主の環境（電子署名・PDFの受領可否）に合わせて先に決めておきます。重説で確認すべき項目そのものは[「中国語圏の買主に日本の収益物件を紹介する前に読む重要事項説明の要点」](/column/chugokugo-buyer-juyojiko-check-toushi-bukken)に整理しています。

## 海外在住者の本人確認・実印に代わる署名証明はどう扱うのか？

海外在住の買主で対面取引と最も違うのが、**本人確認と、実印・印鑑証明に代わる書類**です。

第一に、本人確認です。宅地建物取引業者は犯罪による収益の移転防止法（犯収法）上の特定事業者で、取引時確認が義務づけられています。非対面（オンライン）の場合は、本人確認書類の写しの送付と転送不要郵便、あるいはオンラインで完結する方法など、犯収法施行規則が定める非対面の方法によります。**海外在住だと国内向けの転送不要郵便が使えないことがあるため、パスポート等の確認書類と併用できる方法を、取引の前に確認しておく必要があります。**

第二に、実印・印鑑証明の代わりです。海外在住者は日本の住民登録がなく印鑑登録ができないため、**在外公館（日本国大使館・総領事館）で「署名（サイン）証明」を取得**し、実印・印鑑証明の代わりに用いるのが一般的です。所有権移転登記や契約書の署名に使います。日本国内で署名する場合は公証役場で私署証書の認証を受ける方法もあります。

役割は次のように分かれます。

| やること | 担い手 |
|---|---|
| 重要事項説明・IT重説の実施、35条書面・37条書面の交付、媒介 | 宅地建物取引業者（当社の宅建士） |
| 契約書・重要事項説明書の外国語訳の作成 | 行政書士 |
| 私署証書の認証（国内）／署名証明（海外は在外公館） | 公証役場・在外公館 |
| 所有権移転登記 | 司法書士 |
| 非居住者からの購入に伴う源泉徴収、海外送金に関する税務 | 税理士 |

**当社が行うのは、IT重説の実施・書面の交付・媒介までです。** 翻訳の作成は行政書士、署名の認証は公証役場・在外公館、登記は司法書士、税務は税理士に、それぞれ直接ご依頼いただく形をご案内します。現地の中国語圏の専門家との協働の考え方は[「中華圏の不動産プロと日本の物件を共同で扱うとき」](/column/chuka-fudosan-pro-kyodo-torihiki)に、海外に住むオーナーの物件管理は[「海外在住オーナーの日本の不動産管理」](/column/kaigai-kyoju-fudosan-kanri-chinese)に整理しています。

## 時差・言語で実務が止まらないための段取りは？

海外との取引は、止まる原因が「制度」ではなく「段取り」であることがほとんどです。先に決めておくと滞りを防げます。

| 段取り | 決めておくこと |
|---|---|
| 日程 | 時差を踏まえたIT重説の日時。予備日も置く |
| 書面 | 重要事項説明書等を紙郵送か電子交付か。電子交付なら承諾の取得 |
| 言語 | 翻訳の要否と担い手（行政書士）。専門用語の事前共有 |
| 本人確認 | 犯収法の非対面確認の方法。必要書類の入手経路 |
| 署名 | 署名証明（在外公館）・認証（公証役場）の取得スケジュール |
| 決済・登記 | 送金の経路と着金確認、司法書士との登記日程、税理士との源泉徴収の確認 |

**特に署名証明と登記・送金は、在外公館や金融機関の手続きに日数がかかります。** 決済日から逆算して、翻訳・本人確認・署名証明の取得を並行して進めると、時差や言語で商談が止まりません。事業用・投資用の物件全般は[投資用・事業用不動産](/toushi)をご覧ください。

## よくある質問

**Q. 海外に住む買主に、来日せずオンラインで重要事項説明はできますか？**
A. できます。国土交通省は不動産の売買取引に係るIT重説を令和3年（2021年）3月30日から本格運用しており、海外在住者も対象です。宅地建物取引士が宅地建物取引士証を画面上で提示し、映像・音声で双方向にやりとりでき、重要事項説明書等を買主が事前に受領していることなどが要件です。時差・通信環境・本人確認の段取りを先に整えておくと滞りません。

**Q. 重要事項説明書は紙で郵送しないといけませんか？**
A. いいえ。令和4年（2022年）5月18日施行の宅地建物取引業法改正で、相手方の承諾を得れば重要事項説明書（第35条）・37条書面を電磁的方法で交付できるようになりました。宅地建物取引士の押印も廃止され、記名で足ります。国際郵送に日数がかかる海外の買主には電子交付が有効です。ただし電子交付とIT重説は別の制度で、電子交付には相手方の承諾と技術的な条件があります。

**Q. 海外在住の買主は実印がありません。どうしますか？**
A. 日本の住民登録がなく印鑑登録ができない海外在住者は、在外公館（日本国大使館・総領事館）で署名（サイン）証明を取得し、実印・印鑑証明の代わりに用いるのが一般的です。所有権移転登記や契約書の署名に使います。日本国内で署名する場合は公証役場で私署証書の認証を受ける方法もあります。取得に日数がかかるため、決済日から逆算して早めに着手します。登記そのものは司法書士が扱います。

**Q. 契約書や重要事項説明書の翻訳は不動産会社がやってくれますか？**
A. 当社が行うのは重要事項説明・IT重説の実施と書面の交付、媒介までです。契約書・重要事項説明書の外国語訳の作成は行政書士の業務で、四葉行政書士事務所が承ります。署名の認証は公証役場・在外公館、登記は司法書士、非居住者からの購入に伴う源泉徴収や海外送金の税務は税理士が扱います。いずれも独立した事業体で、それぞれ直接ご契約いただきます。
