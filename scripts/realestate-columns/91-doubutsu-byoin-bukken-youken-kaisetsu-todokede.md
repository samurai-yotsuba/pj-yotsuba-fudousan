**結論（先に要点）**：動物病院（獣医師が診療を行う診療施設）の物件で先に効くのは、①用途地域で「動物病院」を置けるか（建築基準法上は診療所ではなく店舗に準じて扱われることが多く、住居専用地域では制限を受ける）②獣医療法の構造設備の基準（消毒設備・逸走防止・伝染性疾患の隔離、手術を行うなら内壁と床の耐水性、調剤を行うなら冷暗貯蔵）を満たせる素地があるか③排水・防音・臭気で近隣とぶつからないか、の3点です。診療施設開設届（獣医療法第3条）は開設後10日以内に届け出る事後届出で、書類の作成は行政書士が承ります。契約前に用途地域・給排水・換気・貸主の可否を確かめれば、手戻りは防げます。

「テナントを借りてから」動物病院の内装に取りかかったところ、手術室の床や排水が獣医療法施行規則の基準に届かず、工事をやり直す。飲食店や人のクリニックで起きるのと同じ手戻りが、動物病院でも起きます。本記事は、東京で動物病院を新規に開こうとしている獣医師・法人の代表と、その物件を貸す方に向けて、賃貸借契約を結ぶ前に確認できることを、獣医療法とその施行規則、建築基準法の条文から順に整理したものです。診療の可否や治療内容には触れません。物件が基準を満たせるかの最終確認は、届出先である都道府県（家畜保健衛生所等）と特定行政庁の窓口で行います。

## 動物病院の物件は、普通のテナントと何が違う？

まず押さえたいのは、動物病院は「人の診療所」とは別の法律で規律されるという点です。人の診療所は医療法ですが、動物病院は**獣医療法（平成4年法律第46号・平成4年9月1日施行）**が根拠になります。

同法第2条は、この法律でいう「診療施設」を、獣医師が飼育動物の診療の業務を行う施設と定めています。対象となる飼育動物は、牛・馬・めん羊・山羊・豚・犬・猫・鶏・うずらその他政令で定めるものです（**2026年9月27日参照**）。街のペットクリニックも、この「診療施設」に当たります。

そのうえで、物件選びに効いてくる違いは次の3つです。

| 動物病院で特に効く点 | 普通の店舗テナントとの違い |
|---|---|
| 構造設備の基準 | 消毒設備・逸走防止・隔離、手術室の耐水性など、獣医療法施行規則の基準を満たせる素地が要る |
| 排水・臭気・鳴き声 | 近隣影響が物件選びを大きく左右する。飲食店以上に排気・防音の作りが効く |
| 届出と物件の関係 | 開設後に届出（事後届出）だが、物件が基準を満たしていないと使えない |

**同じ「テナントを借りる」でも、動物病院は物件が獣医療法の構造設備の基準を満たせることが前提になります。** ここが物件選びの起点です。なお、トリミングやペットホテルなど「診療ではない」動物の取扱いは、根拠法も所管も別です（動物の愛護及び管理に関する法律の第一種動物取扱業）。その物件要件は[「トリミング・ペットショップの物件、開業前に何を確認する？」](/column/doubutsu-toriatsukai-bukken-youken)に整理しています。本記事は「獣医師が診療を行う動物病院」に絞ります。

## 獣医療法の診療施設として、物件に求められる構造・設備は？

診療施設の構造設備は、農林水産省令で定める基準に適合したものでなければなりません（獣医療法第4条）。その具体は**獣医療法施行規則（平成4年農林水産省令第44号）第2条**が定めています（**2026年9月27日参照**）。物件の側で効いてくるのは、次のような点です。

| 基準（施行規則第2条ほか） | 物件で確認する素地 |
|---|---|
| 飼育動物の逸走を防止するために必要な設備 | 出入口・窓・区画の作り。脱走対策の造作を入れられるか |
| 伝染性疾患の疑いのある動物を収容する設備には、他の動物への感染を防止する設備 | 隔離できる区画。空調・区画の分け方 |
| 消毒設備を設けること | 洗浄・消毒ができる給排水と作業スペース |
| 調剤を行う施設 | 採光・照明・換気を十分にし清潔を保つ、冷蔵庫その他の冷暗貯蔵設備、調剤に必要な器具を置ける区画 |
| 手術を行う施設 | 内壁及び床が耐水性の材料で覆われ、清潔を保てる構造 |
| エックス線装置を備える場合 | 施行規則第6条〜第6条の11の防護基準。装置の設置は別に設置届が要る |

**注意すべきは、これらは「診療のための基準」であって、建物のどこに何を置けるかは物件の給排水・換気・区画の素地で決まるということです。** ワンフロアの店舗に手術室の耐水床や消毒用の洗浄設備、隔離区画を後から入れようとすると、給排水の増設・防水工事・区画の造作で費用と工期が動きます。エックス線装置を置くなら、遮蔽できる壁厚や配置も物件しだいです。

物件の側で確認しておくとよいのは、基準の数値そのものより、**その基準を満たせる素地があるか**です。

| 契約前に確認 | なぜ効くか |
|---|---|
| 給排水の位置と口径 | 消毒・洗浄・手術室の清掃に必須。汚水の排出経路も要る |
| 換気・排気の経路 | 臭気・消毒薬・麻酔の排気。近隣トラブルの主因でもある |
| 電気容量 | 手術・検査機器・空調・給湯で容量が要る |
| 耐水性のある床壁の造作余地 | 手術室・処置室の「清潔保持」の素地。原状回復の範囲とも絡む |
| 防音の余地 | 鳴き声・夜間入院の対策。木造・軽量鉄骨は響きやすい |
| 天井高・床荷重 | エックス線や手術台、入院ケージの設置に効く |

**給排水・換気・防音・耐水床の設計、用途変更に伴う確認申請の要否の判断は、建築士・設計者の領域です。当社（不動産会社）は、物件がこれらの条件を満たせるかどうかの下調べと、貸主との条件交渉に伴走します。** 設備設計や構造適合の判断そのものは行いません。人のクリニックで同じ構造の手戻りが起きる理由は[「クリニックの物件は、契約前に何を確認するのか」](/column/clinic-bukken-youto-chiiki-kaisetsu-todokede)に、施術所の給排水・保健所の論点は[「鍼灸院・整骨院の物件を探すとき」](/column/shinkyu-seikotsuin-bukken-youto-hokenjo-todokede)に整理しています。

## 用途地域や近隣への配慮で、物件選びに影響するのは？

動物病院で、人のクリニックと違うのは、**臭気・鳴き声・排水という近隣影響が物件選びを大きく左右する**ことと、**用途地域の扱いが「診療所」と同じとは限らない**ことです。

第一に、用途地域です。人の診療所は建築基準法別表第二で住居専用地域を含め広く認められますが、**動物病院は「診療所」ではなく、実務上は「店舗」や「サービス業を営む店舗」に準じて扱われることが多く**、その場合は美容室などと同様に用途地域の制限を受けます。第一種低層住居専用地域では単独の店舗は建てにくく（兼用住宅の小規模なものに限られる）、第二種低層住居専用地域では床面積の合計150㎡以内などの制約が出ます。ただし**動物病院の建築基準法上の扱いは床面積・規模や特定行政庁の判断で変わり得るため、可否の最終確認は特定行政庁（建築指導課）の窓口で行う必要があります。** 用途地域と容積率が土地の値づけをどう動かすかは[「日本の土地値はなぜ『容積率』で変わるのか」](/column/yosekiritsu-hosei-tochine)に整理しています。

第二に、既存の建物の用途を変えて使う場合の**用途変更の確認申請**です。もとが物販店舗や事務所だった区画を動物病院に変えるとき、特殊建築物に該当し規模が一定以上になると確認申請が要ることがあります。**該当の有無と要否の判断は建築士の領域**で、契約前に見立てておくと手戻りを防げます。

第三に、近隣と賃貸借契約です。鳴き声・臭気・夜間の入院対応は、自治体の生活環境の条例や近隣からの苦情という形で病院の存続に響きます。集合住宅・雑居ビルの契約書には動物の飼養・持込みを制限する条項があることも多く、**動物病院としての利用が認められるか**を申込みの前に読む必要があります。契約書のどこを読むかは[「賃貸借契約書、どこを読めばいいか」](/column/chintaishaku-keiyakusho-doko-wo-yomu)に整理しています。**排気の向き、営業・入院時間、防音の作り込みは、契約前に貸主と近隣の状況を確かめておくのが安全です。**

## 診療施設開設届は誰がいつ出す？不動産会社はどこまで関われる？

動物病院の開設は、**事後届出**です。獣医療法第3条は、診療施設を開設した者は、その開設の日から**10日以内**に、当該診療施設の所在地を管轄する都道府県知事に、農林水産省令で定める事項を届け出なければならないと定めています。届け出た事項を変更したとき、休止・廃止したときも同様です（**2026年9月27日参照**）。人のクリニックの一部にある「事前の開設許可」とは仕組みが違い、動物病院は開設してから届け出る形です。

だからといって物件を後回しにしてよいわけではありません。**届出は開設後でも、物件が構造設備の基準を満たしていなければ診療施設として使えません。** 順番は「基準を満たせる物件を選ぶ → 内装・設備を整える → 開設 → 10日以内に届出」です。エックス線装置を備える場合は、装置の設置についても別に届出（設置の日から10日以内）が必要です。

役割は次のように分かれます。

| やること | 担い手 |
|---|---|
| 物件の調査・媒介・賃貸借契約 | 宅地建物取引業者（当社） |
| 用途変更の確認申請の要否判断、構造適合、給排水・換気・防音・耐水床の設計 | 建築士・設計者 |
| 診療施設開設届など官公署に提出する書類の作成 | 行政書士 |
| 診療の可否・治療内容 | 獣医師（当社・当事務所は関与しません） |

診療施設開設届など官公署に提出する書類の作成は、四葉行政書士事務所が承ります。**行政の窓口・様式・届出事項・受付の運用は変わります。着手時点で管轄の都道府県（家畜保健衛生所等）のページを直接ご確認ください。** 事業用物件全般は[投資用・事業用不動産](/toushi)、事務所と許認可の関係は[会社設立とオフィス選び](/office)をご覧ください。

## 内見から契約までに確認しておくべきことは？

内見の段階でチェックリストにしておくと、後戻りを減らせます。

| 段階 | 確認すること | 主な担い手 |
|---|---|---|
| 内見 | 給排水の位置・口径、換気/排気の経路、電気容量、天井高・床荷重、防音の余地 | 当社＋建築士・設計者 |
| 内見 | 用途地域・特定行政庁の扱い（動物病院の可否）、用途変更の確認申請の要否 | 建築士・特定行政庁 |
| 申込み前 | 賃貸借契約書に動物病院としての利用・造作の可否がどう書かれているか、原状回復の範囲 | 当社 |
| 申込み前 | 近隣の状況（住宅密集・苦情の有無）、排気の向き、営業・入院時間 | 当社＋貸主 |
| 契約前後 | 構造設備の基準を満たす内装計画、エックス線装置を置くなら遮蔽 | 建築士・設計者 |
| 開設後 | 診療施設開設届（10日以内）、エックス線装置の設置届 | 行政書士 |

これらを並行して進めれば、「借りてから基準に届かず作り直し」を避けられます。当社は物件の見立てと貸主交渉に、建築士は構造適合と設計に、行政書士は届出書類に、それぞれ別の窓口で当たります。

## 誰に相談すればよいですか？

物件の調査、媒介、売買・賃貸借の契約は、四葉不動産株式会社（宅地建物取引業 東京都知事(1)第113304号）が承ります。診療施設開設届など官公署に提出する書類の作成は、四葉行政書士事務所が承ります。用途変更の確認申請の要否判断・構造適合・設備設計は建築士・設計者が、診療の可否や治療内容は獣医師が扱います。

**この2つ（不動産会社・行政書士事務所）はそれぞれ独立した事業体です。それぞれ直接ご契約いただきます。** 当社・当事務所は、紹介料・送客手数料を受け取ることも支払うこともありません。建築士・設計者、登記の司法書士、税務の税理士、労務の社会保険労務士へも、それぞれ直接ご依頼いただく形をご案内します。相談は無料です。

## よくある質問

**Q. 動物病院を開くには、物件を借りる前に許可が要りますか？**
A. 事前の許可ではなく、事後の届出です。獣医療法第3条により、診療施設を開設した者は、開設の日から10日以内に、所在地を管轄する都道府県知事へ届け出ます。ただし届出が事後でも、物件が獣医療法施行規則の構造設備の基準を満たしていなければ診療施設として使えません。基準を満たせる物件を選び、内装を整えてから開設・届出という順番になります。

**Q. 動物病院は住宅街のマンションの一室でも開けますか？**
A. 用途地域と建物しだいです。動物病院は人の診療所と違い、建築基準法上は「店舗」や「サービス業を営む店舗」に準じて扱われることが多く、その場合は住居専用地域で制限を受けます。加えて排水・臭気・鳴き声の近隣影響が大きく、賃貸借契約で動物病院としての利用や造作が認められるかも確認が要ります。可否の最終確認は特定行政庁と貸主に対して行ってください。

**Q. 手術室やエックス線室があると、物件選びで何が変わりますか？**
A. 手術を行う施設は、施行規則第2条により内壁及び床が耐水性の材料で覆われ、清潔を保てる構造であることが求められます。エックス線装置を備える場合は施行規則第6条以降の防護基準に適合させ、装置の設置届（設置の日から10日以内）も必要です。これらは床の耐水造作、遮蔽できる壁、給排水、電気容量、床荷重に効くため、物件の素地を内見の段階で確認しておくのが安全です。適合の判断は建築士が行います。

**Q. 診療施設開設届は不動産会社に頼めますか？**
A. いいえ。官公署に提出する診療施設開設届などの書類の作成は行政書士の業務で、四葉行政書士事務所が承ります。物件の調査・媒介・賃貸借契約は四葉不動産株式会社が承ります。両者は独立した事業体で、それぞれ直接ご契約いただきます。用途変更の確認申請の要否や構造適合の判断は建築士、診療の内容は獣医師の領域です。
