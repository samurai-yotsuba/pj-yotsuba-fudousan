**結論（先に要点）**：中国語圏の買主に日本の中古区分マンションを紹介するとき、重要事項説明書の一般チェックの前に読んでおきたいのが、管理組合の「運営リスク」です。具体的には、①長期修繕計画があるか・いつ改定されたか、修繕積立金の値上げや一時金徴収が予定されていないか②管理規約の用途制限（住宅宿泊事業＝民泊の禁止、ペット、専有部分の用途）③管理費・修繕積立金の滞納（滞納は区分所有法第8条で買主＝特定承継人に承継される）④管理会社の変更・大規模修繕の履歴、の4点です。これらは重要事項説明でも管理費・修繕積立金・滞納額などとして説明事項になります（宅地建物取引業法第35条第1項第6号・同法施行規則第16条の2）が、プロの買主は契約直前の説明を待たず、先に資料で読むのが安全です。重要事項説明と売買契約は宅建業者（当方）、取得後の固定資産税・都市計画税の納税管理人や確定申告は税理士が、それぞれ独立した事業体として別々に担います。

日本の中古区分マンションを扱う中国本土・台湾・香港の不動産エージェントやバイヤーズエージェント（プロ層）に向けて、重要事項説明の一般チェックではなく、**管理組合の運営リスク**を契約前に読む観点を、建物の区分所有等に関する法律（区分所有法）・宅地建物取引業法と国土交通省の資料から整理します。繁体字／簡体字で読む前提で、条文と資料の対応づけを示します。当社は日本側の物件紹介・調査・重要事項説明・媒介を担い、取得後の税務は税理士へ分けてご案内します。本記事は個別の投資判断や管理状態の良否を保証するものではありません。

## なぜ管理規約と長期修繕計画を重要事項説明より先に読むのか？

中古の区分マンションは、専有部分（住戸）だけでなく、建物全体を管理組合がどう運営しているかが、取得後の負担と出口の価値を左右します。重要事項説明（宅地建物取引業法第35条）は契約成立までに宅地建物取引士が書面で説明する法定の手続きですが、**プロの買主は契約直前の説明を待たず、先に管理規約・長期修繕計画・総会議事録・管理費等の滞納状況を資料で読む**のが安全です。

区分マンションでは、重要事項説明の対象に区分所有建物固有の項目が加わります。宅地建物取引業法第35条第1項第6号と同法施行規則第16条の2は、次のような事項を説明事項として挙げています。

| 説明事項（区分所有建物） | 何が分かるか |
|---|---|
| 共用部分に関する規約の定め（案を含む） | 共用部分の範囲・使い方のルール |
| 専有部分の用途その他の利用制限に関する規約の定め | 民泊・ペット・事務所使用などの可否 |
| 専用使用権に関する規約の定め | 駐車場・バルコニー・専用庭などの扱い |
| 修繕積立金等に関する規約の定めと既に積み立てられている額 | 積立金の水準・残高 |
| 通常の管理費用の額 | 毎月の管理費 |
| 管理が委託されているときの委託先 | 管理会社 |
| 建物の維持修繕の実施状況の記録 | 大規模修繕の履歴 |

これらは「物件そのもの」ではなく「管理組合の運営」を映す項目です。管理規約の考え方の土台は国土交通省の「マンション標準管理規約（単棟型）」にあり、各マンションの規約はこれを基に作られています。重要事項説明の一般的なチェックは[中国語圏の買主に日本の収益物件を紹介する前に読む重要事項説明の要点](/column/chugokugo-buyer-juyojiko-check-toushi-bukken)に整理しており、本記事は管理面に絞ります。

## 長期修繕計画と修繕積立金の「値上げ・一時金」はどこで分かるか？

長期修繕計画は、将来の大規模修繕（外壁・屋上防水・給排水管・エレベーターなど）の時期と費用を見積もり、必要な修繕積立金の額を導く計画です。国土交通省は「長期修繕計画作成ガイドライン」でその作り方の目安を示しています。**積立金が計画に対して不足していると、値上げや一時金の徴収につながり、取得後の負担に直結します。**

契約前に読むべき資料と、そこで見る点は次のとおりです。

| 読む資料 | 見る点 |
|---|---|
| 長期修繕計画書 | 計画の有無、直近の改定時期、今後の修繕時期と見込み費用、積立金の将来の引上げ予定 |
| 修繕積立金の残高・会計資料 | 現在の残高、計画に対する過不足、借入れの有無 |
| 総会・理事会の議事録 | 積立金の値上げ・一時金徴収の議案・決議、大規模修繕の決定 |
| 重要事項に係る調査報告書（管理会社発行） | 管理費・積立金の額、滞納額、修繕計画の概要 |

**注意したいのは、現在の積立金が低いことが必ずしも「良い物件」を意味しない点です。** 積立金が実態より低く抑えられていると、いずれ大幅な値上げや一時金が必要になり得ます。取得後のタワーマンション等の修繕積立金や滞納の承継については[相続したタワーマンションを売るなら](/column/souzoku-tower-mansion-reiwa6-hyoka-baikyaku)でも管理費・修繕積立金の精算に触れています。これらの資料は当社が管理会社・売主から取り寄せて整理し、繁体字／簡体字での資料提供にも対応します。

## 管理規約の民泊禁止・ペット・用途制限は投資にどう響くか？

管理規約は、専有部分の使い方を縛ります。中国語圏の買主が投資で特に確認したいのが、**住宅宿泊事業（民泊）の可否**です。住宅宿泊事業法（平成29年法律第65号）にもとづく民泊は、法律上は届出で営める場合でも、**管理規約で「住宅宿泊事業を禁止する」旨が定められていれば、その建物では行えません。** 国土交通省の標準管理規約でも、住宅宿泊事業を可能とするか禁止するかを規約に定めておく考え方が示されています。

| 規約の制限 | 投資への影響 |
|---|---|
| 住宅宿泊事業（民泊）の可否 | 民泊運用を前提にした投資は、禁止規約があると成り立たない |
| ペット飼育の可否 | 賃貸の客付け・入居者層に影響 |
| 専有部分の用途（住宅限定・事務所使用の可否） | 事務所・SOHO利用を想定するなら要確認 |
| 専用使用権（駐車場・バルコニー等）の扱い | 駐車場が別契約か、使用料の負担者は誰か |

規約は、区分所有者及び議決権の各4分の3以上の総会決議で設定・変更・廃止されます（区分所有法第31条第1項）。**つまり、今は民泊可でも、将来の総会決議で禁止に変わり得ます。** 現在の規約だけでなく、総会での議論の方向も議事録で確認するのが安全です。民泊可否や用途を投資の前提にするなら、規約の現状と改定の動きを契約前に押さえてください。現地の専門家と組んで進める形は[現地の専門家と組んで日本の不動産を扱う](/column/chuka-fudosan-pro-kyodo-torihiki)に整理しています。

## 滞納・管理会社変更・大規模修繕の履歴はどう確認するか？

管理費・修繕積立金の**滞納**は、買主にとって見えにくいリスクです。区分所有法第7条は管理組合に先取特権を認め、第8条は、管理費等の債権を**債務者である区分所有者の特定承継人（買主など）に対しても行使できる**と定めています。つまり、前の所有者が滞納していた管理費・修繕積立金は、売買契約でどう取り決めても、管理組合は買主に請求できます。

| 確認する項目 | 何を見るか | 確認先 |
|---|---|---|
| 当該住戸の滞納 | 売主（前所有者）の管理費・修繕積立金の滞納額、遅延損害金 | 管理会社・管理組合 |
| 管理組合全体の滞納 | 他の住戸の滞納が多いと、管理組合の財政・修繕に影響 | 管理会社・会計資料 |
| 管理会社・管理方式 | 全部委託か一部委託か自主管理か、管理会社の変更履歴 | 管理会社・総会議事録 |
| 大規模修繕の履歴と予定 | 過去の修繕の時期・内容、次回の予定と資金計画 | 管理会社・長期修繕計画 |

**滞納を残したまま取得すると、買主に承継されるため、価格交渉や精算で不利になります。** 契約前に管理会社・管理組合へ残高を照会し、必要なら決済時に精算する段取りを組みます。重要事項説明でも、管理費・修繕積立金の額や滞納の有無が説明事項です（宅地建物取引業法第35条第1項第6号・同法施行規則第16条の2）。これらの照会と整理、重要事項説明は当社が宅建業者として担います。

## よくある質問

**Q. 管理規約や長期修繕計画は、重要事項説明で説明されるのに、なぜ先に読むのですか？**
A. 重要事項説明は契約成立までに宅地建物取引士が書面で説明する法定の手続きで、管理費・修繕積立金・滞納額などが説明事項です（宅地建物取引業法第35条第1項第6号・同法施行規則第16条の2）。ただしプロの買主にとっては、契約直前に聞くより、先に管理規約・長期修繕計画・総会議事録・会計資料を読み込み、積立金の値上げ予定や滞納、用途制限を把握してから価格交渉に入るほうが有利です。資料は当社が管理会社・売主から取り寄せて整理します。

**Q. 民泊で運用したいのですが、法律で届出ができれば必ずできますか？**
A. いいえ。住宅宿泊事業法（平成29年法律第65号）にもとづく届出ができる場合でも、管理規約で「住宅宿泊事業を禁止する」旨が定められていれば、その建物では行えません。国土交通省の標準管理規約でも、住宅宿泊事業を可能とするか禁止するかを規約に定めておく考え方が示されています。さらに規約は区分所有者及び議決権の各4分の3以上の総会決議で変更され得る（区分所有法第31条第1項）ため、現在の規約と総会の議論の方向を契約前に確認してください。

**Q. 前の所有者が滞納していた管理費は、買主が払うことになりますか？**
A. 管理組合は、滞納していた管理費・修繕積立金を、買主（特定承継人）に対しても請求できます（区分所有法第8条）。遅延損害金も対象になり得ます。売買契約で売主の負担と取り決めても、管理組合に対する関係では買主が請求を受け得るため、契約前に管理会社・管理組合へ滞納額を照会し、必要なら決済時に精算する段取りを組みます。重要事項説明でも滞納の有無が説明事項です。

**Q. 取得後の税金や申告は、日本側の不動産会社が手続きしてくれますか？**
A. いいえ。固定資産税・都市計画税の納税や、賃貸する場合の確定申告・源泉、納税管理人の届出は、税理士の業務です。当社は物件紹介・調査・重要事項説明・媒介を担いますが、税額の計算や源泉の要否は判断しません。税務は税理士へ、所有権移転登記は司法書士へ、それぞれ独立した事業体として直接ご依頼ください。当社は紹介料・送客手数料のやりとりをしません。
