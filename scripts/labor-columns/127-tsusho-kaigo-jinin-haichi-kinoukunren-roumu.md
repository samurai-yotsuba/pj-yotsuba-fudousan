**結論（先に要点）**：通所介護（デイサービス）の人員配置は、生活相談員・看護職員・介護職員・機能訓練指導員を、指定基準（指定居宅サービス等の事業の人員、設備及び運営に関する基準＝平成11年厚生省令第37号）第93条に沿って置いたうえで、その人数を「勤務時間の総量」で満たし続けるシフト設計が労務の軸になります。生活相談員と看護職員は員数ではなく「提供時間帯を通じて確保する時間数」で見る仕組みで、介護職員は利用者15人まで1人以上、15人を超える部分を5で割って1を加えた数以上とされます（同条第1項）。生活相談員又は介護職員のうち1人以上は常勤でなければなりません（同条第6項）。この記事では、人員基準のうち社会保険労務士が関わる労働時間・シフト・常勤換算の範囲を整理し、指定基準そのものの解釈や指定申請の書類作成は行政書士に分けるという切り分けまで示します。

「指定基準の人数は満たしているが、有給や研修で抜けたときに割れないシフトをどう組むか」「機能訓練指導員を看護職員が兼ねてよいのか」——デイサービスを開設・運営する事業者の労務担当から、よく受ける相談です。このページは、通所介護の人員配置を前提に、労働時間管理・常勤換算・就業規則という労務の設計を整理します。指定基準そのものへの適合や指定申請の可否は指定権者（都道府県・市町村）と申請実務の領分で、この記事は労務の考え方に絞ります。

## 通所介護に最低限必要な職種と員数はどう決まりますか？

通所介護の従業者の員数は、指定居宅サービス等の事業の人員、設備及び運営に関する基準（平成11年厚生省令第37号）第93条に定められています。骨格は次のとおりです（数値の細目・取扱いは制度改正と自治体の運用で変わるため、最終的な適合は指定権者の案内で確認します）。

| 職種 | 配置の考え方（第93条第1項） |
|---|---|
| 生活相談員 | サービス提供日ごとに、専ら提供に当たる生活相談員の勤務時間数の合計を提供時間帯の時間数で割った数が1以上 |
| 看護職員 | 単位ごとに専ら提供に当たる看護職員が1以上（利用定員10人以下の通所介護では緩和される取扱いがある） |
| 介護職員 | 利用者15人までは1人以上、15人を超える部分の数を5で割って得た数に1を加えた数以上 |
| 機能訓練指導員 | 1人以上 |
| 管理者 | 常勤で専らその職務に従事（同令第94条。支障がない範囲で兼務できる場合がある） |

ここで押さえたいのは、**生活相談員と看護職員は「頭数」ではなく「提供時間帯を通じて確保する勤務時間数」で見る**という点です。だからこそ、誰がいつ何時間入るかというシフトの作り方が、そのまま基準への適合を左右します。**生活相談員又は介護職員のうち1人以上は常勤**でなければならない（第93条第6項）という要件も、雇用契約と勤務表の設計に直結します。社会保険労務士が担うのは「置く人数」ではなく「その人数を満たす勤務の作り方」——シフト設計、雇用契約・就業規則・賃金規程の整備、労働時間管理、社会保険の資格得喪の手続です。基準そのものの解釈や指定申請の書類作成は行政書士の業務で、扱う法律が異なります。

## 生活相談員・機能訓練指導員は兼務できますか？

兼務の可否は、指定基準と自治体の解釈通知で細かく決まっており、労務ではその可否を前提に「同じ人の勤務時間をどの職務に何時間割り振るか」を管理します。一般的な考え方は次のとおりです（具体的な可否は指定権者に確認します）。

- **機能訓練指導員は当該事業所の他の職務との兼務が認められるのが通常**です。ただし機能訓練指導員になれるのは、理学療法士・作業療法士・言語聴覚士・看護職員・柔道整復師・あん摩マッサージ指圧師・はり師・きゅう師など、資格を持つ者に限られます
- **生活相談員・看護職員も、一定の条件で他の職務と兼務できる場合がある**とされますが、その時間は「専ら通所介護の提供に当たる時間」から外れるため、提供時間帯を通じた確保の計算に注意が必要です
- 兼務させる場合、**1人の労働時間の総量は変わらない**点に注意します。兼務は員数のやりくりであって、労働時間を増やせるわけではありません。時間外・深夜・休日の割増賃金（労働基準法第37条）は、職務をまたいでも通算した実労働時間で計算します

兼務の設計は、勤務表に「この時間は生活相談員、この時間は介護職員」と職務の別を明記し、後から検証できる記録にしておくのが安全です。障害福祉・介護の常勤換算の数え方は[障害福祉・介護の常勤換算はどう計算しますか](/labor/column/shogai-fukushi-kaigo-jokin-kansan-keisan-jinin)にも整理しています。

## 看護職員の「提供時間帯を通じた確保」はどう管理しますか？

通所介護の看護職員は、単位ごとに専ら提供に当たる者を確保する仕組みで、開院から閉院までの提供時間帯を通じて置けるようにシフトを組みます。労務でつまずきやすいのは次の点です。

| 論点 | 労務での扱い |
|---|---|
| 提供時間帯の途中で看護職員が不在になる | 基準割れの恐れ。休憩・中抜けの時間をどう埋めるかをシフトで先に設計する |
| 看護職員1人体制での有給・欠勤 | 代替の確保が要る。1人に依存する体制は基準割れリスクが高い |
| パート看護職員の労働時間 | 実際の勤務時間で管理し、雇用契約・労働条件通知（労働基準法第15条）に所定労働時間を明示する |
| 休憩の付与 | 6時間超で45分、8時間超で1時間以上（労働基準法第34条）。休憩中に対応義務があれば手待時間として労働時間になり得る |

看護職員を1人しか置かない体制は、その人が休むと提供時間帯の確保が崩れます。**有給休暇（労働基準法第39条。年5日は使用者の時季指定義務）や研修参加で抜ける時間を織り込んだシフト**にしておくことが、基準割れを防ぐ実務です。就業規則は常時10人以上の事業場で作成・届出の義務があります（労働基準法第89条）。詳しくは[就業規則は何人から作成・届出が必要ですか](/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)をご覧ください。

## 常勤換算数はシフトでどう計算しますか？

常勤換算数は、**その事業所の従業者の勤務延べ時間数を、常勤の従業者が勤務すべき時間数で割った数**です。介護職員の必要数も、この考え方で「勤務時間の総量」として満たします。

| 項目 | 内容 |
|---|---|
| 計算式 | 常勤換算数＝（職員全員の勤務延べ時間数）÷（常勤が勤務すべき時間数） |
| 常勤が勤務すべき時間 | 就業規則で定める所定労働時間（例：週40時間）。労働基準法第32条の上限は1日8時間・1週40時間 |
| パート職員 | 実際の勤務時間で延べ時間に算入する |
| 端数・余裕 | 有給・欠勤・研修で延べ時間が落ちても割れないよう、余裕を持って組む |

注意したいのは、**常勤換算は人数ではなく勤務時間の総量で見る**という点です。週40時間の常勤1人と、週20時間のパート2人は常勤換算では同じ「1」です。デイサービスは提供時間帯が日中に固定されるため、変形労働時間制やシフトの工夫で、開院日・提供時間帯に必要な員数を確保しつつ週40時間以内に収める設計が現実的です。1か月単位（労働基準法第32条の2）や1年単位（同第32条の4）の変形労働時間制の選び方は[変形労働時間制とフレックスはどう選びますか](/labor/column/henkei-roudoujikan-flextime-erabikata)をご覧ください。同じ介護でも夜勤のある特定施設の常勤換算・夜勤管理は[介護付き有料老人ホームの人員配置と夜勤の労務はどうしますか](/labor/column/tokutei-shisetsu-yuryo-home-jinin-haichi-yakin-roumu)に整理しています。

## 人員配置基準を割ると報酬にどう響き、労務で何を備えますか？

人員基準を満たせない状態（基準割れ）が続くと、介護報酬の減算や、指定の効力に関わる問題につながり得ます。報酬の算定・請求そのものは事業者と国保連・自治体の領分ですが、**基準割れを起こさないための勤務管理は労務の中心課題**です。労務で備えるのは次の点です。

- **勤務実績を客観的に記録する**。始業・終業時刻、休憩、職務の別（兼務時）を勤務表とタイムカード等で残し、常勤換算が満たされていることを後から検証できるようにする
- **時間外・休日労働は36協定の範囲内で**（労働基準法第36条）。人手が薄い日を残業で埋め続ける運用は、協定の上限（原則月45時間・年360時間）を超える恐れがあります
- **未払い賃金の消滅時効は当分の間3年**（労働基準法第115条・附則）。割増の計算を誤ると3年分をまとめて請求される恐れがあるため、割増賃金の計算は正確に行う
- **処遇改善加算の賃金要件と就業規則を整合させる**。加算の賃金改善は就業規則・賃金規程に落とし込みます。介護の処遇改善加算の賃金規定は[介護の処遇改善加算は賃金規定にどう落とし込みますか](/labor/column/kaigo-shogu-kaizen-kasan-chingin-kitei)をご覧ください

なお、個別の減算の可否や介護給付費の算定・請求の判断は、指定権者・国保連の領分で、この記事の範囲外です。介護報酬の請求に関わる具体的な判断は行いません。

## 指定の人員基準と労務は、誰に分けて頼めばいいですか？

通所介護の開設・運営では、判断する主体が分かれます。役割を切り分けて、それぞれの専門家に頼むのが安全です。

| すること | 誰の領分か |
|---|---|
| シフト設計・常勤換算の管理、就業規則・賃金規程・36協定・変形労働時間制の整備、労働時間管理、社会保険の手続 | **社会保険労務士**（四葉社会保険労務士事務所） |
| 人員基準の解釈・通所介護の指定申請・変更届の書類作成 | **行政書士**（四葉行政書士事務所） |
| 物件の用途地域・構造・採光・避難の適否 | 宅地建物取引業者・建築士 |
| 介護給付費の算定・請求 | 事業者・国保連・自治体 |
| 未払い賃金の請求・紛争、労働審判・訴訟 | **弁護士** |
| 介護報酬に関わる税務 | **税理士** |

四葉社会保険労務士事務所と四葉行政書士事務所は、**独立した事業体**です。労務は社会保険労務士、指定申請は行政書士というように、**別々にご契約**いただく分離受任の形になります。紹介料の受け渡しはありません。人員基準に対応する労務は[人員基準に対応する労務](/labor/services/jinin-kijun-roumu)、介護・障害福祉の労務は[介護・障害福祉の労務管理](/labor/services/kaigo-roumu)にまとめています。**ご相談は無料です。** 費用は[報酬額表](/labor/ryokin)を、よくいただくご質問は[よくあるご質問](/labor/faq)をご覧ください。

## よくある質問

**Q. 機能訓練指導員は看護職員が兼ねてよいですか？**
A. 機能訓練指導員になれるのは、理学療法士・作業療法士・言語聴覚士・看護職員・柔道整復師・あん摩マッサージ指圧師・はり師・きゅう師などの資格者で、看護職員がこの資格で機能訓練指導員を兼ねることは一般に可能とされます。ただし兼務させても1人の労働時間の総量は変わらず、割増賃金は職務を通算した実労働時間で計算します。具体的な兼務の可否は指定権者に確認します。

**Q. 生活相談員は常勤でなければいけませんか？**
A. 生活相談員そのものが常勤である必要はありませんが、生活相談員又は介護職員のうち1人以上は常勤でなければならないとされています（平成11年厚生省令第37号第93条第6項）。どちらを常勤にするかは雇用契約とシフトの設計の問題で、社会保険労務士が関わる範囲です。

**Q. 常勤換算は「頭数」で満たせばよいのですか？**
A. いいえ。常勤換算は勤務時間の総量で見ます。職員全員の勤務延べ時間数を、常勤が勤務すべき時間数で割った数です。有給休暇・欠勤・研修で延べ時間が落ちると基準割れの恐れがあるため、余裕を持ったシフト設計が前提です。

**Q. 人員基準の適合と労務は同じ人に頼めますか？**
A. 根拠となる法律が違うため、分けて考えます。人員基準の解釈や指定申請の書類作成は行政書士、シフト設計・就業規則・労働時間管理・社会保険の労務は社会保険労務士です。四葉では、四葉行政書士事務所と四葉社会保険労務士事務所が独立した事業体として、別々にご契約いただく形で分担します。
