**结论（先讲重点）**：日间照护（通所介护）的人员配置，是依指定基准（指定居宅服务等事业之人员、设备及运营基准＝平成11年厚生省令第37号）第93条配置生活咨询员、护理人员、照护人员与机能训练指导员，再以“勤务时间总量”持续满足该人数的**排班设计**为劳务核心。生活咨询员与护理人员并非以人头计算，而是以“服务提供时段内确保的勤务时数”认定；照护人员在使用者15人以下须1人以上，超过15人的部分除以5再加1（同条第1项）。生活咨询员或照护人员之中至少1人须为常勤（同条第6项）。本文从社会保险劳务士的角度，整理劳动时间、排班、常勤换算的范围，并说明基准本身的解释与指定申请文件应交由行政书士处理的分工。

“基准的人数虽已满足，但有人请年假或参加研修抽离时，如何排出不会低于基准的班？”“护理人员可以兼任机能训练指导员吗？”——这是开设、运营日间照护的经营者常向我们提出的问题。本页以日间照护的人员配置为前提，整理雇用合同、劳动时间管理、常勤换算等劳务设计。基准本身是否符合、指定申请能否通过，属于指定权者（都道府县・市町村）与申请实务的领域，本文专注于劳务的思考方式。

## 日间照护最低需要哪些职种与人数，如何决定？

日间照护的从业人员人数，规定于指定居宅服务等事业之人员、设备及运营基准（平成11年厚生省令第37号）第93条。骨架如下（数值细目与处理方式会因制度修正与各自治体运用而变动，最终是否符合须向指定权者确认）。

| 职种 | 配置概念（第93条第1项） |
|---|---|
| 生活咨询员 | 每个服务日，专责提供者的勤务时数合计除以服务提供时段时数所得之数为1以上 |
| 护理人员 | 每个单位须有专责者1以上（利用定员10人以下的日间照护另有放宽处理） |
| 照护人员 | 使用者15人以下须1人以上；超过15人的部分除以5再加1 |
| 机能训练指导员 | 1人以上 |
| 管理者 | 常勤并专责（同令第94条；在无妨碍的范围内可兼任） |

须掌握的重点是：**生活咨询员与护理人员并非以“人头”计算，而是以“服务提供时段内确保的勤务时数”认定**。正因如此，如何排班会直接左右是否符合基准。**生活咨询员或照护人员之中至少1人须为常勤**（第93条第6项）的要件，也直接关系到雇用合同与勤务表的设计。社会保险劳务士负责的不是“配置的人数”，而是“满足该人数的勤务做法”——排班设计、雇用合同与工作规则与薪资规程的整备、劳动时间管理、社会保险的取得丧失手续。基准的解释与指定申请文件的制作属于行政书士的业务，适用的法律不同。

## 生活咨询员、机能训练指导员可以兼任吗？

能否兼任，由基准与各自治体的解释通知详细规定；在劳务上，我们以此为前提管理“同一人的勤务时间如何分配至哪项职务、几小时”。一般思考如下（具体可否须向指定权者确认）。

- **机能训练指导员通常可兼任该事业所的其他职务。** 但能担任机能训练指导员者，限于物理治疗师、职能治疗师、语言听觉师、护理人员、柔道整复师、按摩指压师、针灸师等具资格者
- **生活咨询员、护理人员在一定条件下也可能兼任其他职务**，但该时间会脱离“专责提供日间照护的时间”，因此在服务提供时段内确保的计算上须留意
- 兼任时须注意，**一人的劳动时间总量并不会改变。** 兼任是人数的调度，并不能增加劳动时间。加班、深夜、假日的加成工资（劳动基准法第37条），仍以跨职务合计的实际劳动时间计算

兼任的设计，宜在勤务表上明记“此时段为生活咨询员、此时段为照护人员”的职务区别，留下日后可查核的记录。身心障碍福祉与照护的常勤换算计算方式，另整理于[身心障碍福祉、照护的常勤换算如何计算](/zh/labor/column/shogai-fukushi-kaigo-jokin-kansan-keisan-jinin)。

## 护理人员的“服务提供时段内确保”如何管理？

日间照护的护理人员，须每个单位确保专责者，并排班使其能在自开院至闭院的服务提供时段内配置。劳务上容易绊倒的地方如下。

| 论点 | 劳务处理 |
|---|---|
| 服务提供时段中途护理人员不在 | 有低于基准之虞。应先在排班中设计如何填补休息、暂离的时间 |
| 单一护理人员体制下的年假、缺勤 | 需确保替代者。依赖一人的体制，低于基准的风险高 |
| 兼职护理人员的劳动时间 | 以实际勤务时间管理，并于雇用合同、劳动条件通知（劳动基准法第15条）明示所定劳动时间 |
| 休息的给予 | 超过6小时给45分钟、超过8小时给1小时以上（劳动基准法第34条）。若休息中仍有应对义务，可能成为待命时间而属劳动时间 |

只配置一名护理人员的体制，该人休假时服务提供时段的确保便会崩解。**把因年假（劳动基准法第39条，雇主有指定5日的义务）与研修抽离的时间纳入考量的排班**，正是防止低于基准的实务。工作规则在经常雇用10人以上的事业场有制作、申报的义务（劳动基准法第89条）。详见[工作规则从几人开始须制作与申报](/zh/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)。

## 常勤换算数如何在排班中计算？

常勤换算数，是**该事业所从业人员的勤务累计时数，除以常勤者应勤务时数所得之数**。照护人员的必要数，也以此思考方式作为“勤务时间总量”来满足。

| 项目 | 内容 |
|---|---|
| 计算式 | 常勤换算数＝（全体职员的勤务累计时数）÷（常勤者应勤务时数） |
| 常勤应勤务时间 | 工作规则所定的所定劳动时间（例：每周40小时）。劳动基准法第32条上限为每日8小时、每周40小时 |
| 兼职职员 | 以实际勤务时间计入累计时数 |
| 端数、余裕 | 为使年假、缺勤、研修导致累计时数下降时也不低于基准，须留余裕地排班 |

须注意的是，**常勤换算是以勤务时间总量、而非人头来看**。每周40小时的常勤1人，与每周20小时的兼职2人，在常勤换算上同为“1”。由于日间照护的服务提供时段固定于日间，运用变形劳动时间制与排班巧思，在确保服务日、服务提供时段所需人数的同时将每周控制在40小时内，是务实的设计。1个月单位（劳动基准法第32条之2）或1年单位（同第32条之4）变形劳动时间制的选择方式，详见[变形劳动时间制与弹性工时如何选择](/zh/labor/column/henkei-roudoujikan-flextime-erabikata)。同为照护、但设有夜班的特定设施之常勤换算与夜班管理，整理于[附照护收费老人之家的人员配置与夜班劳务如何处理](/zh/labor/column/tokutei-shisetsu-yuryo-home-jinin-haichi-yakin-roumu)。

## 低于人员配置基准会如何影响报酬，劳务上要准备什么？

无法满足基准（低于基准）的状态若持续，可能导致照护报酬的减算，或涉及指定效力的问题。报酬的核算与请款本身属于经营者与国保联合会、自治体的领域，但**为避免低于基准的勤务管理，是劳务的核心课题**。劳务上要准备的是：

- **客观记录勤务实绩。** 将上下班时刻、休息、职务区别（兼任时）保留于勤务表与打卡等，使常勤换算是否满足可于日后查核
- **加班、假日劳动应在36协定范围内**（劳动基准法第36条）。持续以加班填补人手薄弱的日子，有超过协定上限（原则每月45小时、每年360小时）之虞
- **未付工资的消灭时效目前为3年**（劳动基准法第115条与附则）。加成计算若有误，有被合并请求3年份之虞，故加成工资须正确计算
- **使待遇改善加算的薪资要件与工作规则一致。** 加算的薪资改善须落实于工作规则与薪资规程。照护的待遇改善加算如何落实于薪资规程，详见[照护的待遇改善加算如何落实于薪资规程](/zh/labor/column/kaigo-shogu-kaizen-kasan-chingin-kitei)

至于个别减算的可否，以及照护给付费的核算与请款判断，属于指定权者、国保联合会的领域，不在本文范围。本文不对照护报酬的请款作具体判断。

## 指定的人员基准与劳务，该分别委托给谁？

在开设、运营日间照护时，判断的主体会分开。切分角色、分别委托各自的专家较为安全。

| 要做的事 | 属于谁的领域 |
|---|---|
| 排班设计与常勤换算管理、工作规则、薪资规程、36协定、变形劳动时间制、劳动时间管理、社会保险手续 | **社会保险劳务士**（四葉社会保険労務士事務所） |
| 人员基准的解释、日间照护的指定申请与变更申报文件 | **行政书士**（四葉行政書士事務所） |
| 物件的用途地域、构造、采光、避难的适否 | 宅地建物交易业者、建筑士 |
| 照护给付费的核算与请款 | 经营者、国保联合会、自治体 |
| 未付工资的请求与纠纷、劳动审判、诉讼 | **律师** |
| 涉及照护报酬的税务 | **税理士** |

四葉社会保険労務士事務所与四葉行政書士事務所为**独立的事业体**。劳务交由社会保险劳务士、指定申请交由行政书士，须**分别承接、另行签约**（分离受任）。彼此不收授介绍费。对应人员基准的劳务整理于[对应人员基准的劳务](/zh/labor/services/jinin-kijun-roumu)，照护、身心障碍福祉的劳务整理于[照护、身心障碍福祉的劳务管理](/zh/labor/services/kaigo-roumu)。**咨询免费。** 费用请见[报酬额表](/zh/labor/ryokin)，常见问题请见[常见问答](/zh/labor/faq)。

## 常见问题

**Q. 护理人员可以兼任机能训练指导员吗？**
A. 能担任机能训练指导员者，为物理治疗师、职能治疗师、语言听觉师、护理人员、柔道整复师、按摩指压师、针灸师等具资格者，护理人员以此资格兼任机能训练指导员一般认为可行。但即使兼任，一人的劳动时间总量不变，加成工资以跨职务合计的实际劳动时间计算。具体可否须向指定权者确认。

**Q. 生活咨询员一定要是常勤吗？**
A. 生活咨询员本身不一定要常勤，但生活咨询员或照护人员之中至少1人须为常勤（平成11年厚生省令第37号第93条第6项）。要让哪一方常勤，是雇用合同与排班设计的问题，属于社会保险劳务士处理的范围。

**Q. 常勤换算只要凑足“人头”就好吗？**
A. 不是。常勤换算以勤务时间总量来看，是全体职员的勤务累计时数除以常勤者应勤务时数所得之数。年假、缺勤、研修导致累计时数下降时，有低于基准之虞，因此以留有余裕的排班设计为前提。

**Q. 人员基准的符合与劳务可以委托给同一人吗？**
A. 因依据的法律不同，须分开考量。人员基准的解释与指定申请文件的制作属于行政书士，排班设计、工作规则、劳动时间管理、社会保险的劳务属于社会保险劳务士。在四葉，四葉行政書士事務所与四葉社会保険労務士事務所为独立的事业体，以分别签约的方式分工。
