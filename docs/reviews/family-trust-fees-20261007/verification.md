| 1契約・30,000,000円 | 330,000円 |
| 1契約・50,000,000円 | 550,000円 |
| 1契約・100,000,000円 | 1,100,000円 |
| 1契約・150,000,000円 | 1,375,000円 |
| 2契約・各25,000,000円 | 各330,000円、合計660,000円 |
| 2契約・各50,000,000円 | 各550,000円、合計1,100,000円 |
| 50,000,000円の不動産・各1/2を別契約 | 各評価25,000,000円、合計660,000円 |
| 100,000,000円の不動産・各1/2を別契約 | 各評価50,000,000円、合計1,100,000円 |
| 100,000,001円 | 算式上1,100,000.0055円。請求額の丸めは未確定 |

「以下／超」「契約ごと」「超過部分のみ」「税込・再加算なし」「通常相談無料・実作業別見積り」「他専門家への直接契約・直接請求・直接入金」「預かり・継続管理を含まない」の説明を4言語で維持。最低330,000円を総額Offerとして構造化していない。
